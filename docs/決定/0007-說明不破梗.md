# 0007 「怎麼玩」的說明不破梗

- 日期：2026-11-08
- 誰決定：翊文
- 狀態：有效

## 背景

- 設定頁右邊的「怎麼玩」原本寫了理智 0 會進「俄國8+9 的房間」。
- 翊文 11-08：

  > 「說明裡的：理智 0就進「俄國8+9 的房間」。不要現在就破梗」

## 決定

- 「怎麼玩」只講怎麼操作、規則的大方向，不寫出要玩家自己發現的東西。
- 不寫出來的：理智 0 會發生什麼、隱藏展品、禁書的續集和怎麼打開、結局。
- 理智 0 那條改成「理智 0 的時候，會發生壹些事。」。

## 影響

- `web/src/ui_screens2.js` 的 `howToPlay()`。
- 同樣的想法也用在別的地方：
  - 我的展廳的「主題展」小卡：還沒見過「俄國8+9」的人不列那個主題，只留一張「？？？ 還有壹個主題，等你發現」；沒解鎖「不可名狀」就不提它。
  - 新的教學、提示、更新公告裡給玩家看的部分，都照這條。
- 第 4 版：劇情、活動放在伺服器照時間給，還沒開放的章節不會先送到玩家的瀏覽器（規劃.md 第五節「不再是一個 HTML 檔」）。

## 什麼時候可以再討論

- 不再討論。每一版都守這條（`docs/界線.md`）。要寫進「怎麼玩」的東西拿不準會不會破梗，先問翊文。
