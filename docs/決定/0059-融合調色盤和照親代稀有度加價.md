# 0059 融合調色盤和照親代稀有度加價

- 日期：2026-11-10 10:35:16
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「靈感：要不要先做「融合照親代稀有度加價」　要，那融合給的稀有度、強度等等的是不是也要提升」
>
> 「融合加多一點融合才有能解開的新顏色……像調色盤一樣解新顏色，新顏色也有機會得到有比較多的強度」

## 決定

1. 新顏色只能在融合室用兩種顏色調出來（`mix`），不能用靈感買、不會被突變抽到、不算進圖鑑格數。
2. 調色配方跟一般配方分開比對，可以同時發生；一般配方已經決定顏色時照一般配方。
3. 調色盤的提示：兩種材料顏色都有了才給，不直接說是哪兩種；調出來過才寫出配方。
4. 融合的價錢照爸媽稀有度加；血統也照稀有度給，愈貴的融合愈容易出好的稀有度。
5. 調出來的顏色在地下收藏庫強度 +1。
6. 數字（加價、血統、強度）是草稿，可以直接調 `shared/config.js`，不用新開決定。
