# 圖書館的「地圖」頁籤換成羊皮紙＋紅圖釘

## 為什麼要改
翊文截圖：「地圖的頁籤可以稍微不一樣一點嗎顏色也可以不一樣，我們可以拿素材或自己畫」。

## 改了什麼
- ui_story.js originTabs：每個頁籤多壹個 class tab-<id>（之後要單獨改別的頁籤也能用）。
- tabx.css：tab-map 用現成的 ui2-tabx-parchment-1／2（圖鑑室的羊皮紙牌子），前面放 map/pin-lit 紅圖釘，墨色字，微微斜 1.5 度，像釘在書櫃上的地圖。沒有生新素材。

## 怎麼確認的
開發版 1400×800：地圖頁籤是淺色羊皮紙、紅圖釘，其他頁籤是木牌；點下去選好的樣子也對。

## 還沒做、要注意
手機窄的時候頁籤會左右滑，圖釘照樣在；要更特別可以請美術生壹張專用的地圖牌子。
