# 0093 欠債玩家賣股票還債：賣出上限隨信用、賣股還債、財經專員

- 日期：2026-11-16 03:00:00
- 誰決定：翊文（玩家回報「一天只能賣 2,000 萬股票要怎麼還債」，翊文：「三件都做」）
- 狀態：有效（第 1 件 PR 560；第 2 件下面；第 3 件做了再補）

## 第 1 件：壹人壹天的賣出上限隨信用等級（PR 560）

- `NUM.casino.stock.sellDay`（2,000 萬）是 **0 級**的上限；`sellMultByCredit: [[2, 2.5], [4, 5]]`：信用 2 級 ×2.5（5,000 萬）、4 級以上 ×5（1 億）。館外股（`casStockSell`）和館內股（`casInSell`）都用 `casSellCap(w)`。
- **信用等級的算法只有一份**：新檔 `shared/casino_credit.js` 的 `casCreditLevel`（槓桿的 `casLevLevel` 也叫它，不另外算）；`casSellCap`、`casSellNext`、`casSellTip`（「信用升到 2 級可以賣到 5,000 萬。」）。不 import 別的規則檔，所以不會跟股票、槓桿 import 成圈。
- 超過上限的訊息多寫提示；`casStockView`／`casInView` 多回 `sellCap`、`sellTip`（畫面寫「信用升到 N 級可以賣到 X」，版面美術統籌）。
- **守住的**：館內股全館淨賣出上限（`netSellPct`、`netSellFlat`）照舊；館外股外面世界付得出來（`casWorldRoom`）照舊。最高級壹人壹天 1 億 ≤ 外面世界起始（100 億）的 1%（`econ:check` 擋）。
- 改倍數用 `npm run tune -- NUM.casino.stock.sellMultByCredit.0.1=3`。

## 第 2 件：賣股還債（不受壹人壹天上限）

- 新的賣法 `op: "sellDebt"`（`functions/casino.js` 的 `actStock`；`shared/casino_debt.js` 的 `casSellForDebt(w, house, id, shares, day, t)`）：館外股、館內股都能賣。
- **欠款** ＝ 錢包的負數（借款到期被直接扣掉的）＋ 現在還得了的借款（過了「借了幾分鐘後才能還」，`repayAfterMin`）的本金加利息。沒有欠款擋掉。
- **賣多少**：最多賣到「賣得的錢（扣手續費）剛好夠還欠款」（`shares: "max"` ＝ 賣到剛好夠；給的股數超過會擋、告訴你最多幾股），不會賣過頭。**手續費、館外股的資本利得稅照舊**。
- **還的順序**：賣得的錢進錢包，先補負數；再照到期順序一筆一筆**整筆**還清借款（`casRepay`，本金加利息回到莊家、`loansOut` 減少；準時還清照樣升額度）；剩下的零頭留在錢包。
- **不受壹人壹天賣出上限**（`opts.free`），也**不算進**今天賣出的額度和館內股的全館淨賣出：因為賣的錢大半馬上還給莊家，莊家不會被搬空；館內股由莊家付賣的錢、館外股由外面世界付（`casWorldRoom` 照舊）。
- 銀行頁的資料：`casBankHall` 多回 `debt: { owed, neg, loans, can }`（版面交美術統籌：有欠款才出現「賣股還債」）。
- 守恆：賣股的錢流照原本（`stockSell`／`stockIn`），借款回到莊家（`loanBack`），沒有新的錢來源；`test/casino_debt.test.cjs` 驗帳。

## 補（11-16，翊文：「放寬成 10 億」）：4 級以上改成每天 10 億

- `sellMultByCredit` 改成 `[[2, 2.5], [4, 50]]`：2～3 級 5,000 萬、**4 級以上 10 億**（×50）；0～1 級照舊 2,000 萬。用 `npm run tune` 改，`world:check`、`econ:check`、世界經濟測試、30 天模擬（景氣 0、−1）全過、守恆。
- `econ:check` 那一條從「最高級一人一天 ≤ 外面世界起始的 1%」放寬成「≤ 10%」（10 億 ＝ 池子起始 100 億的 10%）：持股的賣出本來就是買進時付進去的錢，上限擋的是多頭時一口氣兌現的獲利（館外股一天最多漲跌 10%、槓桿獲利另有 profitCap）；**館內股全館淨賣出上限不放寬**（莊家的 5% ＋ 500 萬，現在約 860 萬一天，所以館內股實際擋的是它）、0～1 級還是原本的上限。
