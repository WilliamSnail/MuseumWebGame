# 介面重塑素材清單（每個廳一個畫面）

> 2026-11-13，Claude 寫。翊文 11-13：「介面重塑也是一個新事項，目前每個廳都要很多訊息，要往上下滑才能看到全部」「需要也可以給我Prompt設計界面，然後我們用共通零件組合起來」。
> 做法看 `docs/介面整合規劃.md` 第六步。跟打怪畫面一樣：先生整張介面當方向（第一節），AI 看圖列出共通零件，再生零件（第二節），切好組起來。
> 網頁版（一張一段、可以直接複製）：`node tools/flat_prompts.cjs --src docs/介面重塑素材清單.md --out 介面重塑Prompt.html --dir assets/ui2`。清單改了就重跑，不要手改網頁。

## 〇、先看這幾條

- 每一張都附打怪的整張介面（`assets/cellar2/ui-電腦.webp`）當風格參考：深色雕花木框、舊銅、酒紅、羊皮紙，老博物館的感覺。
- 不畫青蛙、不畫任何角色的臉（界線：不畫 Pepe）。委託單上要放收藏的地方，畫成空白的小卡或剪影框就好。
- 字讓程式寫：整張介面的圖可以有很短的假字當位置提示，零件一律不要字。
- 共用的結尾（每一段最後的【結尾】）：

```
flat front view, no perspective, soft light from the upper left, hand-painted 2D game UI, muted warm palette with dark carved wood, aged brass, wine red and parchment, cozy old museum mood, clean readable layout, no frog, no animal, no face of any living creature
```

- 零件（第二節）多接一段零件結尾（原因看 `docs/素材生成.md`「零件 prompt 的八條」）：

```
Draw ONLY the listed items: do not redraw the panel, the screen or the mockup itself; use the attached reference only for style and colors. Draw exactly the number of items listed, no duplicates, no extra rows. No text, no letters, no labels, no numbers. Pure flat #00FF00 background with no gradient, no vignette and no ground shadow. Every item the same size and evenly spaced, with at least 80 pixels of empty green between items. Different states of one item keep an identical shape and size; only the color and glow change. 9-slice pieces have a uniform border thickness on all four sides, with plain straight edges between the corners.
```

## 一、整張介面（先生這三張，當方向）

### U-1 共通骨架（電腦）

```
A complete game screen mockup, 1366x768 landscape, for one room of an old museum game, showing a reusable layout that every room will share. Top: a thin dark wood navigation bar with a row of small round brass icons. Below it a single slim title row: an engraved brass nameplate with the room name on the left, one short line of description, and three small brass icon buttons on the right. Main area (about 70% of the width): a large dark wood display frame holding the room's main content as empty placeholder cards. Right side column (about 25%): two or three stacked small wooden side panels with brass corners, each with a short title ribbon and a few placeholder lines. Bottom: a collapsible drawer — a long wooden tray with a brass pull handle, holding one row of small empty square slots. Everything fits on one screen with no scrolling. 【結尾】
```

對應：每個廳共用的骨架（標題一行、主區、側欄、最下面的收藏抽屜）。

Main area: a dark cork notice board in a carved wood frame with three or four parchment request notes pinned by red wax pins, each note with a small tag, star rating, a few placeholder lines and an empty square drop slot at the bottom; one note has a red ribbon on its corner marking a special regular customer. Right side column: a small wooden panel showing three regular customers as three small parchment name cards in a row with little progress dots under each, and below it a wide brass button. 對應：`web/src/ui_screens2.js` 的 `SCREENS.commission`（委託單、老主顧、壹鍵交件、你的收藏）。
