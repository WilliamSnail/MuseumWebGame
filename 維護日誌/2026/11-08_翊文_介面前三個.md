## 改了什麼

- **狀態列**（第 3 項）：
  - 電腦版排成一排：天數改成上下兩小行（「第 001 天」下面「15 分鐘後換天」）、心情和理智的條縮短、間距縮小。1366、1100 寬是一排 70px。
  - 更窄排不下時還是會換排（1024、820 寬是 90px），所以 `ui_core.js` 加 `watchStatusHeight()`：用 ResizeObserver 量狀態列真正的高度，放進 CSS 變數 `--status-real`；各頁底下的留白、看展的圖層、問答框、揭曉畫面的高度都改看它（`ui.css`）。
  - **不能直接寫回 `--status-h`**：`#status` 的 `min-height` 就是 `--status-h`，寫回去就再也縮不回來。
- **擲骰畫面**（第 1 項，`ui_screens1.js` 的 `SCREENS.reveal`）：
  - 擲骰時加 `.rolling`：空展台縮小（電腦 150px、手機 110px），骰盤捲到畫面中間。
  - 骰子停了：捲到「用心情把骰子壓低」，再補捲讓「就這樣」看得到。
  - 揭曉：捲回展台；骰盤收起來（原本只是變透明、還佔著約 350px，把名牌和按鈕推到畫面外）；手機的展台和佩佩縮小一點；按鈕出現後不在畫面裡才補捲到剛好看得到。
  - 揭曉多一顆「回大廳」。
  - 只在不在畫面裡時才捲；上下留給導覽列、狀態列的空間寫在 CSS 的 `scroll-margin`；「動畫減量」時直接跳、不平滑捲。
- **下一步**（第 2 項）：
  - `shared/guide.js` 的 `nextStep(P)`（純函式）：照順序看做過什麼：看一幅畫 → 做第一隻（靈感不夠就先再看畫）→ 交一張委託 → 解鎖一個選項 → 擺進展廳 → 做一個抱枕 → 讀第一章 → 都做過就回傳 null。自由模式不帶路。
  - 大廳標題下面一條「下壹步」：要做什麼、為什麼、「走過去 →」按鈕；電腦和手機都看得到（手機按鈕佔滿一行）。導覽圖上那間房金色光暈慢慢呼吸（動畫減量時不動）。

## 給下一個人

- 狀態列的高度用 `--status-real`（實際量的），不要再用固定的 `--status-h` 算版面；`--status-h` 只當狀態列自己的最小高度。
- 自動捲動要用 `seen()`／`bring()` 這種「不在畫面裡才捲」，不然玩家自己捲了又被拉回去。
- 測自動捲動時，背景分頁的平滑捲動不會動，要開「動畫減量」或把分頁拉到前面。
