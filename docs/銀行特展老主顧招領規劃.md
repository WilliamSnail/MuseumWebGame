## 一、Yuga Bot 銀行：存錢、定存、館債、股票

### 現在

- 銀行只有「跟 Yuga 借錢」（決定 0064）。
- 籌碼的用處很少：換小獎有每週上限，其他就是下注、借錢、吃餐車。籌碼越存越多卻沒地方用。
- 籌碼不是錢，不能買、不能換現實的東西（界線）。這一條不變。

### 要做的

| 東西 | 怎麼玩 | 籌碼從哪來、到哪去 |
|---|---|---|
| **活存** | 錢包的籌碼存進銀行，隨時領。存著的不能直接下注。每天 05:00 給一點利息（先定每天 0.1%，最多算 1,000 萬）。 | 利息由莊家出。 |
| **定存** | 鎖 3 天或 7 天，到期本金加利息一起回來（先定 3 天 1%、7 天 3%）。提早解約只拿回本金。同時最多 3 筆。 | 利息由莊家出。 |
| **館債** | 每週一發一期，名字跟這週的劇情走（例如「B2 修繕債」）。一張 10 萬，週日到期還 10.5 萬。**莊家破產中，到期只還九成**：跟莊家的錢連在一起。 | 買債的錢進莊家，到期莊家還。 |
| **股票** | 館內五家「店」：餐車、Hamachi 賭場、委託櫃台、地下收藏庫、手作坊。每天 05:00 照**前一天大家真的做了多少事**調股價，再加一點隨機。例如昨天大家吃餐車吃很多，餐車股漲；地下守門輸很多，地下收藏庫股跌。買賣收 0.5% 手續費。 | 手續費給莊家。漲跌是籌碼憑空多出來或少掉的，所以要設上限：一天最多漲跌 10%，一個人一家最多持有 1,000 股。 |

- **籌碼的平衡**：利息、館債是籌碼「多出來」的地方；手續費、餐車、賭桌是「花掉」的地方。上線前用 `test/sim_casino.cjs` 跑「一個人每天都把錢存最多」的情況，看一個月會多多少。
- **榜單**：籌碼榜要不要把存款、定存、債、股票算進去（算「身家」）。
- **故事**：股價的理由寫成館內新聞，一天一句，例如「昨天的烤雞肉多賣了 300 份」。可以接每天的公佈欄。

### 怎麼做（分 4 個 PR）

1. 活存、定存：規則放 `shared/casino_bank.js`（純函式），伺服器放 `functions/casino.js`，畫面是銀行那一欄多「借錢｜存錢｜定存」頁籤。
2. 館債：每週一由每週劇情的排程寫進 `week.json` 的 `bond`（名字、利率），檢查程式擋利率太高的。
3. 股票：伺服器每天 05:00 算股價。「前一天做了多少事」用伺服器已經有的統計（吃了幾份、打了幾場）。
4. Discord：`/pepe-存錢`、`/pepe-股價`。

### 要翊文決定的

1. 利率可以嗎？活存每天 0.1%、定存 3 天 1%、7 天 3%、館債一週 5%。
2. 股票要照「大家真的做了多少事」來動嗎？還是單純隨機？
3. 籌碼榜要算身家（含存款、股票）嗎？
4. 先做哪幾個？建議先做活存和定存，最簡單，也最不會把經濟弄壞。

## 二、這週前幾天的特展：補劇情

### 現在（決定 0060 做過一部分）

- 畫廊的今日特展下面，有一排「這週前幾天的畫」（週日叫「本週回顧展」）。可以點開看，看了也會記線索。不給靈感，補做「看完特展」的任務用。
- 問題：
  - 前幾天的畫混在一排，看不出哪幅是哪一天、哪個主題。
  - 每天特展的**介紹文字**（劇情在這裡）只有當天看得到。
  - 沒有地方提醒「前幾天還有幾幅沒看」。

### 要做的

1. 畫廊多一個頁籤「這週的特展」：
   - 一天一張小展間卡，寫第幾天、那天的主題名稱、那天的介紹文字。
   - 下面是那天的畫，還沒看過的蓋布。
   - 「看過 3／5 幅」。
2. 每週劇情面板的每一天，多一行「那天的特展：主題（看過 3／5）」，點了直接到那一天。
3. 前幾天還有沒看過的畫，畫廊的頁籤上標「還有 n 幅」。不標哪幅有線索，不破梗。
4. 看前幾天的畫還是不給靈感（決定 0060），也不擲理智。要不要擲，問翊文。

### 要翊文決定的

1. 補看前幾天的畫，要像當天一樣擲理智嗎？（現在不擲）
2. 上一週的特展要不要也能看（例如放在圖書館的「以前的特展」）？上一週的線索已經收線了，看了不會再記。

## 四、招領：遇到理智歸零的參觀者（不叫幽靈）

> 11-13 做好了（翊文：「先做招領」）：`shared/lostfound.js`、`functions/lostfound.js`、`web/src/ui_lost.js`。下面的問題翊文沒回答，先照建議的做：叫「招領單」、送回去 +2 靈感／心情 +5、進館時自動補最近 7 天的（Jerry 那一位等他下次進館就會出現）。合作時的「幽靈」還沒改名。

### 現在

- 地下合作時隊員理智歸零，那一趟剩下的路會變成「幽靈」：看得到真的記號、不能說話、一間敲一下。一趟結束就沒了。
- 別的館友在地下**遇不到**以前理智歸零的參觀者。Jerry 那一位只留在他自己館長室的「歷任參觀者牆」上。
- 地下會遇到別人的，只有欠款去地下工作的參觀者（每層 80%，決定 0064）。

### 為什麼不叫幽靈

翊文：「這代表變成鬼了。」這個館的可怕是**帳對不上，而且對不上得很整齊**（`content/排程說明.md`）：
- 名牌空白、多一票沒人認領、外套的招領單、號碼牌、溫的空椅子（W46 d4）。
- 所以理智歸零的人沒有變成鬼，是**沒有走出去**：登記簿上還有他的名字，東西留在館裡，等人認領。

### 要做的：地下的「招領單」

1. 有人的參觀者理智歸零了，館裡就多一張招領單。內容有：
   - 他的名字、職業、在哪一層用完理智。
   - 他身上最後一樣東西：帶下去的佩佩、或一頂帽子。
   - 一句從他的紀錄組出來的話，例如「做了 37 隻佩佩，最深到 B3」。
2. 別的館友走地下時，每一層有機會看到一張（先定 30%）。只會出現別人的，7 天內的。同一張每個人只看到一次。
3. 看到的時候三個選項：
   - **送到招領處**：原本那位館友的信箱收到一封信，「○○在 B3 撿到你以前的參觀者△△留下的號碼牌，送回來了」。他現在的參觀者心情 +5。送的人 +2 靈感。
   - **唸出登記簿上的名字**：擲理智（成功不扣，失敗 1D3），看到他完整的那一行紀錄。這也是一條「看懂」的線索來源。
   - **放著**：什麼都沒有。
4. 招領單只寫館友的暱稱（在線名單上本來就看得到），不寫 email 或其他玩家資料。
5. 合作的時候，隊員理智歸零的那個狀態也可以改名，例如「名牌空白」：還在隊上，看得到真的記號、不能說話、可以敲一下。要不要改名問翊文。

### 怎麼做

- 伺服器在參觀者理智歸零（`nextVisitor`，endedBy 是 russia8）的時候寫一筆到 `lostFound`（暱稱、參觀者名字、職業、層、日期、那樣東西）。資料庫只加不刪，7 天後不再抽到。
- 地下房間生成時，從 `lostFound` 抽一張別人的，做成一間「招領」房（借欠款工作者「遇到」那一套）。
- 上線後才會有新的招領單。要讓 Jerry 昨天那位也出現，要從存檔的 `P.history` 補最近 7 天的（伺服器那邊做，不碰正式資料庫以外的東西）。

### 要翊文決定的

1. 叫「招領單」可以嗎？還是有更好的名字（「登記簿上多一行」「名牌」）？
2. 合作時理智歸零的隊員，現在叫「幽靈」，要一起改名嗎？改成什麼？
3. 送回去的獎勵：原本的館友心情 +5、送的人 +2 靈感，可以嗎？
4. 要補 Jerry 昨天那一位嗎（從 7 天內的紀錄補）？
