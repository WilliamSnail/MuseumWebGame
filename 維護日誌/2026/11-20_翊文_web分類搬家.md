## 為什麼要改

資料夾結構第二輪（翊文：「照規劃做」）的第五項，也是最後一項。web/src/ 第一層平放 71 支畫面檔：ui_casino 開頭 7 支、fx 開頭 6 支……看不出哪支是房間、哪支是面板。

## 改了什麼

只搬位置、改路徑，沒改行為、數值、文字。**`main.js` 的載入順序沒變**（新的畫面檔要加在 `boot.js` 前面這條照舊）。

- 用 `git mv` 搬 71 支到 `web/src/<資料夾>/`，檔名不變。
- 每支裡的 `import "./xxx.js"` 重算成新的相對路徑（`./`、`../fx/`、`../rooms/`…）；`main.js` 的樣式 `import "./css/…"` 變成 `"../css/…"`。
- `web/index.html` 的入口 `/src/main.js` 改成 `/src/core/main.js`（vite 的入口）。
- ui_events.js、ui_story.js 裡的 `import.meta.glob("../../content/weeks/…")` 多一層 `../`。
- tools/check/check_imports.cjs 改成連子資料夾一起查；`ui_core.js` 不准 import 後面的檔那條照舊（檔名比對）。
- tools/check/repo_rules.cjs：BIG 清單和 OLD_NUM 換成新路徑；行數檢查、數字結尾檢查、web 繞圈檢查都能進子資料夾（繞圈改成照相對路徑解析）；`web/src/` 第一層不准放新檔（只剩 css/、assets/ 兩個資料夾）。
- tools/check/fx_report.cjs、snd_check.cjs、tools/check/fx_source.cjs、test/tools/class_names.test.cjs、test/web/sfx_files.test.cjs：原本只讀 web/src 第一層，改成連子資料夾（fx_source 只接 fx/ 那六支）。
- AGENTS.md 第 4 節加命名原則；docs/規則/架構.md 第 2 節的資料夾樹換成新的。

- ui_party、ui_login、ui_discord、ui_lost、ui_events 這些蓋在畫面上的面板放 panels。
- ui_trace、ui_route、ui_roomnow、ui_hallnow 跟著合作地下和展廳放 rooms。

## 還沒做、要注意

- 別人手上還沒合併的分支如果改了 web/src/ 的檔，併 main 時要把改動貼到新路徑的檔（git 通常認得出搬家，認不出就手動貼）。
- docs/ 裡寫「web/src/ui_xxx.js」的地方：只改了寫完整路徑的；只寫檔名的（例如「ui_core.js」）沒改，找檔名用 `git ls-files | grep`。
- tools/check/fx_report.cjs 產生的音效與特效總表，檔案欄現在是「資料夾/檔名:行」。

## 給下一個人

- 新畫面檔放哪：共用底層、不屬於某個廳 → core/；特效、聲音 → fx/；某個廳的畫面 → rooms/（賭場放 rooms/casino/、銀行放 rooms/bank/）；蓋在畫面上的面板、卡片 → panels/。第一層不放新檔。
- import 寫相對路徑，例如在 rooms/ 裡拿 core 的東西：`import { UI } from "../core/ui_core.js"`。
- 新的畫面檔要加進 `web/src/core/main.js`，放在 `boot.js` 前面（照舊）。
