# 0076 館外股票跟外面世界買賣，不再由莊家當對手盤

- 日期：2026-11-14
- 誰決定：翊文
- 狀態：有效（取代規劃 2.8a 的「莊家當對手盤」對館外股票的部分；館內五家店照舊由莊家）

## 背景

館外股票上線時（PR 287），照規劃 2.8a 讓莊家當對手盤：買股的錢進莊家、賣股莊家付。這樣帳一定平，但股價漲跌的風險全壓在莊家身上，所以加了「全館持股總市值 ≤ 莊家的 50%」等三道上限。

11-14 莊家錢少，這個上限一下就滿：翊文有 710 萬籌碼、一股不到 1 萬，卻一股都買不了。

翊文：「股票不是跟"外面世界"買的嗎?」→「好更改」。又說：「外面世界不是有台灣GDP嗎」「因為館方自己也會投資外面世界」。

## 決定

1. 館外股票（和之後的台股）跟「外面世界」買賣：
   - 買：股價×股數流出館外（`casBurn`，來源 `stockBuy`）。
   - 賣：股價×股數從館外進來（`casMint`，來源 `stockSell`）。
   - 手續費照舊進預算池（搬，不是憑空）。
2. 莊家不出錢，拿掉「全館持股 ≤ 莊家 50%」和「全館一天淨賣出 ≤ 莊家 5% ＋ 500 萬」。莊家窮不窮都不影響買賣。
3. 外面世界就是整個台灣，接得住。要擋的是多頭時館裡的錢一直變多：靠手續費、每天的 drag、每人每天賣出上限（2,000 萬，保留）。數值平衡在算最壞情況。
4. 館內五家店照舊由莊家當對手盤（館裡自己的店）。
5. 之後：股票的流出流入算進館內 GDP 的淨出口；館方自己也投資外面世界（跟決定 0074 的「莊家每天投資」整合），數值平衡設計中。

## 為什麼

- 符合故事：外面的股票本來就是跟外面買的。
- 股市不會因為莊家窮就停擺。
- 平均玩家略虧（手續費、drag），所以股市長期會把錢帶出館外，變成錢的出口，幫忙壓通膨。

## 風險

多頭時玩家一起賺，館裡的錢變多。記帳照樣記得到（憑空、消失都有來源），日報看得到。看真實數字再調上限。
