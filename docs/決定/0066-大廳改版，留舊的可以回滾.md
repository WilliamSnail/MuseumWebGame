# 0066 大廳改版，留舊的可以回滾

- 日期：2026-11-11
- 誰決定：翊文
- 狀態：有效

## 背景

翊文 11-11 要了一份新的大廳草稿（`drafts/新大廳/`，Issue #154、PR 155），看過之後：

> 「可以，接進遊戲，並且把這個當大版本更新，之後有問題可以回滾」

## 決定

- 大廳換成新的樣子（`web/src/ui_lobby2.js`、`web/src/css/lobby2.css`）：
  - 導覽圖用畫好的底圖（`web/public/lobby/land.webp`），11 間房是疊在上面的透明按鈕；名字、進度、館友名牌、「新」都由程式畫。「新」貼在名字標籤的左上角。
  - 右邊一欄：館友證、今天要做的事（下一步排第一張、會發光；做完的變淡；最多 4 張）、4 個小圓章（週章、委託、靈感、收藏）。
  - 活動預告、館友在線縮成兩條細橫幅，放在導覽圖上面。
  - 頂欄的圖示放進圓形底座，圖示在上、字在下。
  - 籌碼在狀態列（翊文 11-11：「籌碼感覺可以放在底下的ui」）。
- 這是一次大版本更新：版本號換新的一天，館方公告標「重要」。
- **回滾**有三層，由輕到重：
  1. 玩家自己：設定頁「大廳的樣子」選「舊的」（`SAVE.settings.oldLobby`）。
  2. 全部的人：`shared/config.js` 的 `NUM.ui.newLobby` 改成 `false`，開一個小 PR 合併。舊的大廳程式（`SCREENS.lobby` 下半段、`ART.floorPlan`、`ui_hub.js`）都沒刪，馬上就回去；頂欄的圓形底座也一起拿掉。
  3. 整個退掉：`git revert` 這次的合併（決定 0024 的做法）。
- 素材只複製用得到的、縮小轉成 webp 放在 `web/public/lobby/`（30 個，約 260KB）；原圖還在 `assets/`，不進 `dist/`。
