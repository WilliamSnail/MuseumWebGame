# 理智低時，畫廊、展廳、大廳逐漸多的怪事

翊文 11-22：「這些在理智55以下就逐漸有」。程式在 `web/src/fx/ui_sanfx.js`，段數判斷在 `shared/social/room_mood.js` 的 `sanFxTier`，門檻在 `shared/core/config.js` 的 `NUM.sanFx`（改這裡就好，不用動畫面檔）。

## 三段

| 段 | 理智 | 感覺 | 畫廊 | 展廳 | 大廳 |
|---|---|---|---|---|---|
| 1 | < 55 | 很輕，偶爾壹樣 | 壹幅畫的角落多出壹雙眼睛，眨 3 下就消失 | 壹隻佩佩把頭轉向你（傾 11 度，3 秒） | 偶爾壹塊白布從上緣探出壹點點（14 像素） |
| 2 | < 40 | 多幾樣 | 眼睛同時出現兩處；偶爾白布滑下 36 像素 | 兩隻佩佩轉頭；偶爾白布 | 「今日要聞」換成不是館員的口氣（「今日沒有人值班」＋壹句）；偶爾白布 |
| 3 | < 25 | 最明顯 | 眼睛三處；白布滑下 90 像素 | 三隻轉頭；白布 90 像素 | 同第 2 段，白布更深；整個畫面四周壓暗（`body.sf3`） |

- 隔多久演壹次（`NUM.sanFx.gap`，秒）：第 1 段 50～100、第 2 段 25～55、第 3 段 12～30。
- 都是壹次性的動畫，放完拿掉，沒有 infinite（提醒用的閃爍閃 3 下就停，11-17 的規矩）。
- 不演的時候：自由模式、燈熄（理智歸零）、省電中（`body.resting`）、分頁在背景、畫面忙著（`UI.busy`）。
- 大廳的句子是草稿（`shared/core/systems_text.js` 的 `SANFX_TEXT`），延伸劇情世界和 Yuga 可以改。

## 跟現有理智門檻的對照（沒有衝突，但疊在壹起了）

| 理智 | 現有的 | 在哪 |
|---|---|---|
| < 70 | 整個畫面慢慢變暗、變冷（`--wallNow`、`--dim`，越低越明顯） | `ui_core.js` applyBodyState |
| < 55 | **新：段 1** | `ui_sanfx.js` |
| < 50 | 低語層數開始增加（聲音）；畫廊的畫會偶爾多壹個細節差異 | `ui_core.js` whisperLayers、`ui_screens1.js` exhibitDiffs |
| < 45 | 音樂的「不安」（dread low） | `room_mood.js` SAN_DREAD |
| < 40 | `body.lowsan`（名牌抖動）、按鈕文字偶爾亂碼；**新：段 2**；NPC 理智低的人數算進怪影子（RM.sanLow） | `ui_core.js`、`room_mood.js` |
| < 35 | 轉頭畫會翻（ODD flip） | `ui_odd.js` ODD_AT |
| ≤ 30 | 心跳聲；按鈕在說話（ODD talk）；交代人講低理智的話 | `fx_sound.js`、`ui_odd.js`、`ui_giver_talk.js` |
| < 25 | 黑影跟著游標（ODD follow）；**新：段 3** | `ui_odd.js` |
| ≤ 15 | 音樂「邊緣」（dread edge）；合作的探險報告算「差點出事」 | `room_mood.js`、`shared/coop/base.js` |
| 0 | 燈熄（`lights-out`），這裡全部不演 | |

新的三個門檻（55、40、25）特意對齊了 40（lowsan）和 25（黑影），段 2、3 跟它們同時開始，不另外多出壹個數字。這些舊的門檻目前都寫死在各自的檔案裡，沒有放進 `NUM`，要不要統壹是另案。
