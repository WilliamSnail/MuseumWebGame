# 0160 零碎股：照金額買賣

- 日期：2026-11-27 10:16:01
- 誰決定：翊文
- 狀態：有效

## 背景

翊文 11-27：「還有輸入金額而非股數的零碎股交易」。原本館外股只能照整數股數買賣，要自己算買得起幾股，錢也會剩零頭。

## 決定

1. 館外股（台股、美股）可以打金額買賣。館內股、集團股不變。
2. 買：金額含手續費，花的不會超過打的金額。買到的股數可以有零碎，最小萬分之壹股。
3. 賣：打想賣出的金額，或按「全賣」連零碎的一起賣。證交稅、手續費、每天賣出上限都照整數股的規則。
4. 存法：整數股照舊放 `w.stk.own`，零碎的放 `w.stk.frac`（萬分之壹股為單位，1～9999），累積到一股就併進整數股。
5. 只算整數股的地方：配息、掛單、還債賣股、莊家的持股曝險。零碎股每人每支最多不到一股，差很小。
6. 換比例（peg）時，零碎股照換之前的價換成籌碼（從外面世界那池付）。
7. 市值、淨值、持股明細都把零碎股算進去。

## 要注意

- 新的動作是 `stock` 的 op `buyAmt`、`sellAmt`（金額放 `d.amt`）。
- 規則在 `shared/casino/stock.js` 的 `casStockBuyAmt`、`casStockSellAmt`；畫面在 `web/src/rooms/bank/bank_amount.js`。
