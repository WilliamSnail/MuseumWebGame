# 生成介面素材的做法

> 翊文 11-12 定的：「以後生成我們可以這麼做」。給下一次要生成板子、框、圖示的人（AI 或人）看。

## 一、板子、框不要整張生成，拆成零件

整張的板子圖用 `border-image` 拉伸，寬扁的會被拉長、方的會被壓扁（11-12 地下室「跟館友壹起下去」就是這樣）。
改成拆成零件，畫面上再組起來。零件只重複排列、不拉伸，所以什麼大小都不變形。

| 層 | 零件 | 畫面上怎麼排 |
|---|---|---|
| 底 | 壹塊可以無縫拼接的材質（石板、木頭、羊皮紙），正方形 | 鋪滿、重複貼 |
| 框 | 橫的邊條壹條（直的用轉 90 度的）＋四個角放同壹張 | 邊條重複接；角固定在四角 |
| 裝飾 | 鐵釘、鉚釘、夾片，放同壹張 | 角上各壹個，邊上等距排 |

第壹套（地下室石板鐵框）的原圖和處理好的零件在 `assets/panel-kit/`。

## 二、生成指令要寫的

- **英文**比較穩，指令直接貼。
- **背景用純綠色**：指令最後加
  `on a solid pure green (#00FF00) chroma key background, no checkerboard, no shadows on the background`
  Gemini 寫「透明背景」常常畫出假的灰白格子，淺色的部分（鐵釘的亮面）會跟格子分不開。
- **光從左上來**，每張都寫，拼起來才像同壹個地方。
- **正面、平的**：`flat front view, no perspective`。
- 材質寫 `seamless tileable`；邊條寫 `seamless horizontally tileable strip`、要多寬多高。
- 好幾個零件放同壹張時，寫 `arranged in a grid with wide empty space between each item`，方便切。
- 不要有字：`no text`。

### 零件 prompt 的八條（11-13 生 3-8～3-17 學到的）

附了整張介面當參考圖時，Gemini 常常照著整張重畫一次，或自己加東西。每一張零件的 prompt 都要有：

1. **只畫要的零件**：`Draw ONLY the listed items. Do not draw the panel, the screen or the mockup itself; use the reference only for style and colors.`
2. **不要字**：`no text, no letters, no labels, no numbers`（只寫 `no text` 常常還是有編號、小字）。
3. **數量寫死**：`exactly N items, no duplicates, no extra rows`。
4. **純綠底**：`pure flat #00FF00 background, no gradient, no vignette, no ground shadow`。
5. **一樣大、一樣間距**：`every item the same size, evenly spaced`，切的時候才能用 `--cell`。
6. **不同狀態同一個形狀**：平常、選好、不能按要 `identical shape and size, only the color and glow change`，不然換狀態時按鈕會跳。
7. **九宮格要邊一樣寬**：`uniform border thickness on all four sides, plain straight edges between the corners`，四角可以有花樣，中間的邊不要有花樣。
8. **零件之間留寬**：`at least 80 pixels of empty green between items`，發光、陰影才不會黏在一起。

這八條寫成 `docs/地下室素材清單.md` 第〇節的「零件結尾」（第二個程式框），`tools/flat_prompts.cjs` 會自動接在 3-8 以後每一張的【結尾】後面。新的零件編號不在 3-8～3-19 的話，要一起改 `isPart`。

### 給翊文的指令一律做成網頁（翊文 11-12：「先把以後生圖用的html記好，這很好用」）

- 不要給 md 檔、也不要叫翊文自己拼結尾、自己找參考圖。
- 做法：
  1. 先把每張的 prompt 寫進素材清單（例如 `docs/地下室素材清單.md`）。
  2. 跑 `node tools/flat_prompts.cjs`，產生網頁（例如 `docs/地下室素材Prompt.html`），傳給翊文。
- 網頁的樣子：
  - 一張一張卡片，每張上面放要附的參考圖縮圖。
  - 兩顆鈕：「① 複製參考圖」「② 複製 Prompt」。
  - 「生好了」可以勾，記在翊文的電腦上。
  - 圖片包在檔案裡，打開就能用。
- **網頁只放在 `docs/`，生完就刪**（翊文 11-13：「用完的就刪掉」）：這批圖都生好、搬進 `assets/` 了，就 `git rm` 那個網頁；清單（`.md`）留著，要重生再跑 `flat_prompts.cjs`。新的一批做成新的網頁，不要改舊的。
- 翊文生好的圖放 `docs/生成圖片待整理/`，檔名照網頁上的編號（例如 `2-2_f1a.webp`）。AI 處理完搬到 `assets/` 底下對的資料夾。
- 別的主題的素材（不是地下室的）也照這個樣子做。`flat_prompts.cjs` 現在只讀地下室那份清單，要用就改成可以指定清單和輸出檔。

## 三、拿到圖之後

- **壹張壹張傳**：AI 還在處理上壹張時傳的圖存不下來，要等 AI 回覆再傳下壹張。
- 原圖放 `assets/`，處理好的放 `web/public/`，用 webp。
- 材質、邊條：`python tools/make_tile.py 原圖 輸出.webp [--x] [--preview 預覽.png]`。它會拉平「左上亮、右下暗」、修好接縫；`--x` 只修橫向（邊條用，上下的立體光影留著）。
- 第 2、3 套和捲軸：`python tools/build_panel_kits.py`，把 assets/panel-kit/ 的原圖做成九宮格圖到 web/public/kit/，CSS 用 `border-image: url(...) 切線 fill / 寬度 round`。邊重複起來太規律時，取長壹點的壹段、接上左右翻過來的同壹段（接縫天生對得上）。
- 好幾個零件在同壹張：`python tools/cut_sheet.py`（`tools/README.md`）。
- 一張好幾格（怪物的姿勢、特效的連續圖、一排圖示）：`python tools/cut_frames.py 原圖 輸出.webp --rows 6`（`--rows 4,3` 是上排四格、下排三格）。它把綠幕的顏色從半透明的地方減回去（發光、灰塵不會偏綠），每格用同一個框裁，切成一條；CSS 用 `background-size: (格數×100%) 100%` 一格一格播。11-12 地下室第一批就是這樣做的：原圖 `assets/cellar2/`，成品 `web/public/cellar2/`。
- 組好先照「寬扁」和「方」兩種大小看過，再接進遊戲。
