# 0111 政府稅收：證交稅 0.3%、營業稅 5%、娛樂稅 5%

- 日期：2026-11-16 23:59:00
- 誰決定：翊文（營業稅、娛樂稅「可以」；股票稅「『賺錢才抽 5%』換成『賣出都收 0.3%』好」；美股不收，貼近真實）
- 狀態：有效（取代決定 0110 裡「資本利得稅進政府帳」的稅；政府帳本身照舊）

## 決定

1. **證交稅**取代股票資本利得稅：
   - 館外台股、館內股，賣出時收「賣出金額 × 0.3%」，**不管賺賠**；**美股不收**（`NUM.casino.stock.taxUs = 0`，真實美股沒有證交稅）。槓桿平倉、當沖不收。
   - **進位、最少 1 籌碼**（`casStockTax`／`inTax`）：捨去的話賣 333 籌碼以下的小單稅是 0，拆成很多小單就逃稅；手續費本來就進位，一致。稅不超過「賣出金額 − 手續費」，所以不會讓拿到的錢變負。
   - 進政府帳（來源 `stockTax`）。成本、平均成本還是記著，只用來顯示損益，不再影響稅。
   - 賣股還債（`casSellForDebt`）和還款計畫（`casAdvisorPlan`）算「賣一股拿到多少」時都扣證交稅。
2. **營業稅 5%**（`NUM.casino.tax.bizPct`）：NPC、散客在餐車、委託櫃台、地下收藏庫、手作坊花的錢。**牌桌不課**（賭博）；**拍賣、畫的買賣、玩家自己的消費不課**。
3. **娛樂稅 5%**（`NUM.casino.tax.entPct`）：NPC、散客的門票。
4. **營業稅、娛樂稅都內含**：NPC、散客付的錢不變（還是外面世界出），政府先拿 5%，收的人（莊家、預算池、館方帳）收剩下的 95%；門票是政府先拿，剩下的才照 30%／70% 分預算池、館方帳。展廳參觀者分紅池（玩家領的）照淨額算。記帳：外面世界 → 政府帳（來源 `bizTax`、`entTax`，`casPoolWorldOut(house, "gov", …)`），`books_sign_check` 的符號表、兩邊相反的對照都補了。
5. 說明改：銀行確認明細「證交稅（約）」、持倉說明、規則與小提示、日報政府帳一段、政府帳列的說明；館方公告。

## 影響（估，見 `.claude/交接/政府稅收建議.md`）

- 政府帳每天約 +63,000（營業稅 26,800、娛樂稅 36,500）外加證交稅（看玩家賣出量，上線後看日報的 `stockTax`）。預算池約 −30,000、館方帳約 −25,500、莊家約 −8,000。
- 股票來回成本從 1.0% 變 1.3%（賠錢的人也要繳；大賺的人少繳，損益平衡點約賺 7.5%）。

## 不做

- 不課牌桌、拍賣、畫、玩家的消費、槓桿、當沖。
- 不改手續費率。
