## 0. 先開環境（跟別的 session 分開）

```bash

npm install && npm --prefix functions install

VITE_EMU_SET=3 npx vite --port 5394 --strictPort                  # 第二個人用另一個網址（登入是依網址來源記的）
```

- 主 session 用 vite 5173、模擬器第 0 套（4400…）；`--set N` 會把連接埠都加 `1000×N`。開之前先看有沒有人在用。
- 小明在 `http://localhost:5393/?user=小明`，小華在 `http://localhost:5394/?user=小華`（瀏覽器的第二個分頁）。
- 兩個人都要有存檔、有佩佩：
  ```bash
  node tools/qa_seed_save.cjs --set 3 --nick 小明 --pepes 14     # 先登入過一次，才有這位館友
  node tools/qa_seed_save.cjs --set 3 --nick 小華 --pepes 14
  ```

- 模擬器裡的帳號、資料都是假的，不要輸入真的東西。
- 收尾：`npm run local -- --set 3 --stop`，再關掉 5394 那個 vite。

## 1. 量版面（三種尺寸）

電腦 1366×768、手機直拿 375×740、手機橫拿 740×375。每個畫面都量 `document.documentElement.scrollHeight`，要等於視窗高（不用捲）。

- 手機直拿會先跳「請轉橫」：按「先用直的」。
- 量之前把 `.screen` 的 `enter` class 拿掉（`document.querySelector('.screen').classList.remove('enter')`）。
- **不要用 `*{transition:none}` 關動畫**：拖曳的影子靠 transition 結束才收，會卡在半空（11-13 踩到，不是遊戲的 bug）。要量顏色再關，量完拿掉。
- `#畫面` 換 hash 不會重跑 `debug_boot`，要 `location.reload()`。`#commission`、`#hall`、`#fight`、`#route` 都能直接進。
- 預覽分頁在背景時動畫會停，截圖前先 `tabs_select`。

| 畫面 | 電腦 | 直拿 | 橫拿 | 11-13 的結果 |
|---|---|---|---|---|
| 委託櫃台 | 768 | 740 | 375 | 都不用捲；橫拿抽屜拉開會蓋住委託單（要點選再點單） |
| 我的展廳 | 768 | 740 | 375 | 都不用捲；直拿看不到「館友來過」「參觀者留言」；橫拿側欄太窄、字直排 |
| 打怪（`#fight`） | 一個畫面 | 按鈕在第一屏 | 放得下 | 橫拿回合軌道只剩「① ②現…」 |

## 2. 拖拉（真的用滑鼠拖，不是呼叫函式）

- 委託櫃台：把收藏拖到委託單。錯的 → 委託人搖頭；對的 → 蓋「完成」章、委託人說話、評語 +1。老主顧那張交完跳小卡「第 N／5 段」。
  - 找符合的那隻：在瀏覽器 `import('/src/ui_core.js')` 拿 `P`，再 `import` `shared/logic.js`（用 `performance.getEntriesByType('resource')` 找網址）的 `autoDeliverables(P)`。
  - 抽屜拉開（`.onescreen-pull`）有頁籤和顏色／姿勢篩選；交件後篩選會被重設。
- 展廳：把收藏拖到空展台，提示「讓牠多了一件展品」。
- 手機橫拿：抽屜拉開會蓋住單，改用「點一件 → 收抽屜 → 點委託單」。

## 4. 地下的小事件

- **招領單**：
  - 準備：小華的存檔要有 `history: [{endedBy:"russia8", d:"今天", n:1, name, job, where:"cellar:2", deepest:2, madeThis:7}]`（`npm run emu:doc -- --set 3 data saves/@小華 'profiles.challenge.history=[...]'`）；小華進館後 4 秒內會 `lostSync` 寫 RTDB `lostFound`。
  - 不想等：`node tools/qa_lost_card.cjs --set 3 --owner <小華的 uid> [--n 2]` 直接寫一張。
  - 遇到：每層、每次載入頁面只擲一次（30%），所以很難剛好遇到；擲過沒遇到就要重新整理頁面。走探索房才看得到卡。
  - 按「唸出登記簿上的名字」：理智檢定彈窗 → 擲骰 → 登記簿記錄。按「送到招領處」：+2 靈感、小華信箱收到信（11-13 還沒按成，待補）。
- **名牌空白**：`npm run emu:doc -- --set 3 data coopRuns/<id> 'members.0.ghost=true' 'members.0.san=0'`，畫面灰階、名牌有章、「你不能說話了」。（這樣改會讓這趟直接結束。）

## 5. 賭場、錢

- 借錢：`npm run emu:call -- --set 3 --user 小華 casino '{"act":"borrow","amt":100000}'`，用 `npm run emu:doc -- --set 3 get casinoHouse/main` 看莊家 `bankroll`：借出去要減、還要加（本金加 10% 利息）。
  - 還要等 15 分鐘：把錢包 `loan.list[].at` 改成很早（`data casinoWallets/@小華 'loan.list=[{...,"at":1000000000000}]'`）。
  - 到期被扣：把 `due` 改成過期，再叫一次會存檔的動作（`borrow` 一小筆；`peek` 不寫入）；莊家要多收那筆。

- 餐車、贏牌抽券（決定 0070）：`node tools/qa_casino_ev.cjs 400000`。每種餐點平均拿回 60～85%、贏牌期望 ≤ 注的 1%（5.8%＠1,000 萬、20%＠1 億）。抽券要先開過今天的大禮包。
- 展廳參觀者一天最多 40 靈感（`NUM.visitorInspDay`）：在瀏覽器連叫 `visitorArrive(P)`，今天累計不超過 40、再來的參觀者靈感 0 並顯示「滿了」。
