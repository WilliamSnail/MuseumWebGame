# 預告片（佩佩博物館2，2026-11-23）

翊文 11-22：「佩佩博物館3有一個預告片，我們參考一下，再根據我們現在增加的各種項目，再重新出一個全新版預告片，介紹各種功能」。
分鏡給翊文看過，選「照這份做 60 秒」。配樂：「音樂原創」，然後再做一個用素材的版本。結尾彩蛋：要。

## 檔案

| 檔案 | 是什麼 |
|---|---|
| `預告片_原創配樂.mp4` | 1920×1080、30fps、61 秒。配樂是 Claude 寫的、Web Audio 合成（`tools/assets/trailer/trailer.js` 的 `score()`） |
| `預告片_素材配樂.mp4` | 同壹份畫面，配樂用 `web/public/sfx` 的音樂接起來（`tools/assets/trailer/audio_mix.cjs` 的 `CUES`；來源、授權見 `web/public/sfx/來源.md`） |

## 怎麼重做

1. 開 dev server（放背景）：`npx vite --port 5391 --strictPort`
2. 照畫面：`node tools/assets/trailer/shots.cjs`（要照哪些、怎麼點在 `shot_list.cjs`；照片放系統暫存的 `pepe_trailer/shots`）
3. 關掉 dev server，再輸出：`node tools/assets/trailer/render.cjs`（約 5 分鐘；只改配樂加 `--skip-frames`；自己用瀏覽器看加 `--serve`）

需要 ffmpeg、Edge 或 Chrome。

- 改了秒數，`trailer.js` 的 `draw()`、`score()` 和 `audio_mix.cjs` 的 `CUES` 三處都要對上。
- 遊戲畫面改了，重跑第 2、3 步就好。
