# 0071 跟 Yuga 借錢，錢從莊家出

- 日期：2026-11-13
- 誰決定：翊文
- 狀態：有效（補充決定 0064）

## 背景

翊文問：「跟 Yuga bot 的借錢會從賭場籌碼裡扣嗎?」

查了程式：
- 借的時候，錢包的籌碼直接加，錢是憑空多出來的。
- 還的時候，本金加利息從錢包扣掉，也直接不見了。

翊文：「這不太對?」「從莊家來才對」。

## 決定

1. 借出去的籌碼從莊家（`house.bankroll`）出。莊家可以借到變負的；破產中換日，照舊由 Yuga 借他重新開張（`houseReset`）。
2. 還錢時，本金加利息回到莊家。利息是莊家賺的。
3. 到期沒還、換日直接扣的那一筆也回莊家。換日扣款在 `casWalletFix` 裡做，那時候手上不一定有莊家，所以先記在錢包的 `loan.toHouse`。下一次賭場交易讀到莊家時，`casLoanToHouse` 把它交過去。
4. 規則在 `shared/casino_wallet.js`（`casBorrow`、`casRepay`、`casRelief` 多一個 `house` 參數；`casLoanToHouse`），伺服器在 `functions/casino.js`。

## 之後

翊文：「也可以設計債券來借莊家錢」：玩家買館債，等於借錢給莊家，到期莊家還本金加利息。寫進 `docs/經濟體系規劃.md`，還沒做。
