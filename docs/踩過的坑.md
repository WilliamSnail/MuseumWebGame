# 踩過的坑

翊文 11-09：「整合一下今天的經驗，記好，需要腳本的也寫好」。

每條都真的發生過。寫規則或工具已經擋住的，寫在後面。

## 確認結果

- **結束碼別被管線吃掉。** `npm run ship ... | tail` 的結束碼是 `tail` 的，ship 失敗也是 0，PR 其實沒合併。要拿結果就導進檔案：`npm run ship ... > log 2>&1; echo $?`，再找 `✓ PR`。
- **`gh workflow run` 失敗時，`gh run list` 看到的是舊的那一次。** 差點把舊紀錄的「公告發了」當成這次。用 `npm run wf`，它只認新的一次。
- **別在 PR 裡寫沒驗過的事。** 寫之前真的跑一次；腳本要「驗過才合併」，別「合併完再驗」。

## Firebase 和部署

- **新種類的 Function 可能要專案擁有者開權限。** 第一個 Firestore 觸發器讓部署失敗（`Failed to verify ... IAM bindings`），而且**整個部署都擋住**，之後每個 PR 都上不了，隔天的今日館訊也會被擋。先暫時拿掉 export，讓部署恢復，再請翊文開權限。
- **權限剛開要等幾分鐘。** `Permission denied while using the Eventarc Service Agent` 等 5 分鐘重跑就好。部署到一半失敗，網頁還是舊版，但其他 Function 可能已經更新了。
- **`firebase functions:log` 不可靠：** 只回 15 行，還看不到最近的。看耗時用 `npm run wf -- discord-log.yml -f hours=2 --grep "^2026-|^=="`（`gcloud logging read`）。
- **Function 裡有 top-level await，本機模擬器會載不起來**（`require() cannot be used on an ESM graph`），正式環境沒事。`tools/emulators.cjs` 關掉了 require(esm)。
- **`npm run local` 說好了，以前 Functions 其實還沒載入**：第一個請求 404、CORS 錯，看起來像按鈕沒反應。現在會等 Functions 好了才說好了。

## Discord

- **3 秒的限制，要用真實紀錄判斷，別猜。** 模擬器量不準。我們這次：新機器第一次讀資料庫 1.9～2.7 秒，加網路就超過；常駐的機器每 15～20 分鐘會換一台。解法是啟動時先連好（`functions/discord_warm.js`）。
- **`minInstances` 不等於沒有冷啟動。** 小顆 CPU 只能 `concurrency: 1`，同時兩個請求會多開一台新機器。
- **回覆完 Function 不保證還能跑**，不要「先回處理中，再繼續做」。
- **新增指令要重新註冊**（`npm run wf -- discord-commands.yml -f application_id=... -f guild_id=...`）。部署不會自動註冊。
- **重新邀請 bot，`permissions=0` 可能清掉原本的權限。** 要給 19456（看頻道、發訊息、嵌入連結）。
- **顯示名稱不是應用程式名稱：** 「一般資訊」的名稱和「機器人」頁的使用者名稱是分開的。
- **放 token 不要用 `defineSecret`：** Secret 不存在會讓整個部署失敗。現在是部署時從 GitHub Secrets 寫進 `functions/.env`。

## 遊戲的文字和數字

- **顯示要跟效果來自同一個地方。** 餐車的屬性只有一份，卻有三處對不上，因為顯示各寫各的。所以「接資料庫」解決不了，要共用函式加測試（`casFoodWords`、`exchangeUse`）。
- **有限制的效果，沒生效時要說原因。** 「(你的心情變好了些)」一天只算一次，文字卻每次都跳，翊文以為壞了。遇到一天上限、已滿、自由模式也一樣。
- **便宜和貴的東西效果一樣，就是設計問題。** 金箔 150 萬，換週章卻跟 60 萬的舊畫布等值。加新東西時先問「玩家拿到這個能做什麼」，並寫出來。
- **加按鈕前想想版面。** 試煉卡片多一顆按鈕，文字就被擠成一字一行。

## 測試

- **規則是在另一個 VM 環境載入的**（`load_shared`）：`assert.deepStrictEqual` 比陣列會因為原型不同而失敗。比 `.join()` 或 `JSON.stringify`。
- **`G.newProfile()` 沒有「今天」**：要用測試檔的 `fresh()`，或先 `ensureDay`。
- **`casHit`、`casStand` 要帶 `r.seq`**，不然不會動，也不會報錯。
- **賭場的文件內容在 `data` 這個 JSON 字串裡**，直接改欄位不會生效。用 `npm run emu:doc`。

## 改檔

- **不要用腳本改腳本，也不要用 `sed` 改含特殊字的行。** 今天失敗了三次。用 `npm run edits`。
- **`ship` 的 `--title x` 會變成 commit 訊息**，而且推上去就改不回來（不能 force push）。已經有 PR 時也要寫真的標題；現在太短會被擋。
- **有人在 `ship` 時別動那個資料夾。** 它會 `git add -A`。
- **`mklink` 的路徑要小心跳脫：** 多出一個 `functionsnode_modules` 差點被 commit。用 `npm run wt`。
