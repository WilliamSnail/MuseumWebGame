# 0018 一個帳號最多 3 位參觀者，同時在館裡，共用一間博物館

- 日期：2026-11-08
- 誰決定：翊文
- 狀態：有效（「新參觀者」「理智歸零」裡「從 3 位候選人挑」那一段被第 0028 篇取代：每一位都從 6 個職業選，再抽優缺點）

## 背景

- 原本一個人只有一位參觀者：理智歸零，下一位才進來（roguelike 的繼承，規劃第四節「參觀者一位接一位」）。
- 翊文 11-08：

  > 「首頁可以改成登入」
  >
  > 「玩家可以選擇和命名多個參觀者」

- 問了三種做法（同時好幾位共用博物館／一次一位／各自獨立的存檔），翊文選「同時好幾位，共用博物館」，最多 3 位。

## 決定

- **登入之後先選參觀者**，再進館。首頁的順序：登入 → 選參觀者（或新增一位、幫他取名字）→ 進館。
- **一個帳號最多 3 位**，同時都在。可以隨時換人（選單裡「換參觀者」）。
- **共用的（博物館的）**：收藏、解鎖的選項、靈感、升級、圖鑑、書、結局、展廳、信箱、每天的次數。
- **每位自己的**：名字、職業、技能、理智、心情、怪癖、佩佩神話、讀過哪幾本禁書、小優點和小缺點、正在走的地下。
- **每天的次數照帳號算**：換人不會多拿（不然開 3 位就是 3 倍）。
- **理智歸零**：那一位退休，掛上歷任參觀者牆；空出來的位子可以新增下一位（繼承照第 0016 篇／規劃第四節）。
- **合作時**：帶自己選的那一位下去；結果寫回那一位（就算玩家中途換了人）。

## 影響

（11-08 做好了，照實際做的寫；細節在 `維護日誌/2026/11-08_翊文_多位參觀者.md`。）

- **換人＝換欄位**（`shared/visitors.js`）：規則照舊讀 `P.sanity` 這些欄位（不用改幾百個地方）。
  - 現在在場的那位，欄位就在 `P` 上；不在場的收在 `P.visitors`，每位一包 `VISITOR_KEYS` 的欄位，另外帶 `cellarRun`（正在走的地下）、`dayVis`（今天掉了多少理智）。
  - 換人 `switchVisitor`：現在這位收進 `P.visitors`，要換的那位放出來。`test/visitors.test.cjs` 檢查換來換去完全一樣。
  - 「這一位的」（`VISITOR_KEYS`）：`vid`（編號）、`vname`（名字）、`slot`（第幾個位子）、`visitor`（第幾位）、理智、心情、佩佩神話、怪癖、發作、熄燈、職業、技能、優缺點、前一位留下的、這一位的統計 `visit`、還沒挑的候選人 `cands`、連續抱抱枕 `hugDays`、怪事的旁白 `oddSeen`。
  - 其他都是博物館的：收藏、解鎖、靈感、升級、圖鑑、書、結局、展廳、信箱、歷任參觀者牆、遺物櫃、每天的次數。
- **每天的次數照帳號算**：`P.day` 留在博物館，換人不會多拿。
  - `P.day` 裡算這一位理智的 `startSan`、`lost`、`quirkGiven`（一天掉超過 1/5 給怪癖）、`exLoss`（同一件展品一天最多掉多少）、`views`（看習慣了）跟著人走：換人時收進 `dayVis`（記日期），同一天換回來放回去，不同天照新的一天重算。
  - 理智歸零換下一位（`nextVisitor`）也一樣：只重算這幾個，每天的次數留著（以前整個 `P.day` 重來）。
- **第幾位參觀者**：每位自己記；新的號碼從博物館的 `P.visitorCount` 拿，三個位子不會重號。理智歸零在同一個位子換人，換新的號碼。
- 這一位做了幾隻、玩了幾分鐘，改成各記各的（`P.visit.made`、`P.visit.sec`）：`stats.made`、`activeSec` 是整間博物館的，輪流玩相減會算到別人的。
- **首頁**：登入之後是三個位子的卡片（`ui_screens1.js` 的 `visitorSlotsBox`）。上次玩的那位「繼續參觀」是主要按鈕；可以改名字；空位子「新參觀者」。
  - 「新參觀者」先取名字：整個帳號的第一位照舊選職業，之後在空位子加的從 3 位候選人挑（不用留遺物）。
  - 「新參觀者」不會再清掉博物館（原本的「再按壹次：整個重新開始」拿掉了）。
  - 選單的「換參觀者」回到這一頁。自由模式照舊在下面，沒有位子。
- **名字**是玩家打的字：`cleanName` 照暱稱的規矩（`server/store.js` 的 `cleanNick`：1–12 個字、不能有控制字元和看不見的字）。顯示一律用 `h()` 的字串（`textContent`），不用 `html:`。舊存檔沒有名字，畫面寫「第 N 位參觀者」，卡片上可以改。
- 理智歸零：照第 0016 篇留遺物、挑候選人，挑的時候多一格「取名字」（不填就叫「第 N 位參觀者」）。
- 館長室的名片、歷任參觀者牆寫名字；別的位子上的參觀者也在牆上，標「也在館裡」。
- 節奏：3 位輪流玩，理智歸零的壓力會變小。模擬（`test/sim.cjs`、`sim_san.cjs`）都只有一位，還沒有模擬三位輪流玩；必要時調理智或每天的次數。

## 什麼時候可以再討論

- 3 位不夠或太多的時候。
- 模擬或實際玩起來，發現換人可以繞過理智的壓力的時候。
