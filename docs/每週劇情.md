## 二、主線和每週的關係（翊文定了：「配合我們的主線延伸」）

- **主線**：地下收藏庫的大謎團，四週（一季）一個段落。主線的大方向由 Claude 寫、Yuga 改，事先排好（只有寫的人和審的人看得到，玩家看不到）。
- **每週**：主線往下延伸一段，用最近一兩週的新聞當靈感決定**這週發生什麼事**；不是跟主線無關的獨立小故事。
- **每天**：接著這週的劇情線往下（幾本書），週日收尾，留一個接下一週的線索。
- 新聞只決定這週的「事件」和氣氛，主線的大方向不跟著新聞改；沒有合適的新聞，就照主線原本的安排走（備用週，第四節）。
- **主旨和副劇情**（翊文 2026-11-09：「主線劇情的主旨還是要繼續下去，季節線跟每日也要像副劇情一樣，圍繞這主軸，即便有使用新聞來參考喔」，決定 0037）：

  - 新聞不能帶走主軸；每週的線、每天的書、季節線都是圍繞它的副劇情，碰到主線的東西（同一個帳、同一批人物或地方、同一個謎的另一面），但不揭曉主線的謎底、不搶主線的進度。
  - 帳本要記 `ties`：每週（`weeks.<週>.ties`）、季節線每章都寫碰到主線的哪一點。沒寫只警告，不擋（擋了會來不及上線）。

## 三、新聞怎麼當靈感（規矩）

- 每週一次，Claude 的排程上網查**台灣最近一兩週**熱門的事：熱門搜尋、幾家新聞網站的熱門、天氣、節日、展覽、流行的食物和話題。
- **選舉、政治話題、兩岸議題都可以用**，要轉成我們劇情的講法（翊文 2026-11-09：「新聞可以找最近台灣相關的，連選舉那種都可以，把找到的用我們劇情敘述的方法來呈現」「兩岸 的可以，這是我們喜歡的議題」，決定 0037）。
- **只取抽象的元素**：一種天氣、一樣東西、一種心情、一個現象。舉例（不是真的新聞）：
  - 颱風、豪雨 → 地下室淹水，展品漂走了
  - 某種排隊美食爆紅 → 地下冒出一個只賣那個的攤子（不寫店名）
  - 搶演唱會門票 → 展品們搶展台的位子
  - 選舉 → 館內的展品投票選館長（兩邊都有道理，看不出在挺誰）
  - 兩岸議題 → 隔著一道水閘的兩層展廳互相寄信，各說各的（一樣看不出在挺誰）
- **不准**：
  - 有人受傷、死亡的事故、災難、犯罪：不當題材，更不能開玩笑。
  - 真人、政黨、候選人、公司、品牌、商標、別人作品的名字。
  - 選邊站、嘲笑任何一邊：看不出在挺誰。
  - 健康、醫療的說法。
  - 抄新聞的文字：只用自己的話；新聞的連結只寫在靈感來源表和 PR 裡，**不進遊戲**。
  - 畫 Pepe 的樣子；跟仇恨符號扯上關係的東西（`docs/界線.md`）。
- 找不到合適的：用「常青」主題（跟新聞無關，見第四節的備用週）。
- 每份草稿附一張**靈感來源表**：哪則新聞（連結）、取了什麼元素、為什麼安全。審的人看這張就知道有沒有踩線。

- **話題日子**（翊文：「雙11購物節那種的也可以加入每日的安排」）：雙 11、情人節、萬聖節這種不在節日表裡、但大家會聊的日子，寫在帳本 `calendar`，每天的排程看到就融進今天，一樣圍繞主旨、不寫品牌。

## 九、書架要分類（劇情回顧放哪）（做了）

> 「讀書館的書也要有一些分類，不然都平鋪就會一直增加下去」（翊文 2026-11-09 00:37:25）

現在起源室只有兩排：「館藏」（佩佩起源考的章節、續集）和「禁書」。每週劇情一週一本、加上節日故事，一年會多五十幾本，平鋪會一直變長。

- **書架分成幾個頁籤**（草稿）：
  - 館藏：佩佩起源考、續集（照舊）。
  - 禁書（照舊）。
  - 主線：地下收藏庫的大謎團，一章一本。
  - 每週劇情：一週一本。
  - 節日：節日那週的故事。
- **合訂本**：每週劇情照「季」（4 週）收成一本合訂本，書架上只放這一季的幾本，舊的季變成一本「第 N 季合訂本」，點開再選哪一週。節日照年份收。

- 書架一排最多放的本數固定（例如 8 本），超過就分頁或收進合訂本，畫面不會被撐長，手機也一樣。
