# 0067 地下室改版：選路、打怪、預設都能合作

- 日期：2026-11-12 17:27:53
- 誰決定：翊文（要重新規劃、要有互動打怪物、預設都要能合作）；細節是 Claude 的預設，等翊文看
- 狀態：有效

## 背景

翊文：

> 「這兩個都先擱著一下，我要開發地下室探險的部分，我想徹底重新規劃一下，讓整個冒險更有趣，最好還有互動打怪物的部分，你幫我先規劃一下」
>
> 「預設都要能合作」

## 決定

翊文定的：

- 地下室探險徹底重新規劃，要更有趣，要有互動打怪物。
- **預設都要能合作**：每一種玩法一開始就是 1～4 人的版本。一個人下去＝一個人的隊伍，不是另一套玩法。規則只寫一份。
- 館友證和待辦卡的框、各房間的手機版先擱著，先做這個。

Claude 的預設（等翊文看，細節在 `docs/地下室改版規劃.md`）：

- 每層變成一張可以選路的小地圖：探索（現在的 20 間房）、遭遇、休息、寶箱和怪事、守門。選路用投票。
- 打怪物是回合制：怪物先亮出下一招，每個人各出一招（推、看穿、安撫、擋、招式、撤），一起結算。按時機的做法在合作時延遲不公平，所以不做。
- 帽子和姿勢的能力從自動觸發改成一場一次的招式。
- 這一趟拿到的東西先放背包，回地面才入帳；全隊倒下背包剩一半。
- 靈感總量不加（節奏本來就太快）。新獎勵是怪物圖鑑、材料、證據、少量籌碼。
- 怪物是收藏庫裡的東西成精，全部原創，不畫青蛙（決定 0005）。
- 合作的九個機制（決定 0036）都留著。
- 舊的地下室程式不刪，用 `NUM.ui.newCellar` 切換，比照決定 0066。

## 影響

- 單人的 `logic3.js` 地下室規則和合作的 `coop_flow.js` 之後要併成一套。
- 存檔只加欄位，`P.cellar` 現有的都保留。
- 決定 0036 還有效；「留守算不算走過這一層」改版時一起定。
