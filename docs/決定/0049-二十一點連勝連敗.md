# 0049 二十一點連勝連敗：連贏回心情、連輸掉理智

- 日期：2026-11-09 16:41:51
- 誰決定：翊文（要加）；怎麼算、數字是做的時候先定的，標「先照這樣」的等翊文看
- 狀態：有效

## 背景

翊文 11-09：

> 「21點連續贏會恢復一點心情，連續輸會降一點san值」

餐車吃東西已經會加心情、理智（決定 0040，`NUM.casino.foodCap`）。這次是打牌本身也會影響心情和理智。

## 決定

先照這樣（等翊文看）：

- **連贏 3 把心情 +2，連輸 3 把理智 -1**（`NUM.casino.streak`：`winN`、`mood`、`loseN`、`san`）。觸發後計數歸零重新算。
- **贏**＝贏、黑傑克、五張過關。**平手不中斷也不累積。**
- **每天上限**（台灣 05:00 換日）：心情最多 +6、理智最多 -3（`moodDay`、`sanDay`）。到了上限，計數照歸零，只是沒有效果、不出通知。連勝連敗的計數跨日不歸零，只有「今天加了、扣了多少」重算。
- **心情**照既有的上限 99（已經 99 就不加、也不佔今天的份）。
- **理智只直接扣，最低留 1**：不走 `applySan`。`applySan` 會把掉的理智記進「今天掉了多少」（`P.day.lost`），超過一定比例會觸發小缺點，理智用完還會熄燈（`P.dark`）。賭場的扣法不能把人弄到不能玩，所以不碰它：理智已經 1 以下（含熄燈）就不扣，也不佔今天的份。
- **自由模式**沒有理智規則，這裡也一樣：沒有效果，計數也不動。沒有存檔的（只有錢包）同樣不算。
- **只算單人 21 點。** 館友同桌先不接：同桌的結算可能發生在別人按的那一步或時間到的時候，那時只讀得到當事人的錢包，沒有讀他的存檔，要改交易的讀寫範圍，不是小改動。
- **伺服器算、寫在錢包**：`shared/casino_streak.js`，錢包多 `sk { day, win, lose, mood, san }`（舊錢包沒有，`casWalletFix` 補）。在 `casAfterMove` 裡，同一手只在第一次結算時算一次（沿用 `round.settled`、`seq`），心情、理智跟錢包在同一個交易寫進存檔（`deal`、`hit`、`stand` 都讀存檔），不看畫面傳來的任何值。
- **畫面**：結算後用 `note` 顯示，文字是博物館和賭場的口吻，不提錢、不鼓勵下注。狀態列隨存檔更新（`save_changed`，跟餐車一樣）。
  - 連贏：「手氣順了三把，心情好了壹點（心情 +2）」
  - 連輸：「連輸三把，手心冒汗（理智 -1）」
  - 牌桌頁面下面的規則多一句。
- 公告：`shared/notices.js` 的 `casino-streak`（館方公告、更新，2026-11-10 起）。
