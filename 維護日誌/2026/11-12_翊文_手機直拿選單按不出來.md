## 為什麼要改

> 「手機版直式的時候選單按不出來」
>
> 「不知道，好像在大廳就沒辦法」
>
> 「edge」

## 改了什麼

- 選單（#navDrawer）原本放在標題列（#nav）裡面。標題列有 sticky、模糊背景，有些瀏覽器會把裡面的 position: fixed 算成相對標題列，選單就被畫到螢幕外面，看起來像按不出來。現在手機直拿打開時，把選單搬到 <body> 最外層；關起來放回原位（轉成橫拿照原本的排法）；重畫標題列時把外層的舊選單拿掉，只會有一份。
- toggleMenu 原本要右上角的選單按鈕（.menu-btn）在才打得開；手機直拿那顆藏起來了。現在沒有它也打得開。
- 館方公告「手機直拿時「選單」按不出來的問題」。

## 怎麼確認的

- 本機用 Chrome 的手機模擬（375×812、觸控）：大廳、畫廊按底下的「選單」都打得開；修改後打開時選單在 body、位置在螢幕裡（64～700），關起來回到 #nav，只有一個 #navDrawer。
- npm test 全過、npm run build 成功。
- 沒驗證：翊文用的是手機 Edge，本機重現不出來（修改前在模擬器也打得開），這是照最可能的原因做的防範。上線後要請翊文用 Edge 再按一次。
