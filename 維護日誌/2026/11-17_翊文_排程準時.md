## 為什麼要改

翊文 11-17 問伺服器、排程還有什麼可以優化，選「1、2 都做」。查 11-15 起的 GitHub 紀錄：
1. 「館外股票每日資料」（stocks-daily.yml）從 11-14 起每天失敗：最後壹步在切到資料分支之後才跑，找不到 tools/stocks_fetch.cjs。它寫的 stocksDaily/latest 已經沒有程式在讀（股價改成伺服器盤中自己抓），等於每天白寫壹次正式資料、GitHub 每天寄失敗信。
2. GitHub 的定時晚很多：20:00 的 Discord 彙整 11-15 晚了約 6 小時（02:23 才發）、11-16 晚了 9.5 小時（隔天 05:32 才發）。

## 改了什麼

- 刪掉 stocks-daily.yml（tools/stocks_fetch.cjs、stocks_publish.cjs 留著，測試和手動還用得到）。
- 20:00 彙整改由伺服器排程發：functions/discord_digest.js 的 discordDigestTick（Cloud Scheduler，台灣 20:00），寫進 discordOutbox/digest-日期，由原本的 discordOutboxSend 發；同壹天只寫得進壹次。組字搬到 shared/discord_out.js 的 dcDigestText／dcDigestPost，tools/discord_digest.cjs 改用同壹份。discord-digest.yml 拿掉定時，只留手動。
- 固定動作、say 這些「按 GitHub 流程」的腳本：排隊超過 10 分鐘還沒開始就取消、重按壹次（tools/gh_lib.cjs 的 dispatch；11-17 有壹次排隊卡了壹小時）。
- GitHub 提醒 Node 20 要淘汰：actions/checkout、setup-node 從 v4 升到 v5。
