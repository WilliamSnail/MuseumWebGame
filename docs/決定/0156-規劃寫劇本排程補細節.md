# 0156 規劃寫劇本、排程補細節和時事

- 日期：2026-11-24 08:56:01
- 誰決定：翊文
- 狀態：有效（補第 0031 篇「每週劇情全自動」：深度由規劃的人定，排程不自己決定深度）

## 背景

11-24 翊文問每日排程寫的故事有沒有照規範、四問（恐懼、代價、佩佩、嚇人的展品）有沒有做到。查 W48 d1、d2：

- 格式、壹字、線索、新畫都照規範。
- 但四問只有欄位，內容停在「數字對不上」。佩佩那條會被認成蹲著的先生；代價只有壹句旁白；今日特展的理智寫成 1/1D4，成功也扣，不合「成功不扣」。
- 檢查只看「那天那個地方有沒有內容」，看不出深度。
- 時事慢：11-23 最大的股市新聞（顯卡大廠的老闆離開沒多久又回來）d2 沒用；靈感來源也沒記 d2 的新聞。

翊文：

> 「你做真正的規劃，有多深並確認不夠，排程每天只做細節補足，並結合時事」
>
> 「時事要結合的夠快，例如黃仁勳復職」
>
> 「劇情也要有壹點相關到，不只有財報」

## 決定

1. 深的那幾天由規劃的 session 先寫好劇本：帳本 `extend.weeks.<週>.script.dN`，有 `scene`（場景）、`must`（必寫句和放的地方）、`san`（理智檢定）、`free`（排程補什麼）。
2. 排程照劇本走：必寫句原樣放，理智照配；只補其他頁、台詞、畫、市場新聞、梗和時事。`day:check --strict` 查必寫句和理智有沒有放進去。
3. 時事每天都要：週二到週日，`靈感來源.md` 要有 `## dN` 那段，附新聞網址，加壹行「劇情：」寫放進哪本書、哪個任務或公佈欄；搜不到寫「搜不到：搜了什麼」。`day:check --strict` 擋。
4. 最大的那則新聞當天就用：市場新聞第壹則，劇情也碰壹句，接回這週的主軸。界線照決定 0048。
5. W48 d3～d7 先照這個寫好（恐懼 d3、佩佩 d4 和 d6、嚇人的展品 d5、代價 d7；d6 收過期的伏筆 f-backdoor）。cost 的理智改成 0/1D6（成功不扣）。
6. 之後的週，週一排週時由規劃的 session 寫劇本；沒有劇本的日子，排程照舊自己寫。
