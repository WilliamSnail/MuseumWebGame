# 0061 大廳的四塊收成一塊總覽，館友證放大廳

- 日期：2026-11-10 11:20:41
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「大廳的下一步、今天、簽到、本週地下收藏庫各佔一整行，太佔空間，館友證也不在大廳。」
>
> 「翊文要重要的事一眼看完。」

## 決定

- 大廳最上面只放一塊總覽：左邊小館友證，右邊下一步、今天的事（一件一格）、本週劇情。
- 格子跟「今天」清單用同一份資料，不另外存。
- 畫廊的今日特展也放一格，每天換的時候標「新」。
- 自由模式沒有每日的事，大廳照舊排。
- 參考一般遊戲主畫面的做法：玩家名片、任務追蹤、一排帶數字的小格。沒有另外上網查。

## 之後

- 介面整合第 3、4 步（賭場首頁、導覽列變短）還沒做。
