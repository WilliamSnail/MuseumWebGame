# 0055 線索和看懂

- 日期：2026-11-10 00:06:12
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「要往神秘角度（但要留提示），看懂會說你看懂了什麼，然後逐漸拓展世界觀，埋伏筆。最後收線回來」

## 決定

1. 擴充起源室原本的《看懂的事》，不另做壹本書。
2. 每週內容的書、房間、今日特展的畫可以帶 clue；壹組線索集齊，跳「你看懂了」，記進《看懂的事》，不扣理智、不發作。
3. 拿線索不提示；拿到部分才說還差幾條和 hint；壹條都沒拿到不顯示。
4. 拿不到的線索（過了那週沒找到的房間、沒看的畫）不卡；沒看懂也不影響主線。
5. 賭場和每日任務先不接。
6. 謎底只放帳本，不進遊戲、日誌、PR。
