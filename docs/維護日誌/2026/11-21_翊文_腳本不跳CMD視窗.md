## 為什麼要改

> 「話說你執行的 Command line 為什麼我的 Windows CMD 視窗會跳出來一下再不見。我以為我不會看到才對」

AI 在背景跑（沒有自己的視窗），腳本用 child_process 叫 git、gh、npm、firebase 時，沒傳 `windowsHide: true`，Windows 就替每個子程式開壹個主控台視窗，跑完就關。tools/ 有約 100 處開外部程式，只有 1 處有設。

## 改了什麼

- 新的 `tools/dev/child.cjs`：跟 child_process 同樣的 spawn、spawnSync、exec、execSync、execFile、execFileSync、fork，預設 `windowsHide: true`（呼叫的人自己寫 false 可以蓋掉）。
- tools/、test/ 裡 35 個檔的 `require("child_process")` 全改成這支（只換 require，呼叫的地方沒動）。
- code_rules 第 7 項：tools/、test/ 直接 require／import child_process 就擋（註解行不算）；配測試。
- AGENTS.md「其他」那條重複的 replace 規矩換成這條。

## 怎麼確認的

- npm test 全過。

## 還沒做、要注意

- 沒測：實際看視窗還閃不閃（要人看）。Claude Code、npm 自己開的子程式不歸這裡管，可能還會偶爾閃。
