# 0117 外面世界擴到約 1,000 億、每天成長照 GDP 年增率

- 日期：2026-11-17 13:30:00
- 誰決定：翊文（建議見 `.claude/交接/外面世界擴到千億建議.md`；公式選「不夾上限」）
- 狀態：有效

## 決定
1. **一次性擴充**：`NUM.casino.world.expand` ＝ 900 億（池子約 110.6 億 → 約 1,010 億）。每個莊家文件只做一次（`house.wExp` 記），新來源 `mint.worldExpand`（憑空）；帳上分類（`wu`）照權重分（`wuGrow`），總和仍等於池子。對帳差仍 0（憑空多少、總和多多少）。
2. **`world.start` 不改（100 億）**：它是對帳起始和吃緊門檻（低於 start 的 10%＝10 億）；改了會讓補助、賣出上限等「占起始 %」的規則一起變。
3. **每天成長**（`growYoy: true`）＝ `max(growBase 500 萬, 池子 × max(0, yoy%) ÷ 365)`，yoy ＝ `content/economy.json` 的 gdp.yoy（現在 14.36%）。**不夾上限、不再乘景氣 b**（yoy 已經是景氣；b 仍用在分給哪個集團）。1,010 億時約每天 3.97 億；10 億以下時 ≈ 下限。
4. 成長只進外面世界，不進玩家。**其他金額不動**（門票、大禮包、借款…）；NPC 和散客花多少由自己的預算和 dayCap 決定，池子大小只用來擋「集團錢不夠」。
5. 說明：日報「跟外面世界的往來」加註一次性擴充和每天成長；銀行「全館的帳」外面世界那列加說明；`books_sign_check`、`econ:check` 跟著改。

## 資料怎麼來
`functions/casino.js` 日報產生時把 yoy 寫進 `house.econ.yoy`（和 `doc.ext.yoy`），下一次換日用；沒有或過期就是 0，用 growBase。
