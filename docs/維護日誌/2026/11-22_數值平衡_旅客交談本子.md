# 交談紀錄加旅客的本子

## 為什麼要改
翊文選了旅客的交談另開壹本（每位旅客最多 20 句、不顯示總句數、串門子兩人的本子都顯示）。

## 改了什麼
`casinoNpcLog/{uid}` 多一個 `t`（旅客 id → 句子）：`heard` 的 `id` 可以是交代人或旅客（`v-`、`c-` 開頭，`t-` 劇情角色不收）；每位旅客最多 20 句、最多 80 本；`log` 多回 `travelers`。`NUM.npcRel` 加 `logMaxTraveler`、`logTravelers`。

## 怎麼確認的
