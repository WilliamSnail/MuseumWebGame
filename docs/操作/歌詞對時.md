# 深夜大廳歌詞：對時

> 歌：`web/public/sfx/lobby-night.mp3`（約 137 秒，23:30～05:00 在大廳放）。歌詞和時間軸：`content/lyrics/lobby-night.json`。
> 11-21 的時間軸是用音量起伏估的，**還沒人聽過**。用這個工具按空白鍵校。

## 對時

1. `npm run dev`
2. 開 `http://localhost:5173/?lyrics-tap#lobby`（要用耳機或喇叭聽；工具自己放歌，不受遊戲靜音影響）
3. 右上角的小視窗按「開始播」。每句歌詞**開始唱的那壹刻**按空白鍵；亮著的那行是下壹句。
4. 按錯：Backspace 退回壹句；R 從頭來；Enter 提早結束。
5. 按完最後壹句會印出新的 `lines`（視窗下面的框，也在瀏覽器主控台），按「複製」，貼回 `content/lyrics/lobby-night.json` 的 `lines`。
6. 沒有字的 `gap` 不用按，它的時間會跟著前壹句平移；要自己調就直接改 json。

## 在大廳看字幕

- 字幕只在「深夜曲真的在放、有聲音」時出現（`fx_sound.js` 的 `nightPos()` 回秒數；靜音、換了曲子都是 null）。
- 想不等到 23:30 看：開 `npm run dev`，在主控台跑 `UI`-外的方法不好找；最簡單是暫時把 `web/src/core/audio_state.js` 的 `lobbyNight` 改成回傳 true（別 commit）。
- 每句最長顯示 6 秒；json 的 `end` 可以指定結束秒數；`kind: "whisper"` 是耳語（小字、偏右）。
