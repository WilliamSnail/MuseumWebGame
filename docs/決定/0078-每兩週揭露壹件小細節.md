# 0078 每兩週揭露壹件小細節

- 日期：2026-11-14 10:09:01
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「劇情規劃每兩週要揭露一些些更細節的事情，規劃一下」
>
> 「照這樣排（建議）」
>
> 「可以再具體」
>
> 「揭露週另外發一則「館裡有些不一樣了」」

## 決定

1. 2026-W47 起，每隔壹週是揭露週（W47、W49、W51、W53、2027-W02……W42），共 23 次小揭露；季末（W50、2027-W04、W17、W30、W43）仍是大揭曉。
2. 每次只多露出壹件具體、可驗證的細節；偶爾可以給稱呼或壹點原因，但不給謎底、不寫總數、劇情角色不露臉。
3. 揭露週當天，今日館訊後面自動多發壹則「館裡有些不一樣了」，不劇透。
4. 個人化的線索先不做。
5. 帳本 revealBeats 是排程的依據，`npm test` 會檢查格式。

詳細看 `docs/劇情揭露節奏.md`。
