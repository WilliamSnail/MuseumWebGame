# 0082 新玩家的起始籌碼由文化部補助（從外面世界搬，不再憑空）

- 日期：2026-11-15 01:10:00
- 誰決定：翊文（「改成是從文化部補助的，文化部將來也是世界經濟體系裡的其中一個公司」「也是博物館要還債的對象」）
- 狀態：有效

## 決定

1. **新玩家的起始籌碼（`NUM.casino.startChips`，現在 1,000 萬）不再憑空給**：新錢包帶 `led.cult = 1` 的記號，第壹次碰到莊家時（`functions/casino.js` 的交易開頭，`casCultureFund`），把錢包帳上「憑空的 mint.start」改記成外面世界池子出的：池子 −起始籌碼、憑空 −起始籌碼、錢包籌碼不變，總量不變、對帳差 0。來源叫 `cultureStart`（日報寫「文化部補助（新玩家的起始籌碼）」）。
2. **舊錢包不動**：沒有記號的錢包，`mint.start` 的歷史照舊（翊文沒要改）。
3. **上限**：`NUM.casino.culture.maxPlayers`（300 位）。補助到這個人數後，新玩家的起始籌碼還是記憑空，池子不會被補光；`econ:check` 檢查「起始籌碼 × 人數上限 ≤ 池子起始的 40%」（現在 3%）。池子吃緊（低於起始的 10%）時，只補今天付得出的部分，剩下的還是記憑空。
4. **文化部同時是館債債主**：名字、日報、財報上，「文化部補助」（外面世界 → 玩家）和「文化部館債」（外面世界 → 莊家，要還）都歸在「文化部」底下，之後「NPC 的館外公司」（`docs/未來更新.md`、`docs/幣值規劃.md` 第 8.6 節）可以把文化部當成第壹個公司接上。這次不做公司系統，只留名字：`NUM.casino.culture.name`。
5. **補助不算館債**（翊文 11-15：「不用算進館債」）：文化部補助新玩家的錢，就是外面世界（文化部）撥給玩家的錢，博物館不用還，不加進文化部館債。

## 理由

- 外面世界已經有池子和帳，新玩家的錢也該是「搬」不是「印」，守恆好驗證。
- 用「改記帳」而不是在建立錢包時直接搬：建立錢包的路徑很多（不是每條都有莊家），改記帳讓錢包的籌碼和使用者看到的壹模壹樣，只有帳的來源不同。
