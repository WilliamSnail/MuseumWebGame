# 0139 「海外科技集團」改名「跨海科技集團」

- 日期：2026-11-20
- 誰決定：翊文（11-20，Yuga 轉達）：「海外」現在是真實市場的帳（決定 0126），玩家會把「海外科技集團」和「海外」搞混；改名「跨海科技集團」，跟「島上科技集團」成對
- 狀態：已決定，做完

## 決定
1. 只改**顯示的名字**：`content/world/units/g-overseas.json` 的 `name`（海外科技集團 → 跨海科技集團）、`note`（海外的 → 跨海的）；景氣市場 `content/world/markets/overseas.json` 的 `name`（海外 → 跨海）、`note`。id（`g-overseas`、`overseas`）、錢、股票（6 支）、集團股 id、帳本一律不動。
2. 打包檔（`shared/world_roster.js`、`shared/world_markets.js`）用 `tools/world_pack.cjs`、`tools/market_pack.cjs` 重產。集團股名稱、財報、金流圖、日報、新聞的名字都是從單位名稱讀的，自動跟著變；銀行畫面的示範資料（`web/src/ui_bank.js`）的「海外集團」也改成「跨海集團」。
3. **沒改**：寫「海外」指真實市場帳的地方（金流圖的「海外」節點、日報「跟海外的往來」「海外的景氣」、「館方投資海外」等）；已發的館方公告、維護日誌、決定紀錄、`docs/` 裡舊的說明（歷史不改）；劇情帳本的 truth。
4. 館方公告壹則；`test/cross_sea_name.test.cjs` 擋舊名字（`web/src`、`shared`、`content/world`、`content/npc` 不能再有「海外科技」「海外集團」）。
