# 介面素材（先存起來，還沒接進遊戲）

- `panel-wide.png`：橫向的鎏金面板框，1024x254，酒紅天鵝絨中間是空的，綠底已去掉。`_panel-wide-src.png` 是原圖。
- 用法：適合大廳的標題橫幅、活動預告條、大按鈕底板。
- 能不能拉伸：左右兩端是尖角和渦卷花紋，上下中間各有壹個裝飾。要拉長時，**兩端和中間的裝飾不能跟著拉**，要切成「左端、中間（可重複或拉長）、右端」三段（三切片），不是九宮格。
- 授權要翊文確認；不要放 Pepe the Frog 的樣子（決定 0005）。
- 不在 `web/` 底下，不會進 `dist/`。
