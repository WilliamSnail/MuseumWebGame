# 0060 每日任務可以補做，綜合獎勵只給當天做完的

- 日期：2026-11-10 11:03:02
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「好可以補，這樣才能解開之前的書本，劇情才能跟得上，但是每週都每天都有完成的綜合獎勵只有每天都解的人才能拿」

## 決定

1. 同一週裡，前幾天沒做的每日任務可以補做。上一週的不能補。
2. 補做的任務，單一任務的獎勵照領；靠任務解開的書照樣解開。
3. 「3 個都做完多一份」只給 3 個都在當天做完的。
4. 每週任務「每日任務全部做完 N 天」只算當天做完的天。
5. 這週前幾天的特展畫每天都看得到（今日特展下面），只能看、不給靈感。
6. 第 3、4 點的開關是 `NUM.story.lateBonus`，預設 false。

## 取代

`docs/每週劇情.md` 原本寫「每日任務只有當天」「畫展只有當天」，改成上面這樣。

## 還沒決定

- 第 3 點是 AI 照「綜合獎勵只有每天都解的人才能拿」解讀的；翊文如果只是指每週那一份，把開關拆成兩個就可以。
