## 為什麼要改

> 「GitHub 通知 Actions 分鐘用到 90%（1,800／2,000）。11-01 起的紀錄：Deploy（合併到 main）275 次約 866 分、CI（PR）312 次約 476 分、CI（合併到 main）275 次約 418 分。」
>
> 「合併到 main 時 CI 和 deploy.yml 都跑同壹套測試，等於測兩次。翊文 11-13：「好啊」（同意拿掉合併後 CI 重跑）」
>
> 「翊文 11-13 同意把 repo 改成公開（公開 repo 的 Actions 不限分鐘）；公開前掃過歷史：沒有私鑰、token、.env、玩家資料；commit 作者欄的 Gmail 會公開，翊文說「沒問題」。」

## 改了什麼

- ci.yml 拿掉 push: main，只在 PR 跑。合併到 main 後的測試由 deploy.yml 的 test 工作負責（沒過就不部署，跟以前壹樣）。
- repo 改成公開（gh repo edit --visibility public，翊文 11-13 同意）。

## 怎麼確認的

- tools/ship.cjs 合併後只看 deploy.yml 的那壹次，不看 CI 的 push，不受影響。

## 還沒做、要注意

- PR 太多、main 常常先被別的 PR 合併，要重新併 main 再跑壹次 CI：之後各 session 把小改動併成壹個 PR。

## 給下一個人

- 不要把 push: main 加回 ci.yml：deploy.yml 已經會先測。
