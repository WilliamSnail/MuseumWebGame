# 0073 參觀者門票三分，莊家改成投資而不是繳稅

- 日期：2026-11-13 15:01:51
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「翊文 11-13：門票進館方自己的帳，和預算池分開，專門給修繕、捐款對口、預算公投用；一部分進預算池，一部分分紅給展廳主。」
>
> 「翊文 11-13：莊家不要門檻稅，莊家自己也可以投資，投資的標的其他玩家也都看得到；跟玩法 4（館內股票）合併。」

## 決定

1. 展廳參觀者付門票，門票是館外的錢（記為憑空），分三份：展廳主分紅（進錢包）、預算池、館方帳（`house.museum`）。比例先 30／20／50，每人每天最多 20 位，等翊文調。
2. 伺服器認領：瀏覽器報來了幾位，伺服器用存檔算評分和上限。
3. 莊家稅（超過 2 億的部分繳一成）不做。改成莊家投資，投資的標的公開，其他玩家也可以跟著投；和玩法 4（館內股票）合併，另外寫計畫，守恆要先設計。
4. 預算凍結（預算池 ≤ 0 時拚經濟只撥兩成）先做，已上線（PR 241）。
