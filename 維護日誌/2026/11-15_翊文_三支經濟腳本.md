## 為什麼要改

翊文 11-15：「三支都做」。改價格時要看哪些價格受影響、哪些文字裡寫死的金額要跟著改、還要能壹鍵拿正式站的帳面。

## 改了什麼

- `npm run econ:prices`：從 NUM、餐車、大禮包印出玩家看得到的價格和上限（名字、值、路徑）；`--md` 印表格、`--json`。路徑找不到會報錯，不會默默跳過。
- `npm run econ:scan`：掃 `shared/`、`web/src/`、`content/` 文字裡的金額，對不上 NUM 的列出檔名:行；×40 或 ÷40 剛好對得上的標「像舊量級」。白名單在 `tools/econ_scan_allow.json`（舊公告、假資料、毫秒）。`--all`、`--strict`。
- `npm run econ:status -- --yes`：按固定動作 econ-status（只讀）→ 存 log → 交給 `econ_check --ledger`。沒有 `--yes` 不會跑；金鑰不經過 AI。

## 怎麼確認的

- 新測試 `test/econ_scripts.test.cjs`（價格表、金額解析、掃描、白名單、log 擷取、沒有 --yes 不跑）。

## 還沒做、要注意

- 掃描只看字串裡的金額；寫成 `1e6` 或算式的看不到。純數字（沒有逗號、沒有萬）要整行有跟錢有關的字才算。
- `econ:status` 要翊文同意；log 被 GitHub 遮成 `***` 時 `econ_check` 會報。

## 給下一個人

改 NUM 的路徑時要同步改 `tools/econ_prices.cjs` 的 GROUPS，不然 `npm run econ:prices` 會報「找不到」。
