# 打怪的玩法（規劃）

> 2026-11-12，Claude 寫。翊文 11-12：「地下戰鬥再更多規劃一下」「好，從個性開始」「另外佩佩可以用的機制也要更多一點」「要考慮各種補如可以當buff當坦之類的合作玩家，規劃一下」「好，先做規則」。
> 規則在 `shared/cellar_fight.js`（數字 `shared/config.js` 的 `NUM.fight`、`CELLAR_FOES`）；演出在 `docs/打怪演出規劃.md`。

## 一、現在的問題

- 怪物只有四種招（撲、嚇、全體、回壓力），15 隻差在數字，打起來都差不多。
- 佩佩身上只有帽子、姿勢有用（一場一次的招式）；顏色、完美、怎麼湊隊伍幾乎沒差。
- 合作只有「擋在隊友前面」，沒有坦、輔助、治療這種分工。

## 二、每隻怪物一個個性（`CELLAR_FOES[].trait`）

九種，可以重複用（每天的排程做新怪物時也能選）：

| kind | 名字 | 規則 |
|---|---|---|
| shell | 殼很硬 | 沒看穿之前，推只剩 shellMult（0.65）|
| thick | 很硬 | 每回合第一下推少 n |
| slippery | 看不出弱點 | 看穿的成功率 −mod |
| stubborn | 很固執 | 安撫的成功率 −mod |
| grow | 越來越多 | 每 every 回合自己多 n 壓力（招式以外） |
| steal | 會拿東西 | 每 every 回合拿走一個人還沒用的招式 |
| mark | 會記帳 | 把一個人寫進帳裡，every 回合後重重打他（理智 san）；安撫成功可以塗掉 |
| veil | 蓋著布 | 下一招只看得到要對誰，看不到是哪一種 |
| blur | 看不清楚 | 前 n 回合完全看不到下一招 |

分配：紙箱 shell、失物 steal、多出壹箱 grow、白布 veil、空白名牌 slippery、石像 thick、影子 stubborn、沒簽名的畫 grow、不肯回框 thick、泡爛的帳頁 slippery、算盤珠 grow、帳本 mark、排隊的 blur、差壹點的 veil、門前的那壹個 blur。

## 三、佩佩身上的每一項都有用

- **心情**：剋怪物的心情時強度加倍（`memberPower` 本來就有算），畫面上寫「剋牠」。
- **顏色**（帶的佩佩裡有幾隻那個顏色，就算幾份）：紅 推 +1；綠 每回合結束理智 +1；黃 看穿、安撫 +10%；黑 被嚇時少扣 1。
- **完美**：那隻佩佩的帽子、姿勢招式可以用兩次。
- **隊伍組合**：全隊（含館方助手）有兩隻以上同顏色，那個顏色的效果全隊都有；四種心情湊到三種，全隊推 +1。

## 四、合作分工：五個新行動

| 角色 | 行動 | 效果 |
|---|---|---|
| 坦 | 引開（taunt） | 牠這回合的「點一個人」改打我；我這回合算有擋 |
| 輔助 | 鼓舞（inspire，指定隊友） | 那個人這回合推 +3 |
| 輔助 | 分膽（share，指定隊友） | 把我的膽量分一半給他 |
| 治療 | 安慰（comfort，指定隊友） | 他理智回 1D3＋（說服 ÷ 30） |
| 偵查 | 看清（reveal） | 偵查檢定：成功就看得到被布蓋住、看不清楚的下一招（這回合和下一回合） |

- **你適合**：開打時照每個人帶的佩佩和職業算出 1～2 個角色，寫在座位上（例如黑色、斯拉夫蹲、棒球帽、抱枕職人 → 坦）。
- **館方助手補位**：隊伍裡沒有人適合坦、而牠下一招要打人時，助手引開；不然助手推。
- 一個人也能打：上面這些一個人用也有意義（看清、引開給助手擋）。

## 五、分幾個 PR

1. 規則：個性、佩佩效果、新行動、你適合、助手補位（這一份）。跑 `node test/sim_fight.cjs` 看 1～4 人的勝率。
2. 畫面節奏（`docs/打怪演出規劃.md` 第七節）：回合軌道、亮招的紅線、按鈕滑上來和鎖定、順序列表、鏡頭拉近、聲音。
3. 開打、打完的演出和登記卡。
4. 之後：理智低看到假的下一招、怪物圖鑑、職業特色、樓層環境、掉落。

素材：新行動 5 個按鈕圖示、角色 5 個小徽章（做成 prompt 網頁給翊文）。
