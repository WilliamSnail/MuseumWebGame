- 日期：2026-11-09 00:25:30
- 誰決定：翊文（「好，接下來日期就照實際日期和時間秒數」；問「是指哪一個」，選「日誌和紀錄」）

## 背景

- 維護日誌、決定紀錄原本只寫日期（2026-11-08）。
- 11-08 晚上過了半夜 12 點寫的日誌還是寫 11-08，看不出真的是什麼時候寫的；同一天好幾篇也看不出先後。

## 決定

- **維護日誌**的「日期」、**決定紀錄**的「日期」、Claude 的紀錄檔（`../_AI_Note/yu program_Claude紀錄.md`）新的條目，都照**真的台灣時間寫到秒**，例如 `2026-11-09 00:25:13`。
- 寫的時候用 `npm run now` 印出現在的台灣時間（不管電腦設在哪個時區）。
- 過了半夜 12 點就是隔天：日誌的檔名（`月-日_作者_主題.md`）跟著真的日期。
- 2026-11-09 以前的舊日誌、舊決定只有日期，不用補。2026-11-09 起的日誌沒寫到秒，檢查（`tools/log_lib.cjs`）會擋。
- commit 本來就記到秒，不用另外寫。
- 版本號（`version.json`，2026.11.08-1）照舊。

- 遊戲裡的時間（換日、每週活動、怪癖倒數）照網路上的真實時間，不照玩家電腦：翊文另外說「遊戲裡的內容也是跟著那網路抓取的真實時間時間」，寫在 0026（真實的一天）。
