# 玩家中心規劃

翊文 11-09：「財產合成就可能要不只在賭場可以看到比較好，可能之後要有一個整個遊戲的玩家使用者中心看各種東西」。

**狀態：只有規劃，還沒動工。** 順序排在 Discord 聯動第二、三步之後，「追加預算」小遊戲之前，這樣小遊戲的戰績可以直接放進來。

**11-10 定了名字（決定 0058）：** 入口叫「館友證」，裡面的收藏本叫「典藏冊」。下面表格是 11-09 的草稿，分頁動工時照 `docs/介面整合規劃.md` 第 2 步重排。

## 怎麼做

把現在的「我的帳號」擴充成「玩家中心」，不另外蓋新畫面。從右上角選單進去。

| 分頁 | 內容 |
|---|---|
| 總覽 | 暱稱、戴的稱號、籌碼、週章、今天的進度 |
| 成就 | 賭場的成就，之後也放其他玩法的；可以在這裡戴稱號 |
| 財產 | 紀念品；可以在這裡掛到展廳 |
| 紀錄 | 累計數字，例如收藏數、地下走多深、21 點勝負、拚經濟和斗內的戰績 |
| 設定 | 現有的暱稱、隱身、上線提示、Discord 綁定、登出 |

## 要注意

- 賭場裡的成就和財產頁籤留著，兩邊看同一份資料，不寫第二套。
- 資料都在伺服器上，主要是把畫面整合起來。
- 自由模式、沒進過賭場的人也要能開。
- 手機橫向要排得下。

## 動工時再定

- 館友小卡要不要加「看他的成就」，哪些能公開。理智、怪癖、靈感預設不給別人看。
