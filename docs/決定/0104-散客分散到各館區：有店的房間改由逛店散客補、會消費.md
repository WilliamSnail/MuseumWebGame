# 0104 散客分散到各館區：有店的房間改由逛店散客補、會消費

- 日期：2026-11-16 19:00:00
- 誰決定：翊文（「讓旅客和散客不要那麼集中在展廳，這樣他們也才能到其他館區消費」）；做法 Yuga 同意
- 狀態：有效（補充決定 0095、0102）

## 決定

不讓「看展的散客順路逛」的組去店裡花錢（那組的類型跟氣氛綁，算進館內股「到店的人」會跟畫面對不上），改成：

1. `crowd.wander.rooms`：賭場（casino）、手作坊（workshop）、委託櫃台（commission）、地下收藏庫（cellar）的權重設 0（看展的散客不再逛到有店的房間；其他房間不變）。
2. 有店的房間由「逛店散客」補：`crowd.shop.perStore` 6 → **72**（每店每天平均 72 位）、`stay` 30～120 → **60～240 分鐘**、`spend` 4,000 → **800**、`dayCap` 600,000 不變。他們付錢（餐車、牌桌進莊家，其餘進預算池）、算進館內股的人數（跟原本壹樣）。
3. `stockIn.npcBase`（NPC、散客的保底人數上限）12 → **120**：不然 72 位逛店散客會被上限壓到 12，館內股變得不會動。
4. `econ:check`：每店逛店位數 ≤ `npcBase` × 75%（原 ÷2）。

## 模擬

- 房間平均人數（14 天、5:00～23:00）：翊文要「不低於改之前」（賭場 8.2、手作坊 8.8、委託 4.4、地下 2.7，之前是看展散客逛過去的、不花錢）。新數字（72 位、停留 60～240 分鐘、每位花 800）：賭場約 21、手作坊約 10、委託約 9、地下約 9（都 ≥ 之前；賭場有餐車和牌桌兩家所以最多）；展廳不變。
- 逛店消費：平均每天 123,000 → 約 280,000（每位花得少、人多；+ 約 16 萬，外面世界搬給莊家和預算池；全館逛店上限 600,000 不變）。
- 館內股（館友 0、3 位）：安靜日 0%、平均跳空約 0.9%（原本 1.1%）、上限 5% 不變。卡位模擬（`test/sim_peek_stock.cjs`）看人數每家店每天 0.000%（成本 1.04%），沒有變好賺。
