## 改了什麼

- 新增 tools/check/ui_check.cjs（npm run ui:check）：自己起 dev server（port 5499，結束關掉；也可以 --url 接已經開著的）、用無頭 Edge／Chrome 打開 20 個畫面的 #畫面 假資料（自動靜音），各用手機 375×740（觸控、DPR 2）和電腦 2140×1440。
- 報三種問題：(1) 超出視窗的元素（右邊 > 視窗寬或左邊 < 0，外面沒有可橫向捲動的容器接住；只報源頭，不報跟著超出的子孫；頁面出現橫向捲軸也報）。(2) 按鈕被切（可見寬或高 < 實際的 80%；被 overflow:hidden 的容器切掉、被視窗左右切掉；放在可以捲動的容器裡的不算；新聞跑馬燈 .l2-hl 不算）。(3) 字變直排（壹段文字 ≥3 個字、排成 ≥3 行、平均壹行 ≤1.3 個字，只看按鈕和標題）。
- 要登入才有的畫面（賭場、餐車、銀行）列為「跳過」，不算失敗；有問題 exit 1。選項：--screens、--sizes、--shots 資料夾（每個畫面存 PNG）、--js（先在頁面跑壹段）、--wait、--json、--url。
- 手機寬度用我們設的 375，不用 innerWidth：手機模擬時內容壹超出，瀏覽器會把 innerWidth 撐大，用它量就看不到超出。
- AGENTS.md 加「改了畫面，上線前一定要跑 npm run ui:check」；tools/README.md 加壹行；test/tools/ui_check.test.cjs（不開瀏覽器：畫面清單、量測程式語法、報告整理、AGENTS.md 有寫）進 npm test。沒放進 npm test 的瀏覽器部分和 CI（要瀏覽器、跑壹輪約 4 分鐘）。
