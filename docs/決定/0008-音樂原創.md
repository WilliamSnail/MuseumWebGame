# 0008 音樂、聲音都自己寫，不用現成的歌

- 日期：2026-11-08
- 誰決定：Claude 做聲音時定的做法，寫進第 3 版的說明.md；第 4 版規劃列為「照舊」
- 狀態：有效

## 背景

- 11-08 翊文陸續要了很多音樂，例如：

  > 「大廳也可以有音樂嗎」
  >
  > 「抱枕區音樂也要」
  >
  > 「手作坊 的音樂聽不太到，可以換一首嗎」
  >
  > 「能不能做一個遊戲預告片，30秒左右，要像真正的遊戲預告片那樣介紹，並且有宏大配樂」

- 每一段都是 Claude 自己寫的旋律、和弦、節奏，用 Web Audio 即時合成，沒有音效檔。
- 紀錄裡找不到翊文特別說「不要用現成的歌」的原話。這條是為了版權，Claude 從一開始就這樣做，第 3 版的 `說明.md` 寫成「以後也不要放現成的歌」，第 4 版的規劃.md 把它列在「照舊」的界線裡。

## 決定

- 遊戲裡的音樂、節奏、音效都自己寫、自己合成。
- 不放現成的歌、不放下載來的音效檔、不照著有名的曲子改寫。
  - 例如大廳的門廳音樂「為了不像卡農，和弦沒有用卡農那串」（紀錄）。

## 影響

- `web/src/fx.js` 的 `FX.sound`：一次性的聲音在 `R`，環境音在 `AMB`（`docs/架構.md` 聲音引擎那一節）。
- 加新聲音照架構.md 的步驟：寫進 `R` 或 `AMB` → 用 `FX.sound.analyze` 量大小 → 設定頁加試聽。
- AI 聽不到聲音，只能量；好不好聽要翊文、Yuga 聽了才知道，日誌要寫「還沒人聽過」。

## 什麼時候可以再討論

- 不再討論。每一版都守這條（`docs/界線.md`）。
