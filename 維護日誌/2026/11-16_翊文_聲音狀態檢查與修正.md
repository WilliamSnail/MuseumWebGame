# 聲音狀態徹底檢查：離開房間、登出時聲音要收乾淨，並寫了檢查腳本

## 為什麼要改
翊文：「各個被理智嚇退出房間的，好像原本在房間裡的音效不會停」，接著說「徹底檢查，然後寫好需要的腳本」。地下的那壹個已經在 11-16_離開地下收掉地下聲音 修掉；這次把「離開房間／被嚇退／昏倒／逃跑／發作／關框／換參觀者／登出」每條路的聲音狀態都讀過壹遍，並把能自動檢查的寫成腳本，以後改聲音時不用再靠人讀。

## 改了什麼
- **修正：登出（或登入過期）時，蓋在畫面上的賭場框、合作框是被直接 remove 的**（ui_login.js），框自己的關閉函式沒跑。結果 UI.ambOver 還是 "casino"、每 30 秒重算的 UI.ambTimer 還在跑、合作的 UI.cellarSnd 也沒清；再登入進大廳會聽到賭場那首（或地下的聲音），而且沒有框。現在登出時照 nbClose 的正常方式關，並保險地 setAmbOver(null)、setCellarSnd(null)。
- 同樣的寫法還有 ui_signin.js 簽到面板的「去畫廊看」按鈕，也改成走 nbClose。
- 新增 web/src/audio_state.js 的 ambFor()：把 audioState() 裡「現在該放哪首環境音、要告訴它什麼 ambMix」抽成純函式（不碰畫面、不碰 fx.js）。audioState() 改成呼叫它，玩家聽到的行為不變。AMB_OF 仍留在 ui_core.js（fx_report 從那裡掃）。
- 新增 tools/snd_check.cjs（npm run snd:check）：靜態檢查，詳見下面。
- 新增 test/snd_check.test.cjs（13 項，加進 test/run_all.cjs）。

### 檢查結果（其他路徑讀過、沒有問題）
- 離開房間（navTo／go）：換 AMB_OF 的名字，fx.js sync() 會 ambNow.stop()：停 timers、g 淡出 1.2 秒、1.4 秒後 disconnect 並停 nodes。所有 AMB.* 的 every／songCycle／creepyHook 都進 timers、fileLoop 都進 nodes、fileOnce／fileLoop 都接在房間的 g（17 個環境音逐壹檢查過）。即使整首曲子（songCycle）或延遲的 setTimeout 之後才響，因為接在已斷線的 g 上也聽不到。
- 被嚇退（sanFlow 的 backout，ui_screens1.js 三處、ui_story.js 壹處）、昏倒、逃跑（boutFlow）：都是 go("lobby")，沒有別的聲音狀態。地下的靠上次的修正；圖書館禁書頁籤的緊張音樂跟 UI.params.tab 走，go 換參數就換回去。
- 賭場框開著被嚇退：框是蓋在畫面上的，不會因為 go() 關掉，賭場音樂照放（框還看得到，是壹致的）；框關掉時 setAmbOver(null) 會清計時器。單人賭場開同桌框時會自己重接。
- 換參觀者、讀伺服器存檔（useProfile）：audioState 每次都從 P 重算，沒有殘留。
- 心跳、不安低鳴、耳鳴：sync() 關得掉；理智歸零（dark）的 zero 鼓聲由 ambFor 決定。

### 刻意不停（不算錯）
- 理智低的恐怖音樂 horror-low（理智 45 以下）、horror-edge（15 以下）、horror-bout（發作中疊壹首）：接在 bus.heart，跟著理智和發作走，換房間不停。
- 心跳（30 以下）、不安低鳴（40 以下）、耳鳴（發作中）：同上。
- 理智掉到 15 以下的升高音（pulse-rise）壹次。
- 鐘聲（整點，clock-strike）：換畫面不打斷。
- 賭場框開著時換房間：賭場音樂跟著框走，不是跟著房間。

### snd:check 檢查什麼
1. AMB.* 每個 every／songCycle／creepyHook 的停止函式都要進 timers；沒接回傳值的 every 會被抓；每個 fileLoop 都要把 .n 放進 nodes。
2. AMB 裡的 fileOnce／fileLoop 只能接 g（或接到 g 的小音量），接 bus 會被抓；AMB 外面接 bus 的只有白名單（恐怖音樂、升高音）。
3. startAmb().stop() 要停 timers、斷開 g；sync() 要有 ambNow／heart／tinnitus／drone 的停止。
4. UI.ambOver／cellarSnd／ambTimer 只能在 ui_core.js 的 setAmbOver／setCellarSnd 裡改；開賭場聲音的檔要有關的地方；go() 要收 "room" 設的地下聲音；登出要走 nbClose 並清狀態；任何地方直接 remove .nb-layer 不走 nbClose 會被抓。
測試裡也試了各種「壞掉的寫法」（漏 timers、漏 .n、接 bus、stop 沒停、心跳沒關），確認檢查抓得到。

## 怎麼確認的
- npm run snd:check：17 個環境音都過。
- test/snd_check.test.cjs：ambFor 的轉換（地下→大廳、合作框、賭場框開著／關掉／登出回標題／結局、禁書頁籤→大廳、理智歸零、圖庫走音、失敗作之夜）、用假的 AudioContext 把每個房間建了再換掉確認計時器都停、心跳耳鳴不安低鳴關得掉。
- npm test 全過。

## 還沒做、要注意
- 沒有做瀏覽器實測（#畫面 靜音模式聽不到，而且要登入、進賭場／合作才走得到登出那條路徑；dev 模組實例也沒有掛到 window）。聲音好不好聽 AI 聽不到，這裡只量「有沒有建、有沒有停」。
- 單人地下的 SCREENS.cellar 重畫時會用 "room" 重設 UI.cellarSnd，若同時開著合作的框（from "coop"），會被蓋掉；平常合作的框開著時不會進單人地下，沒有處理。
- 賭場框開著被嚇退回大廳，音樂是賭場不是大廳，這是設計。若翊文覺得被嚇退應該連賭場框一起關，是另外一件事。
