## 共用的「效果狀態」（寫在壹處，三處都叫）

建議放 `shared/room_mood.js`，純函式：`roomMood(data)` → `{ light, crowd, flags, omen }`。資料從 `todayHeadlines`、`statView` 來，不另外算。

- `light`：`{ warm: -1～1, dim: 0～1 }`。冷清 → warm −0.6；熱絡 → 0.5；沸騰 → 0.9。莊家吃緊或破產 dim 變大。
- `crowd`：0～24，展廳人數換算（超過 60 人封頂）。
- `flags`：`{ bunting: null | "policy" | "event" | "both", skyLit: 0～1, layoff: 暗窗幾格 }`。
- `omen`：0～1。NPC 平均理智低或集團不安高才大於 0；0 就完全不出現。
- 門檻（冷清 29、熱絡 60…）讀 `statBandOf`，不另外寫。

## 原則

- 效果很淡、蓋在上面壹層，`pointer-events: none`，不擋點擊、不影響字的可讀性。
- 不做「減少動態」版本（翊文 11-15 拿掉了動畫減量）。
- 手機直拿用同壹套；窗外遠景那條佔高度，手機可能要省略（要做的時候再量）。

## 需要翊文決定

1. 五種效果要做哪幾種、先做哪壹種。
2. 窗外遠景要不要做（要多佔導覽圖上面壹條）。
3. 怪影子要不要做、多常出現（現在提案是「偶爾閃壹下」）。

## 要生的素材

目前都是 CSS 示意，不需要新素材。正式做時可以選擇生：街景遠景（遠處的樓和窗）、彩旗（單色三角旗壹組）、怪影子（壹隻，透明背景）。要生再列清單給你。
