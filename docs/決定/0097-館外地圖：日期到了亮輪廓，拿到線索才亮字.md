# 0097 館外地圖：日期到了亮輪廓，拿到線索才亮字

- 日期：2026-11-16 10:30:00
- 誰決定：翊文（館外地圖放圖書館頁籤，日期到了亮輪廓、玩家拿到對應線索才亮字）；怎麼判斷線索由美術統籌看現有資料定
- 狀態：有效

## 決定

1. 圖書館多一個頁籤「地圖」（`ORIGIN_TABS`，放在主線後面）。畫面 `web/src/ui_map.js`，規則 `shared/map.js`，資料 `shared/map_data.js`（`tools/map_pack.cjs` 從 `content/map/館外.json` 打包，揭露當天才由排程寫進去，只增不減）。
2. **兩階亮度**：`from` 日期到了（含當天）＝亮圖釘輪廓，名字寫「？」；再拿到對應線索＝亮字（圖示、名字、壹句話、住的人）。
3. **怎麼判斷「拿到線索」**：點上的 `need` 是壹個線索 id（`c-…`），看 `P.clues[need]` 有沒有（`P.clues` 由 `shared/clues.js` 的 `gatherClues` 在玩家讀過書、找到房間的點、看過畫之後記進去，不重複）。沒寫 `need` 的點，日期到了就全亮。只看日期和 `P.clues`，不看哪天打開過；晚進來的玩家日期都到、線索補讀到就全亮。
4. 「新」：日期到了新出現的點，由 `scanFresh` 標壹次（`FRESH_KEY.map(id)`，房間 origin），頁籤和圖釘上有「新」。
5. 四片透明片：L1 城鎮是紙和虛線路；L3 的點後面蓋空心章；L2 上緣起霧、點後面蓋缺角章；L4 紙換成帳頁。有那片的點才疊那片。沒有價格、數字、集團的錢；不寫別的館的名字和總數。
6. 素材：翊文生的原圖在 `assets/map/`，`tools/map_assets.py` 處理成 `web/public/map/`（裁掉多的介面列、地點圖示的三個英文字塗掉、章去背、霧用 `tools/black_to_alpha.py` 轉透明）。M-3 紙邊、M-8 路徑這次沒用（邊用 CSS、路用 SVG 畫）。

## 沒有做

- 四片透明片整張預先拼好的底圖（用零件在畫面上疊）。
