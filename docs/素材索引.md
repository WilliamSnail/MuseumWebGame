# 素材索引：哪些素材在哪、可以重複用在哪

> 11-20，美術統籌。翊文問「素材都有分類好嗎、有些可以重複使用」。**現況**：素材照「地方」分資料夾，各資料夾大多有 README；但沒有跨資料夾的總表，所以不知道哪些零件可以借。這份就是總表，新生的素材請順手加一行。
> 規則：**原圖不進 repo**（翊文 11-20）；只存處理好的（去綠底、切好、轉 webp）放 `web/public/`。**會被別處借用的零件放 `web/public/kit/`**（共用零件），只有一個地方用的放自己的資料夾。舊的地方（地下室、介面重塑…）以前存過原圖在 `assets/`，照舊留著。

## 加新素材時
1. **原圖不進 repo**（翊文 11-20）：只存裁好的成品，放 `web/public/<地方>/` 或共用的 `web/public/kit/`。
2. 想想有沒有別處能借：能借的處理完放 `web/public/kit/`，並在上面「共用零件」加一行（寫「還能用在哪」）。
3. 授權照 `assets/授權.md`；不放 Pepe the Frog 的樣子（除決定 0147 那一張）。

- 餐車的 `food-tea.webp`（冰涼啤酒）是 D-7_beer 右上那一格（黃銅杯墊），其餘品項是 D-7 的八格。
