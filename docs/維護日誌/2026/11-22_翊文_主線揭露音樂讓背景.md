# 主線劇情揭露時，背景音樂先讓開

## 為什麼改

翊文 11-22：「圖書館讀到主線劇情揭露時音樂好像會跟背景音樂重疊」。

主線揭露的那首（film-reveal／film-inspiring／film-sad）走音效音軌。
圖書館的合成旋律、鋼琴曲走背景音軌，兩邊各放各的，所以疊在一起。

## 改了什麼

- `fx_sound.js`：背景音軌出去前多一個「讓路」的音量鈕（bus.ambDuck）。
- `FX.sound.file(id, g, { duck: true })`：放的時候把背景壓到 8%，播完前 2 秒淡回來。
- `sndFile` 多傳第三個參數。
- `ui_story.js`：主線揭露那首加 `{ duck: true }`。
- 測試：`test/web/amb_mix.test.cjs` 加一條，用假的 AudioContext 量「有給 duck 會壓低、快播完會淡回來；沒給不動」。

## 測了什麼、沒測什麼

- npm test、build 過。
- 聲音 AI 聽不到，只量了音量鈕的排程。還沒人聽過。

## 給下一個人

- 其他「整首放一次」的音效（例如「你看懂了」的 suspense-short）也想讓背景讓開，傳 `{ duck: true }` 就好。
- 讓路壓的是整條背景音軌（含恐怖音樂、心跳以外的環境音），心跳走 heart 音軌，不受影響。
- 揭露放到一半離開圖書館，曲子照舊放完（原本就這樣），背景會在曲子快結束時才回來。
