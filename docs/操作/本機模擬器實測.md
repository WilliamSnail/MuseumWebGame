# 本機用 Firebase 模擬器登入、看賭場和其他要登入的畫面

> 給所有 AI（和人）：賭場、銀行、展廳的訪客、拍賣這些畫面都要「登入伺服器」才開得起來（沒登入會直接擋），所以光用 `npm run dev` 的 `#畫面` 看不到。
> 這份寫「在自己的電腦上開模擬器、登入一個假帳號、給它籌碼和資料、用無頭瀏覽器照下來」。全部只連 `127.0.0.1`，碰不到正式的 Firebase，帳號和資料都是假的。
> 測試 session 11-14 寫，每一步都跑過。

## 0. 只想看畫面：不用登入的假伺服器（11-22，翊文：「賭場要登入才打得開，有沒有辦法不用登入」）

`npm run dev` 之後，網址加 `#畫面` 就直接打開賭場、銀行，**不用登入、不用開模擬器**。`mock_net.js` 把 NET 換成假的（不連任何網路），回的是 `web/src/core/mock/fixtures.json` 裡錄下來的真伺服器回應：

- 賭場：`#casino`（牌桌）、`#casino:餐車`、`#casino:大禮包`、`#casino:我的`（也可以寫 table、diner、gift、mine、swap、ach、props、week、packs、econ、live）
- 銀行：`#bank:財報`、`#bank:金流`、`#bank:股票`、`#bank:存款`、`#bank:借款`、`#bank:館債`
- 館友證的賭場頁：`#pass`；其他畫面加 `?mock`（例如 `http://localhost:5173/?mock#lobby`）也會用假伺服器
- 調狀態：網址加 `&chips=5000`（籌碼；要放在 `#` 前面，例如 `/?mock&chips=5000#casino`），或在 console 叫 `__mock.set({ chips: 5000 })`；理智低用 `#casino:lowsan`（debug_boot 本來就有）
- 德州：`#casino:德州` 是開桌畫面；看打牌中、結算要加參數（放在 `#` 前面）：`/?mock&holdem=play#casino:德州`（輪到我、超時過 1 次）、`holdem=other`（輪到別人）、`holdem=over`（攤牌、有邊池、兩位贏家、下壹手倒數）；也可以在 console 叫 `__mock.set({ holdem: "over" })`。假畫面是手寫的（`mock_net.js` 的 `holdemMockView`），倒數每次 tick 重設；按動作會回「不處理」
- 荷官的聊聊、送佩佩、德州桌的「開桌」、頂上「這裡現在 N 人」的小框，都能點開看
- 全館投票（決定 0166）：`/?mock&vote=open#vote` 打開投票畫面。`vote=` 是假裝現在到哪裡：`before`（開投前一天）、`open`（開投、還沒投）、`voted`（投過、還能改）、`locked`（改過、鎖住）、`counting`（截止、等公布）、`result`（公布）、`missed`（公布、自己沒投）、`nobody`（公布、沒人投）；不帶就是真的現在（12-11 05:00 以前什麼入口都沒有）
  - 入口：把 `#vote` 換成 `#lobby`（大廳最上面那條）、`#today`（任務板）、`#pass`（館友證）。規則跑真的（`shared/story/vote.js`），投了、改了畫面跟著變，重新整理就清掉；館史的字是假的佔位
  - 直接到某個樣子：`#vote:write`（選寫下名字、打好字）、`:blank`、`:long`（名字太長）、`:confirm`、`:edit`、`:editconfirm`、`:send`（直接送出）、`:history`；理智低是 `#vote:write:lowsan`
  - 擋下來和斷線：`&votewhy=before|closed|badChoice|noName|longName|badName|noChange`（下一次投票被擋，不附理由、看備用句子）、`votewhy=net`（投票時斷線一次，按「再送壹次」就成功）、`votewhy=netpeek`（一直連不上）
  - console：`__mock.set({ vote: "counting" })`、`__mock.set({ votewhy: "closed" })`，再打開投票畫面
  - **用模擬器（真的伺服器）看四個階段**：開發版網址加 `?user=小明&votenow=2026-12-13T10:00:00+08:00`（要放在 `#` 前面），畫面照那個時間畫，呼叫 `storyVote` 時帶 `testNow`；正式站的伺服器不理它。大廳、館友證的入口也照這個時間出現
- `npm run ui:check` 也用它：賭場、銀行的每一頁（手機＋電腦）都量得到，不再「跳過」

**只能看畫面**：發牌、買賣股票、存提、領獎這些會動錢的動作，假伺服器回「不處理」，按了什麼都不會變；聊聊、送佩佩只在畫面上走完，不記熟識度。**動到錢、伺服器規則的實測，還是要照下面用模擬器登入。**

假資料是錄的，不是手寫的：伺服器回應改了形狀，就重錄（要先開模擬器）：

```powershell
npm run mock:record -- --set 6          # 重錄 web/src/core/mock/fixtures.json（對模擬器真的叫一次）
npm run mock:record -- --set 6 --check  # 不寫檔，只看假資料的形狀還跟不跟得上伺服器（改了伺服器回的欄位後跑；要模擬器，不在 npm test）
```

畫面新叫了一個 `NET.call("casino", { act: "新動作" })`：只讀的，加進 `web/src/core/mock/calls.json` 再重錄；會改狀態的，加進 `test/web/mock_net.test.cjs` 的 MUTATING。兩邊都沒有，`npm test` 會擋。假伺服器和假資料只在開發版載入，不能進 `dist/`（`npm test` 的程式規矩第 8 項擋）。

## 1. 開環境（一個指令）

```bash
npm install && npm --prefix functions install     # 第一次，新的 worktree 也要
npm run local -- --set 3 --port 5393              # 放背景跑；開模擬器、放規則、開網頁
```

- `--set N` 會把模擬器的連接埠都加 `1000×N`，**每個 session 用不同的 `--set` 和 `--port`**，不然會測到別人的分支。開之前先看有沒有人在用（`npm run local -- --set 3 --stop` 只關這一套）。
  - 建議：美術統籌 `--set 4 --port 5394`，測試 `--set 3 --port 5393`，數值平衡 `--set 5 --port 5395`，Yuga 自己用 `--set 0`／5173。
- 等到印出「好了：http://localhost:5393/?user=小明」就是起來了（約 60～90 秒）。
- 改了 `shared/` 或 `functions/` 要**重開**（規則是開的時候才複製進 `functions/shared/`）；只改 `web/` 不用，網頁會自己更新。
- 用完關掉：`npm run local -- --set 3 --stop`。

## 2. 登入一個測試帳號

網址加 `?user=名字` 就是登入那一位，不用密碼、不用 email：

```
http://localhost:5393/?user=賭場甲
```

- 第一次進標題畫面，按「**自由模式**」就能進大廳（賭場、銀行、大廳都看得到；不用做佩佩、不用選職業）。要看需要挑戰存檔的畫面（展廳有展品、委託、館長室升級）按「新參觀者」，並用 §4 的 `qa_seed_save` 先放存檔。
- 瀏覽器可能先跳「這台電腦有之前的存檔…要搬上去嗎？」：按「從頭開始」。
- 大廳會自動跳公佈欄，右上角 × 關掉。
- 開第二個分頁用 `?user=別的名字` 就是第二個人。**網址的連接埠不同，登入也是各自的。**

**帳號一致（11-21）：** `emu:call`、`qa:user`、`qa:giver` 跟網頁用同一種登入（假的 Google 憑證，`tools/dev/emu_lib.cjs`），同一個名字就是同一個人，先後順序不再有差。（以前 emu:call 用 email＋密碼註冊，網頁登入過的名字就 `EMAIL_EXISTS` 登不進去。）

**實測的捷徑（11-21）：** 一個指令備好帳號＋挑戰存檔＋錢包文件：`npm run qa:user -- --set 7 --nick 聊乙 --pepes 12`；交代人的熟識度、今天誰有拜託：`npm run qa:giver`；瀏覽器 console 的 `window.__qa`（開發版才有）：`await __qa.enter("銀行")`、`__qa.as("聊乙")`、`await __qa.casino({...})`、`__qa.date(1)`；`npm run local -- --list` 看哪幾套有人在用。

## 3. 建帳號、給籌碼

```bash
# 建帳號和錢包（任何一個會寫入的動作都可以；存 1 萬進活存）
npm run emu:call -- --set 3 --user 賭場甲 casino '{"act":"bank","op":"put","amt":10000}'

# 給籌碼（改錢包的 chips 欄位；賭場、銀行、大禮包、餐車都用得到）
npm run emu:doc -- --set 3 data casinoWallets/@賭場甲 chips=50000000

# 銀行館債要帳號滿 3 天、拍賣也是：把開戶日往前改
npm run emu:doc -- --set 3 data casinoWallets/@賭場甲 'bond.born="2026-01-01"'
```

- `@暱稱` 會換成那個人的 uid。看欄位：`npm run emu:doc -- --set 3 get casinoWallets/@賭場甲`。
- 莊家的錢（`casinoHouse/main` 的 `bankroll`）預設 11 億，不用管。
- 賭場面板打開要「進館」過；自由模式進大廳就算進館。
- 其他腳本說明在 `tools/README.md`（`emu:call`、`emu:doc`、`qa_seed_save`）。

## 4. 賭場每一頁要有資料

賭場面板的頁籤（11-21 收成 4 個）：牌桌（旁邊有實況）、餐車、大禮包（大禮包、拚經濟、本週收藏）、我的（成就、換小獎、財產）。剛建的帳號有的頁是空的（成就全部鎖著、本週收藏沒有進度），要看「有資料」的樣子：

```bash
U=賭場甲
# 打幾手 21 點（成就、牌桌紀錄、本週收藏的進度會動）：發牌 → 停牌（seq 從 0 開始，每手重新發）
for i in 1 2 3 4 5 6; do
  npm run emu:call -- --set 3 --user $U casino '{"act":"deal","text":"10000"}' > /dev/null
  npm run emu:call -- --set 3 --user $U casino '{"act":"stand","seq":0}' > /dev/null
done
# 開大禮包、吃餐車、拚經濟（各壹次）
npm run emu:call -- --set 3 --user $U casino '{"act":"pack","n":1}'
npm run emu:call -- --set 3 --user $U casino '{"act":"buy","item":"tea"}'
npm run emu:call -- --set 3 --user $U casino '{"act":"econ"}'
```

- `deal` 要帶 `text`（下注的字，例如 `"10000"`、`"全下"`）；打到一半（還沒 `stand`）的手，網頁畫面會看到進行中的牌桌。
- 動作的名字和參數看 `functions/casino/casino.js` 的 `switch (act)`（`pack`、`buy`、`econ`、`stock`、`bank`、`borrow`…）。
- 要看展廳有人、有展台：`node tools/dev/qa_seed_save.cjs --set 3 --nick 名字 --pepes 6 --hall 3`（要先用 `emu:call` 建過帳號；然後網頁按「新參觀者」→「繼續參觀」）。
- 要看銀行股票有行情、台股盤中：模擬器沒有真實行情，要自己寫假的（看維護日誌 `11-13_測試_真實價過期的暫停訊息.md`）。

## 5. 照畫面存成 PNG（不用開瀏覽器分頁）

登入後的畫面也能用無頭 Edge／Chrome 照，**一個指令**（`tools/dev/shot_login.cjs`，背後用 `tools/dev/shot_phone.cjs`）：

```bash
node tools/dev/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --tab 成就 --size 1366x768 --out 成就.png
node tools/dev/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --size 375x740  --out 直拿.png
node tools/dev/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --size 740x375  --out 橫拿.png
```

- `--room` 是大廳地圖上的房間名（賭場、銀行、我的展廳、圖書館…）；`--tab` 是進去之後要點的頁籤字（牌桌、本週收藏、大禮包、拚經濟、實況、餐車、換小獎、成就、財產；不給就停在第壹頁）。
- `--size`：電腦 `1366x768`、手機直拿 `375x740`、橫拿 `740x375`。直拿會自動略過「請轉橫」。
- 照完用 Read 打開 PNG 看。要照每一頁就把 `--tab` 換九次。
- 沒給 `--mode` 是「自由模式」；要用「新參觀者」加 `--mode 新參觀者`（要先 `qa_seed_save` 放過存檔，而且網頁第一次會跳選職業，無頭瀏覽器走不過，這種畫面請用瀏覽器分頁看）。
- 只准 `localhost`；需要的字（頁籤、房間）要跟畫面上一模一樣。

### 踩過的坑

- **賭場面板的關閉鈕、公佈欄的關閉鈕都是 `.nb-x`。** 自己寫腳本時，進房間之後不要再 `document.querySelector('.nb-x').click()`，會把剛打開的賭場關掉。
- `?user=` 帶中文沒問題；`#畫面` 的 debug 網址（`#bank`、`#hall`…）**不登入**，只有示範資料，看不到真的錢包。
- 頁籤超出螢幕時（手機直拿）只有前幾個看得到；點得到的用 `--tab` 指名，它會直接點（程式點擊，不用捲）。
- 手機直拿的大廳是壹張地圖，房間在 `.l2-room`（`aria-label` 是房間名），程式點擊就行，不用真的點到字。
- 沒聲音：網址有 `?user=` 在開發時自動靜音。
- 瀏覽器分頁測試時：先 `resize_window` 到要的尺寸再載入頁面；用完改回 `desktop`。

## 6. 收工

```bash
npm run local -- --set 3 --stop
```

模擬器裡的資料每次重開都清空，不用清。

## 坑：關不乾淨、連接埠被 java 占著（11-14）

`npm run local -- --set N --stop` 以前只關得掉外面那層 node／shell，資料庫、Firestore 模擬器的 java 會留著占連接埠（set 4 是 13100），下次開就報「連接埠已經有人在用」或 Functions 兩分鐘載不進來。
11-14 已修：`--stop` 會照這套設定檔（`firebase.emuN.json`）裡的連接埠把 java 一起關掉。如果還是殘留（舊版開的、設定檔被刪），手動：
`Get-CimInstance Win32_Process -Filter "Name='java.exe'" | Select ProcessId,CommandLine` 找出有 `--port 你的埠` 的那支，`Stop-Process -Id 它 -Force`。
