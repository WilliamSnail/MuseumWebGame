# 0084 館外來客在餐車照菜單點，財報分類列出昨天的花費

- 日期：2026-11-15 12:00:00
- 誰決定：翊文（「好，一起交給數值平衡做」「可以銀行的財報之類的地方看到嗎? 要分類一下」）
- 狀態：有效

## 決定

1. **餐車點餐**：有名字的 NPC 和散客到餐車，照菜單點烤雞肉、冰涼麥茶、搶鮮壽司（常點）、歡樂分享餐、堂主推薦葡萄汁（少點），價錢照 `CAS_MENU`（`npcOrder`，種子含祕密）。花的總額 ≤ 原本的預算（`perDay × shopPct%`、散客 `shop.spend × 人數`），所以全館上限、外面世界出錢、守恆都照舊；預算買不起任何品項就不花。不加心情、不進館友的點餐紀錄，只記「賣出幾份」。
2. **看得到的地方**：日報多兩行（「昨天餐車賣給館外的客人：…」「某某在餐車點了…」）；銀行財報頁多 `h.econ.ext`（資料給美術統籌排版）。
3. **`h.econ.ext` 的形狀**（昨天，跟日報同壹份快照）：
   `{ day, ticket: { hall, crowd }, shop: { food, bj, craft, cellar, job }, shopCrowd: { 同上，散客那份 }, total, people: { npc, crowd }, menu: [{ id, name, npc, crowd }], orders: [{ who, item, name, n }] }`
   `casBankEcon` 回傳多壹個 `ext`（沒有就 null）。

## 取捨

- 餐車花費會比原本略少（拿不完整的零頭），預算買不起最便宜的 45 就不花。
- 地下收藏庫、手作坊、委託櫃台、牌桌只記金額，不分品項。
