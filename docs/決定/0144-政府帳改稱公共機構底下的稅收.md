# 0144 政府帳改稱「公共機構底下的稅收」

- 日期：2026-11-20
- 誰決定：翊文（11-20，Yuga 轉達）：「公共機構可以底下有壹個就是稅收」
- 狀態：已決定，做完（只改名字，不動錢，不用存基準）

## 決定
1. 玩家看到的「政府帳」全部改成「稅收」（公共機構底下）：金流圖節點、財報那一段、帳本標籤、銀行說明、槓桿說明、館方公告。
2. 程式裡的 `house.gov`、`casPoolGain(house, "gov", …)`、`govSweep` 都不動：稅先進 `house.gov`，每天換日搬進公共機構（決定 0140）。
3. **沒做真正的子單位（建議 A）**：已知世界的錢只分到頂層單位（子單位沒有自己的餘額，見 `shared/world.js` 的 W3 分帳）；要讓稅直接進子單位，得改 7 個進稅的地方，加上 NPC 營業稅、娛樂稅要跟 `wuDebit` 的順序對上，守恆容易出錯，換來的只是少了壹個中繼的池子，玩家看不出差別。翊文要的話再另外做。
