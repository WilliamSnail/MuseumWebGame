# 0103 旅客理智等級公開成排程讀得到的 JSON

- 日期：2026-11-16 17:00:00
- 誰決定：翊文（「理智等級讓排程讀得到」）
- 狀態：有效（補充決定 0097）

## 決定

- 排程環境不接連接器、AI 又不能按固定動作 `world-status`，所以把週結算的分級放在不用金鑰就讀得到的地方：**公開網址 `/data/npc_san.json`**（Hosting 轉到 Cloud Function `npcSan`，`functions/san_levels.js`，只讀 `casinoHouse/main`，快取 5 分鐘）。`npm run san:levels`（`tools/san_levels.cjs`）印出來，`--json` 印原始。
- 內容（`nwArcPublic`，`shared/world.js`）：`{ asOf（最近一次週結算的段首日期）, seg, levels: { 旅客 id: { now（最近 7 天均線的分級）, st（這次結算）, prev（前壹次）, since, end? } }, edge（edge 又還沒走結局的）, newEdge（前壹次 uneasy 以上、這次 edge 的）}`。**不寫玩家名字、不寫誰造成的**，只有旅客 id 和分級。
- **所有有名字的旅客都追蹤**（不再只追蹤有 `variants` 的）：排程可以對任何旅客觸發 edge，不預先指定。劇情角色（trace）不算。每位存最近 7 天收盤理智（7 個整數）。
- 排程說明（一之十一之二、第五節第 9 點）改讀這份，取代固定動作 `world-status`；`asOf` 是 null 或讀不到時，當成沒有人到 edge。

## 沒有做、要注意

- `firebase.json` 多壹條 Hosting 轉址、`functions/index.js` 多壹個匯出：合併後部署會建新的公開端點。**這是正式站新增壹個公開端點**（只讀、只有旅客 id 和分級），翊文如果不要，把這條轉址和匯出拿掉即可。
- 「走完結局」（`nwArcEnd`）還沒有程式觸發：排程寫了 `branch` 結局之後，要有人（或之後的程式）呼叫它，不然 `edge` 清單會壹直有那位旅客。目前排程自己看 `content/npc/*.json` 有沒有寫過 `branch` 就好。
