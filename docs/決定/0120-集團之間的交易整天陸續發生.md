# 0120 集團之間的交易整天陸續發生，財報寫出往來

- 日期：2026-11-17 18:00:00
- 誰決定：翊文（11-17：「改成陸續發生」「加進財報」；96 格可以、借還選整週分散、要館方公告）
- 狀態：已決定（取代 0119 裡「換日壹次結算」的部分；其餘不變）

## 決定
1. 每天 96 格（05:00 起每 15 分鐘壹格）。換日（`whTick`）只「排」，碰到莊家文件時（`playCore`，跟館內股同樣惰性補算）用 `wtAdvance` 補到現在那壹格。全天總額跟 0119 壹樣，每格份量照「白天多、夜裡少」加固定隨機（雜湊，不用 RNG）。前壹天沒走完的，換日那刻補完再算健康值，所以健康值、週一狀態的規則不變。
2. B 貨款、A 利息、C 營收：照 1 分到 96 格。
3. 借款、還款：**整週分散**。週一定下總額，之後每天借／還 1/7（最後壹天補零頭）；欠款隨每天的小筆增減，利息照目前欠款算。新聞照舊寫「誰借了、誰還了」（借：週一定下就寫；還款：還完才寫）。
4. 守恆照舊：只動 `house.wu.adj`，`wtLed` 累計；文件只多 `house.wh.tr`（走完就刪）、`house.wh.draw`／`rep`（本週的借還進度）、`house.wh.wk`（週一的 `led.units` 快照）。
5. 財報「外面世界」多壹塊「集團之間的往來」：本週累計（種類、從哪個集團到哪個集團、金額）、目前欠金融集團的（誰、多少、哪天借）。資料 `bankHall.trade`（`wtCard`），不列個人。`wtNews` 接進財報的「這週換了狀態的」和 `world:news draft`。
6. 開關：`NUM.casino.worldDoc.trade.live`，關掉就回到換日壹次入帳。

金流頁籤每 45 秒重拿，原本 05:00 壹次出現、整天不動；翊文要看到錢在動。
