## 決定

- 一個 Claude 的排程，每天 04:30（台灣時間）跑，先看今天星期幾（翊文 2026-11-09 08:18:36：「兩個牌程可以和再一起吧?自己確認今天是週幾」；雲端，用翊文的 Claude 帳號額度）：

  - 週二到週日 04:30：照這週的線寫今天的內容，再加一兩樣遊戲裡的新東西（可以找的東西、限定頭飾……）。
- 測試過就自己合併、自動部署（決定 0024 的「AI 可以自己合併」用在排程上），不等人審。人可以事後改、退版、把排程停掉。
- 每天只能加「內容」和小東西；新的玩法、改存檔格式的，開 Issue 提案，翊文說好才做（走一般的 PR）。
- 補充（2026-11-09，翊文：「新的畫廊的話好像只是原本的畫改一點點，之後能不能更加不一樣」）：今日特展可以用 `svg` 畫全新的畫，不用提案，算內容；規矩在 `content/README.md` 第九節。要新的**程式**才要提案。
- 檢查沒過、來不及：用備用的週、備用的一天，開 Issue 告訴翊文。
- 新聞的界線照 `docs/每週劇情.md` 第三節（`docs/界線.md` 第三節也有）。
