# 0137 集團股手續費 0.5% → 0.2%

- 日期：2026-11-20
- 誰決定：翊文（11-20，看過集團股炒作模擬後；Yuga 轉達）：集團股手續費降到 0.2%，利息、借券維持，不加稅；館內股不動
- 狀態：已決定，程式和測試做完；上線前 Yuga 存基準

## 決定
1. `NUM.casino.stock.feeOut.grp` ＝ 0.2（%，買賣各收）。集團股現股買賣、掛單鎖錢、槓桿開平倉（`casStockFeePct`）都讀它；`gsFeePct()`（`shared/casino_stock_grp.js`）是取值的地方，沒設就退回 `feePct`。
2. 沒動：集團股賣出證交稅（照 `taxPct`）、槓桿利息 0.15%／借券費 0.3%、集團股的價差（半價差）、每天買賣上限、莊家曝險；館內股的手續費（0.5%）。
3. 說明和公告：銀行說明頁、槓桿規則（`casLevCostText`）、集團股下單表單、館方公告都讀設定或寫 0.2%；`test/fee_text.test.cjs` 擋不一致。

## 模擬（`tools/gstock_lev_sim2.cjs`，40 天，莊家餘額 5,900 萬、曝險上限 20%、5 倍）
- 手續費 0.5 → 0.2（加當沖稅 0.15 那組）：莊家 40 天收入約 −20%（1,200～1,660 萬 → 920～1,380 萬），最差壹天 −43 萬 → −49 萬。
- 炒作攻擊（自己推價強平別人、拉高出貨）在任何費用下都不賺：推價 −0.05%～0、攻擊者壹天淨 −66,000～−78,000 或 0、空頭被強平 0 筆、壞帳 0。莊家的錢大半是推價的半價差，不是手續費。
- 這次**沒有加當沖稅**（翊文：不加稅），模擬裡 0.2% 那組有加 0.15 稅，實際莊家收入會略多於那組。
