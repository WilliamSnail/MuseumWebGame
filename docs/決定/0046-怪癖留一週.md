# 0046 怪癖留一週：要在兩個不同的遊戲日做事情才治好，不然七天後自己好

- 日期：2026-11-09 16:09:27
- 誰決定：翊文（要改、方向）；七天、兩天、最多 3 個、換日改治法、提示的寫法是做的時候先定的，標「先照這樣」的等翊文看
- 狀態：有效（先照這樣做了，等翊文看）。取代第 0027 篇裡「20 分鐘」和「做完一件事就治好」的部分，其他照舊

## 背景

第 0027 篇把怪癖改成「做完一件事就好，不然 20 分鐘後自己消失」。翊文 11-09：

> 「怪癖改留久一點，自動恢復要一週之類的，恢復要做事情兩天，這個引導讓使用者多切換不同參觀者，需要的話可以給提示」

20 分鐘太短，玩家根本感覺不到怪癖。留久之後，怪癖就是這一位參觀者的狀態，玩家可以換別位玩。

## 決定

- **自動恢復：恐懼症 7 天**（`NUM.quirkDays`），**狂熱 3 天**（`NUM.quirkManiaDays`，翊文 11-09：「狂熱縮成三天」）。
  - 照真的時鐘（`nowMs()`），得到那一刻起算，關掉遊戲、換成別位參觀者都照走。不在場的參觀者也一樣，`until` 是毫秒，換人不動它。
  - 7 天整就算到期：差 1 毫秒還在，到了就不擋（`quirkLive`）。
  - `NUM.quirkMinutes` 拿掉，換成 `NUM.quirkDays`。
- **做事情恢復：在 2 個不同的遊戲日做到治法那件事**（`NUM.quirkTaskDays`，先照這樣）。
  - 治法那件事跟 0027 一樣三種：抱一次抱枕、交一張委託、看一幅不可怕的畫；得到怪癖時抽一件。
  - 「遊戲日」是 `todayStr()`（台灣 05:00 換日）。不用連續；同一天做幾次都只算一天。
  - 進度記在怪癖物件上：`q.done`（做到的遊戲日，不重複的日期字串）。湊滿 2 個就治好，沿用現有的治好通知。
  - 得到怪癖「之後」做的才算；得到的那天也算一天。
- **舊存檔**：
  - 沒有 `done` 當 0 個日子（`fixQuirks`）。
  - 有 `until` 的（20 分鐘版）照舊，不延長，所以舊的怪癖很快就自己好。
  - 沒有 `until` 的（更舊的）從載入那一刻起算 7 天。
  - `until` 比「現在 ＋ 7 天」還晚（電腦時鐘被往回調過）拉回「現在 ＋ 7 天」。
- **同時最多 3 個怪癖**（`NUM.quirkMax`，先照這樣）。滿了 `gainQuirk` 回傳 null，不給新的；那天的額度（`P.day.quirkGiven`）照樣用掉。理由：以前怪癖 20 分鐘就沒了，疊不起來。留一週的話，一位參觀者一天最多得到一個（`quirkGiven`），七天可以疊到 7 個，可能性和委託都會被擋死，狂熱也會一直多花靈感。
- **治法一週內可能做不到，所以每天看一次**（`retaskQuirks`，`ensureDay` 換日時叫）：
  - 治法現在做不到（沒有抱枕、靈感不夠做一隻又沒有可以交的委託），或得到時都做不到（`task` 是 null），就改抽一件今天做得到的。做過的日子留著，不重算。
  - 畫廊有不用理智檢定的畫，挑戰模式一定有，所以至少有一件可以抽。
  - 有改的話跳一則提示。
  - 退路一直都在：不管治法做不做得到，7 天一定會自己好。
- **提示，引導玩家換參觀者**（`QUIRK_PLAN_TEXT`、`quirkSwitchTip`）：
  - 換參觀者的入口：標題畫面（門口）的三個位子卡片，按「繼續參觀」。進去的路：選單的「換參觀者」（登入後才出現），或重新整理網頁。**換人不用花任何東西、沒有冷卻**，怪癖只留在這位身上。
  - 玩家不一定有別的參觀者（一個帳號從第 1 位開始，要自己在門口按「新參觀者」加）。所以：有別位的寫「換別的參觀者玩」，只有一位的寫「到門口按新參觀者招一位新的（最多 3 位）」。自由模式沒有怪癖，也沒有位子，不提。
  - 得到怪癖的卡片和狀態列點開的怪癖視窗最下面有按鈕（「去門口換參觀者」或「去門口招新參觀者」），直接帶到門口。
  - 得到怪癖的卡片寫：做什麼、要做 2 個不同的日子、不做的話還有 7 天自己好、這段時間可以換參觀者。
  - 進度看得到：怪癖卡片、狀態列小牌子（`抱抱枕・還要 2 天・7 天`、`今天做過了`）、小牌子的 title、手作坊不敢碰的說明、抱枕工作台和委託櫃台和畫廊上面的綠框、說明頁「理智檢定」那條。
  - 做到第一天：跳「「X」：今天算壹天了。改天再○○壹次就好。」；第二天治好沿用「治好了「X」」。
- 管理員介面（決定 0033）的怪癖列改成「還剩 N 天」。
- 模擬（`sim*.cjs`）的「現在」改成每一天隔 24 小時，不然怪癖永遠不會到期、兩個遊戲日也算不出來。

## 怪癖留一週會不會太難受（做的時候查過）

- 恐懼症最多擋掉一整類的選項，但 `gainQuirk` 保證每一類至少還剩一個可以選，所以做佩佩不會卡死。可能性會變少，有些委託會做不出來；上限 3 個之後，最壞是三類各被擋，仍然可以做。治法三件裡的「看畫」永遠做得到。
- 狂熱：做指定的那個選項少花 1 靈感，其他多花 1（現在 `costPepe` 是 2，所以其他變 3，多 50%）。同時有好幾個狂熱，只有第一個會算（`maniaQuirk` 是 `find`）。留一週，這是最痛的一項。**要不要把狂熱縮短、或只有恐懼症留一週，等翊文決定**；現在先都照 7 天。
- 理智不受怪癖直接影響。怪癖的來源是「一天掉超過當天理智的 1/5」，每位參觀者每天最多一次。
- 不由自主做一件事（`involuntary`）、瘋狂發作跟怪癖無關，沒變。合作地下（`shared/coop.js` 的 `coopSanHit`）也是呼叫 `gainQuirk`，滿 3 個時回傳 null，那邊已經處理 null。
- 歷任參觀者牆（`shared/legacy.js`）只記沒過期的怪癖，沒變。

## 什麼時候可以再討論

- 7 天、2 天、最多 3 個覺得不對（`NUM.quirkDays`、`NUM.quirkTaskDays`、`NUM.quirkMax`）。
- 狂熱要不要比恐懼症短，或不留一週。
- 做事情要不要綁在特定的房間（現在三件事可以抽）。
- 想要換參觀者的按鈕出現在別的地方（例如大廳）。
