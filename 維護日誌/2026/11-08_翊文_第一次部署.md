## 為什麼要改

> 「好了先部屬上去讓大家玩吧」（翊文的原話）

- 問了要從哪裡部署，翊文選「這次從這台電腦部署」。
- AGENTS.md 寫「只有自動部署能碰正式專案」；這次是翊文明講的**一次例外**。之後照舊走 GitHub 的自動部署。

## 改了什麼

- 程式沒改。部署的是 `main` 的第一次 commit（`bd73f57`）。
  - 當時 `claude/退休換人` 分支還沒做完，為了不把它部署上去，從 `bd73f57` 用 `git archive` 拿一份乾淨的到暫存資料夾，在那裡測試、打包、部署。
- 翊文在自己的終端機 `firebase login`（PowerShell 擋 `npx.ps1`，改用 `npx.cmd`）。
- 指令：`firebase deploy --project prod --only hosting,firestore,database,functions --force`。
  - 第一次部署會自動打開 Cloud Functions 要的 API（Eventarc、Cloud Run 等）。
  - Functions 的 `join` 建在 asia-east1（Node 22、第 2 代）。
  - 舊的 Functions 映像檔保留 1 天就清掉（cleanup policy）。
- 邀請名單：翊文在 Firestore 後台的 `invites` 自己加（文件 ID＝Gmail 小寫，欄位 `name`）。
