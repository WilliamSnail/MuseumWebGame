> 接 `docs/地下室改版規劃.md` 第八節（一眼看得出要怎麼做）。畫面在 `web/src/ui_fight.js`、`web/src/css/fight.css`；規則在 `shared/cellar_fight.js`、`shared/coop_fight.js`。

## 一、現在的問題

- 一回合是：大家選 → 都選了 → 結果一次跳出來（一串文字和一兩個特效）→ 馬上換下一招。
- 看不出現在在哪一步；結算太快，看不懂誰做了什麼、為什麼扣這麼多；開打、打完沒有儀式感；第一次打的人沒人教。

## 二、每一回合分四步，最上面一直寫現在在哪一步

1. **牠出招前**：下一招的木牌掉下來，箭頭指到會被打的人，那個人的座位閃紅。
2. **選行動**：計時圈開始跑；按鈕上照情況亮「建議」（「牠下一招打你：擋可以減半」「弱點找到了：推 ×1.5」「安撫要過半的人選才會取消」）；自己的座位上預告「這一招可能 −2～4 理智」。
3. **等隊友**：選好的人座位翻成「選好了」，最上面寫還在等誰。
4. **結算演出**：照伺服器給的事件一件一件播（每件 0.6～0.9 秒，可以按「跳過」）：
   - 推：那個人的座位亮 → 怪物身上灰塵特效 → 壓力條上跳「−12」，條慢慢掉。
   - 看穿成功：放大鏡光圈，怪物身上釘一個「弱點」標籤。
   - 安撫成功：音符特效，壓力條跳「−n」。
   - 擋：被擋的人座位上盾牌。
   - 招式：座位上跳招式名字；回理智的跳「理智 +n」。
   - 怪物出招：怪物換出招姿勢衝出去 → 被打的座位震一下 → 跳「理智 −3」；膽量擋住是油燈亮、被擋下是盾牌；回壓力是旋渦、條跳「+5」；被安撫取消寫「沒出手」。
   - 第二階段：白布滑落，大字「第二階段」，條重新灌滿。
   - 文字紀錄跟著演到哪、亮到哪。
   - 最後一張**回合小結**：「這回合：壓力 −18（小明 −12、小華 −6）／你：理智 −2」，再亮出下一招。

## 三、開打和打完

- **開打**：怪物滑進來，名字牌和爪痕等級，帶一句牠的來歷（`FOE_TEXT.intro`）；守門的時候舞台先暗下來。
- **打贏**：怪物換成「安靜下來」的姿勢 → 蓋章 → 登記卡（素材 3-5）從下面滑上來，寫名字、弱點、打了幾回合、最後一下是誰 → 獎勵小結（靈感、誰受傷、膽量剩多少）。
- **逃跑**：一陣灰塵往旁邊散；**牠走掉**：怪物慢慢變淡；**全倒**：畫面暗下來。

## 五、技術上要注意

- **演完才開始倒數**（翊文 11-12）：伺服器算出這一回合要演多久（事件數 × 每件的時間，有上限），加進下一回合的期限；畫面演出時不顯示倒數，演完倒數剛好是完整的 25 秒。
- 畫面一有人選就整個重畫：演出的進度放在模組裡（不放在 DOM），重畫時照進度畫回來。
- `body.reduce-motion`：不播動畫，直接顯示小結。
- 手機：飛行動畫和跳出來的數字都要在 375 寬裡、不能蓋到按鈕。
- 素材：現有的夠（特效、登記卡、怪物三個姿勢），不用再生。

## 六、分幾個 PR

1. 結算演出（一件一件播、跳數字、條慢慢掉、跳過）＋回合小結＋演完才倒數。
2. 開打、第二階段、打完的演出＋登記卡。
3. 每一步的提示、建議、座位上的傷害預告。
