# 素材索引：要做新畫面，先查這裡

> 翊文 11-20：「做好素材索引才好重複使用」「只存切好的素材並分類好」。**做新畫面之前先查這份：能用現成的就不要重生。**
> 下面「全部成品」是 `node tools/assets/gen_index.cjs` 從資料夾自動產生的：每個成品一行，寫路徑、尺寸、是什麼、可以用在哪、現在哪些畫面用、從哪張原圖切的，照用途分類。

## 怎麼找
- **要框、邊條、九宮格**：看「框和邊條」（木框、金框、深色框、卷軸、鉚釘…）。
- **要底、材質**：看「底和材質」（木紋、羊皮紙、酒紅絨面、石板）。
- **要按鈕、頁籤、標籤**：看「按鈕和標籤」。
- **要小圖示、章**：看「圖示和印章」（房間圖示、狀態列、籌碼、券、心情、理智）。
- **要人物頭像**：看「人物頭像」。要餐點、道具：看「品項和道具插畫」。
- **要房間背景、場景**：看「房間和場景插畫」；怪物和特效在「怪物和特效」；館外地圖在「地圖零件」。
- 路徑都是 `web/public` 底下（標題畫面那組在 `web/src/assets`）。程式裡用 `/kit/…`、`/diner/…` 這樣的網址。

## 規則
1. **原圖不進 repo**（翊文 11-20）：只存裁好的成品（去綠底、切好、轉 webp），放 `web/public/<地方>/`；**會被別處借用的零件放 `web/public/kit/`**。
2. 切法照 `docs/素材/素材生成.md`：零件拆開（底、邊條、四角），不整張拉伸。
3. 新增素材之後：在 `docs/素材/素材標註.json` 加一條規則（是什麼、可以用在哪、從哪張原圖切的），再跑 `node tools/assets/gen_index.cjs`；`--check` 可以檢查索引是不是最新。
4. 原圖已移出 repo：要找原檔，`git show 41f45c13:assets/<資料夾>/<檔名>`（那個 commit 以前都有）；`assets/<資料夾>/README.md` 寫了每個資料夾移出了什麼。
5. `assets/` 還留著的是「切過的單張 png」（切好、沒縮成 webp 的版本，有些還沒接進遊戲），翊文 11-20 決定留下：nav、status、icons、props、rooms、badges、title、ui、cellar、panel-kit 的單張。
6. 不放 Pepe the Frog 的樣子（決定 0005；Yuga Bot 頭像是決定 0147 的唯一例外）；圖裡不放真人、品牌、政黨標誌；沒有字。授權照 `assets/授權.md`。
