# 0115 「預算池」改名「博物館資金」、「館方帳」改名「修繕基金」

- 日期：2026-11-17 14:00:00
- 誰決定：翊文
- 狀態：有效

## 決定

1. 玩家看得到的名字：「預算池」→「博物館資金」，「館方帳」→「修繕基金」。包含畫面、規則與小提示、日報、銀行「全館的帳」、`casino_report` 的來源說明、館方公告（**舊公告也換**）、Discord。
2. **程式裡的鍵名不動**：`house.budget`、`house.museum`、`NUM.casino.econ.budget…` 等；決定紀錄、維護日誌、規劃文件是當時的紀錄，**不改**（舊文件裡的「預算池」就是現在的「博物館資金」）。目前有效的 `docs/現況.md`、`docs/經濟系統的坑.md`、`docs/經濟自我檢查.md` 換了。
3. 測試裡比對字串的跟著改。
4. 順便改說明：銀行「全館的帳」莊家那列寫「牌桌、館內股、免費大禮包、借款」，博物館資金那列拿掉「大禮包」（大禮包是莊家出的，`casOpenPacks` 的 `casHouseMove pack`）。
