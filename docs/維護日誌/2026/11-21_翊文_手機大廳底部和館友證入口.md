## 為什麼要改

翊文手機截圖：大廳底下的「今天／這週」積分條中間的進度條縮成壹小顆，右邊「每日任務」卡被切到畫面外；而且手機沒有館友證入口。

## 改了什麼

- `lobby2.css`：手機的 `.l2-todos` 欄寬改 `minmax(0, 1fr)`，積分條（`.l2-pts`）佔壹整排，不再跟任務卡擠同壹格。
- `ui_core.js`、`ui.css`：手機頂欄多壹顆館友證圖示（電腦已有頁籤，所以只在 760px 以下顯示）。

## 怎麼確認的

- dev `#lobby` 手機截圖：積分條整排、進度條有長度；頂欄有館友證圖示。
- `npm run ui:check` 沒有發現問題。

## 還沒做、要注意

- 任務卡本身在 dev 假資料裡沒出現，沒親眼看到卡片，只靠 ui:check 沒有超出。
- 灰色頭像是設計（只有 yuga 有畫，其他交代人用剪影），沒動。
- 沒用挑戰存檔看過。
