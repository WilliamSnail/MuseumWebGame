# 新上架的台股先顯示代號和名字

## 為什麼要改
翊文截圖：新的四支（腦袋機架行、大戶櫃匠、量身晶片坊、粗線變壓坊）寫「休市」、價 10,000、旁邊是介紹，沒有代號。「怎麼新的沒有股票號碼那些」。

## 原因
銀行的「代號 名字」來自 H.real，只有抓到真實價才有；這四支今天收盤後才上架，明天 09:00 開盤才會第壹次有價。

## 改了什麼
- casino_stock.js：casStockSetReal 另外記 H.sym（每支的代號和名字，照 functions 的 TW_SYMBOLS／US_SYMBOLS 和名字表），view 多給 code。只是顯示，不影響價格和錢。
- ui_bank.js：沒有 real 但有 code 的，寫「代號 名字・開盤後才有價」。

## 怎麼確認的
casino_stock、casino_stock_peg、stocks、books_sign 過，build 過。

## 還沒做、要注意
價 10,000 是還沒對到真實價前的預設，明天第壹次開盤會照真實價換（stPegDirect）；這段時間休市不能買賣。
