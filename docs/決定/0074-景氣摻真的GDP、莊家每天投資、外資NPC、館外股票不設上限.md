# 0074 景氣摻真的GDP、莊家每天投資、外資NPC、館外股票不設上限

- 日期：2026-11-13 15:42:30
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「翊文 11-13 回答規劃問題 16～22，詳見 docs/經濟體系規劃.md 2.7、2.8 與第五節。」

## 決定

1. 景氣指數一半來自館內活動量（每天），一半來自台灣最新一季 GDP 年增率（一季變一次）。抓不到外部資料時外部那一半當 0。
2. GDP 用活動量，不用金額。
3. 莊家超過 1 億準備金的部分，每天投資；莊家有自己的法則（趨勢七成、分散兩成、隨機一成）和停損停利，持股公開。
4. NPC 投資人的錢來自外面世界（買 = 憑空、賣 = 消失），量跟景氣連動、有上限。
5. 館外股票用免費公開 CSV，畫面只出現世界版名字；不設持股上限，手續費 0.5%。
6. 借錢買股：額度為持股市值 100%、上限 2,000 萬，每天利率 0.5%，維持率低於 130% 強制賣出，壞帳由莊家吸收；上線後看財報再調。
7. 莊家稅取消（決定 0073）。
