## 決定
1. **手續費**（`NUM.casino.stock.feeOut`）：台股 0.05%、美股 0（買賣各收）；館內股、集團股、館方投資照舊 `feePct` 0.5%。`casStockFeePct(id)` 照這支的市場取。
2. **證交稅**：現股照舊（台股、館內股賣出 0.3%，美股 0）。**槓桿原本完全沒有稅**；新增台股當沖證交稅 0.15%（`stockLev.byMk.tw.taxPct`）：平倉時按平倉部位金額收，無條件進位、最少 1，從剩下的保證金扣（不夠就少收），進政府帳（來源 `stockTax`，計數 `levTax`）。美股、館內股、集團股槓桿沒有稅。
3. **槓桿利息、借券費**（`NUM.casino.stockLev.byMk`）：台股、美股利息 0.02%／天（做多借的部分，開倉時收壹次）、借券費 0.08%（放空，占部位；**美股借券費沒人指定，我照台股 0.08**）；館內股、集團股照舊（利息 0.15%、借券費 0.3%）。
4. **畫面**：每支的 view 帶 `fee`、`taxPct`；整體 `feeTw`、`feeUs`；槓桿 view 多 `rates { in, tw, us, grp }`（手續費、利息、借券、稅）。買賣確認、掛單鎖定、槓桿確認單、行情表標題、說明頁（`helpSections`）都照這支的市場算和寫。
5. **沒動**：倍數、部位上限、每天淨賺上限、強平、每天賣出上限、館內股和集團股的任何費用、館方投資的手續費（照舊 0.5%，是館方自己的錢在內部搬）。
