# 賭場超過 35 人改放 Copper Nights

## 為什麼要改
翊文給 Pixabay「Copper Nights」：「賭場裡超過35人就改播這個」。

## 改了什麼
- npm run sfx:add 壓成 casino-jazz.mp3（149 秒循環、單聲道 40 kbps，729 KB）；Pixabay 抓不到資料，網址、原名、作者照檔名手動給（網址沒有分類前綴，Pixabay 會轉址）。
- fx.js AMB.casino：合成的爵士（低音、刷子、電鋼琴）接到 mus；mix 收到 busy 時 mus 淡出、Copper Nights 淡入（用到才下載、從頭放）；人聲錄音和籌碼聲照舊。
- audio_state.js：casino 的 mix 多 busy；ui_core.js 用 ADDONS.roomPeopleN("casino")（ui_lobby2.js 的 roomCounts：館友＋旅客＋散客＋被邀去的）≥ NUM.ui.casinoBusyMusic（35）。賭場開著時 setAmbOver 每 30 秒、讀到新的館內人數時都會重算。

## 怎麼確認的
snd_check、sfx_files、fx_report、amb_mix 過，build 過。沒有實際聽。

## 還沒做、要注意
散客別館消費上線後賭場平均約 21 人，35 人以上是比較熱鬧的時候；門檻改 config 的 casinoBusyMusic。
