# 0155 水位調快

- 日期：2026-11-24 00:09:50
- 誰決定：翊文
- 狀態：有效（改第 0132 篇的 `step`）

## 背景

Yuga 11-23 賣股票拿到 11.84 億，問水位能不能推進劇情。原本水位每天最多動 0.03（約 0.7 格），從 15/24 到頂至少要 13 天。翊文：

> 「調快水位」
>
> 「並且把歷史紀錄也調整」

## 決定

1. `NUM.casino.pool.step` 從 0.03 改成 0.1：每天 05:00 日報最多動 0.1（2.4 格）。
2. 其他照舊：目標水位看累計賺的（`earnT` 2 億）、連續 `confirm` 3 個日報目標到頂才是門檻那晚。
3. 以前的日子也照新速度補算：改了以後第一次日報（11-25 05:00），這一次可以動 step ×（記過的天數＋今天），等於從一開始就是 0.1。之後每天照 0.1。記在 `house.pool.sv`（補算過的 step），只補一次。
4. 補算以後水位直接到「照賺的錢該在的位置」；賺的還不夠 2 億就停在對應的高度，不會直接到頂。到頂和 confirm 可以同時算。

## 要注意

- 賣股票不會讓水漲：淨值本來就算股票市值，只有淨值變多的部分算「賺的」。
- 一天大漲大跌，水最多動 10%，比以前的 3% 明顯。
- W49、W50 不放水位的規矩照舊（排程說明一之九之五）：門檻那晚落在這兩週，那一句延到 W51。
