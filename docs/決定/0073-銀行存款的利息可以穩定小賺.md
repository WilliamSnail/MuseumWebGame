# 0073 銀行存款的利息可以穩定小賺

- 日期：2026-11-13 15:18:32
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「規劃第五節問題 3：存款利息、館債算不算違反決定 0070 的「不能穩賺」？我提「小額、有上限、由莊家出」，翊文回「可以」」

## 決定

1. 銀行的活存、定存、之後的館債，可以是穩定的小額利息，不算違反決定 0070。
2. 條件：利息由莊家出（不印錢）；莊家破產（≤ 0）時沒有利息；有上限（活存本金最多算 1,000 萬、定存壹筆最多 1,000 萬、最多 3 筆）。
3. 利率順序要守：活存每天 < 定存每天 < 借款每天，借錢來存不會賺（測試擋）。
4. 股票可以借錢買（翊文 11-13：「可以借錢買」），但整體平均要略虧（手續費），照 0070。
