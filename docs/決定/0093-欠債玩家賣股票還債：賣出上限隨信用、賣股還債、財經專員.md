## 第 1 件：壹人壹天的賣出上限隨信用等級

- `NUM.casino.stock.sellDay`（2,000 萬）是 **0 級**的上限；`sellMultByCredit: [[2, 2.5], [4, 5]]`：信用 2 級 ×2.5（5,000 萬）、4 級以上 ×5（1 億）。館外股（`casStockSell`）和館內股（`casInSell`）都用 `casSellCap(w)`。
- **信用等級的算法只有一份**：新檔 `shared/casino_credit.js` 的 `casCreditLevel`（槓桿的 `casLevLevel` 也叫它，不另外算）；`casSellCap`、`casSellNext`、`casSellTip`（「信用升到 2 級可以賣到 5,000 萬。」）。不 import 別的規則檔，所以不會跟股票、槓桿 import 成圈。
- 超過上限的訊息多寫提示；`casStockView`／`casInView` 多回 `sellCap`、`sellTip`（畫面寫「信用升到 N 級可以賣到 X」，版面美術統籌）。
- **守住的**：館內股全館淨賣出上限（`netSellPct`、`netSellFlat`）照舊；館外股外面世界付得出來（`casWorldRoom`）照舊。最高級壹人壹天 1 億 ≤ 外面世界起始（100 億）的 1%（`econ:check` 擋）。
- 改倍數用 `npm run tune -- NUM.casino.stock.sellMultByCredit.0.1=3`。
