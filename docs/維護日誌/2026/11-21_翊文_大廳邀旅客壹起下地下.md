## 為什麼要改

> 「大廳的邀請旅客也不只能去賭場了，現在不是可以去地下室了嗎」（伺服器是 PR 893、899，決定 0149）

## 改了什麼

- 大廳的邀旅客區塊（右欄、手機的精簡列、「全部」視窗，都是 `ui_hallnow.js` 的 `inviteBtn`）在「邀旅客去賭場」旁邊多壹顆「邀旅客壹起下地下」。兩顆包在 `hn-invs`（`display: contents`），不改原本的排法。
- 按下去走 `ADDONS.coopWithNpc`（`ui_coop.js`）：準備區已經開著就不動；有隊伍（`partyOf/我`）就接回去；沒有就先 `coopStep open` 開隊伍，進準備區，那裡的「旅客」那塊可以邀（送禮／不送、被拒、座位滿都照 PR 899 的規則，沒改）。
- 顯示條件：登入、挑戰模式、`NUM.casino.coopNpc.on`，而且館裡有旅客（跟邀去賭場同壹個判斷）。

## 怎麼確認的

- npm test、code:check、ui:check。
- 模擬器自由模式的大廳沒有這個區塊（自由模式不顯示），所以**這顆鈕沒有親眼看過**；跑不過選職業的無頭瀏覽器看不到挑戰模式的大廳。

## 還沒做、要注意

- 實際按下去的流程（沒隊伍開隊、有隊伍接回去、準備區捲到旅客那塊）沒走過。
- 手機精簡列放兩顆鈕可能擠：沒看過，看過再調。
- 沒做「沒按準備區就直接邀」：邀人還是在準備區的旅客那塊按。

## 給下一個人

- 旅客那塊在 `ui_coop_npc.js`；它不能 import `ui_coop.js`（不准繞圈），所以入口放在 `ui_coop.js` 用 ADDONS 登記。
