## 現在有多散（11-10 數的）

- 上方導覽列：12 個入口（11 個房間＋公佈欄）。
- 右上角選單：另外 10 多項（信箱、簽到日曆、每週劇情、兌換所、榜單、賭場、館友、我的帳號……）。
- 賭場裡 9 個頁籤：牌桌、本週收藏、大禮包、拚經濟、實況、餐車、換小獎、成就、財產。

  - 狀態列（籌碼、週章、券、靈感）

## 常見手遊的做法（筆記）

1. **大廳加少數固定入口。** 例如蔚藍檔案、賽馬娘：主畫面是場景，底下只放 4～6 個大分類，其他從場景或大分類進去。
2. **「今天要做的」集中一處。** 原神的冒險之證、崩鐵的每日實訓：簽到、每日、每週、活動排成一張清單，每項有「前往」按鈕直接帶你過去。
3. **收藏集中一本冊子。** 原神的「檔案」、崩鐵的「資料庫」：角色、書、故事、成就都在同一個地方，用頁籤分類。
4. **個人頁和背包分開。** 個人頁放名片、稱號、成就、戰績；背包放各種貨幣和道具。
5. **小遊戲先一頁總覽。** 打開先看到幾格大卡片，每格寫剩幾次、能不能領，點進去才是細節，不一開始就排一整排頁籤。
6. **紅點一層層往上傳。** 裡面有東西沒處理，外層入口就亮紅點，不用每個按鈕各自提醒。

## 第五步：「今天」變成領取中心（11-13 規劃）

翊文 11-13：「還要想介面整合，因為現在有很多東西了，希望要能夠在同一個介面領到各種東西，以及追蹤各種事項」。

### 現在（11-13 看的）

- 「今天」清單（`ui_today.js`）和大廳總覽（`ui_hub.js`）已經把**要做的事**排在一起，每項有「前往」。
- 但是**領東西**還是要一個一個跑：
  - 簽到：簽到面板。
  - 每日任務、全做完那份、每週任務：每週劇情面板，一個一個按。
  - 信箱：館方的信在存檔裡，館友送的、招領處寄的在伺服器，兩種分開領。
  - 留言牌的讚：痕跡那邊。
  - 賭場的本週收藏：賭場。
- **還在進行中的事**散在各房間，沒有一個地方看得到全部：
  - 受傷的佩佩幾天好、怪癖幾天消失。
  - 跟 Yuga 借的錢幾天到期、在地下工作的參觀者。
  - 老主顧走到第幾段、主題展掛了幾天、這週前幾天的特展還有幾幅沒看。

### 要做的

1. **「今天」最上面一顆「全部領取」**：一次把能領的都領掉，最後跳一張總結（靈感 +n、心情 +n、週章 +n、收到的佩佩……）。
   - 包括：簽到蓋章、每週劇情裡做完沒領的（每日、全做完那份、每週）、信箱（存檔裡的和伺服器的）、留言牌的讚、賭場的本週收藏（集滿了才有）。
   - 不包括要自己決定的：開大禮包（要選開幾包）、拚經濟、補做任務。這些留在清單上，照舊按「前往」。
   - 每一樣都用原本的規則函式（`claimTask`、`claimAllMail`、伺服器的 `claimMail` 等），不另外寫一份。
2. **「今天」分三段**：
   - **可以領**：每項一行，寫領什麼，也可以單獨按「領」。
   - **要做的**：現在那些（每日、每週、Yuga Bot 交代的、老主顧在櫃台、大禮包、拚經濟）。
   - **進行中**（新的，只看不按，點了帶過去）：受傷的佩佩、怪癖、借款到期、工作中的參觀者、老主顧進度、主題展、這週前幾天的特展。
3. **紅點只算「可以領」和「要做的」**；進行中的不算，不然紅點永遠消不掉。
4. **大廳總覽的格子**：多一格「全部領取（n）」，有東西可以領才亮。

### 分幾個 PR

1. 「全部領取」和「可以領」那一段，加測試（每一種都領到、領過的不重領、自由模式不給）。
2. 「進行中」那一段。
3. 大廳總覽那一格、紅點。

### 要翊文決定的

1. 「全部領取」要包括「開大禮包」嗎？（建議不要：開包是賭場的樂趣，留給自己按。）
2. 「進行中」上面那幾樣夠嗎？還有沒有想一起追蹤的？
3. 先照這個做第 1 個 PR 嗎？

## 第六步：每個廳一個畫面看得完（11-13 規劃）

翊文 11-13：「介面重塑也是一個新事項，目前每個廳都要很多訊息，要往上下滑才能看到全部」（附委託櫃台的截圖：標題、說明、回大廳、評語、老主顧、壹鍵交件疊在上面，委託單只露出一半，收藏要再往下滑）。

### 做法（跟打怪畫面一樣，`docs/打怪演出規劃.md` 第八節）

- **完成的條件**：電腦 1366×768、手機直拿 375×740，打開一個廳不用捲，就看得到這個廳最主要的東西（委託櫃台＝三張委託單和交件的收藏）。次要的資訊可以收起來，點了才打開。
- **共同的骨架**（每個廳都套）：
  1. **標題一行**：廳名、一句說明（太長就收進「ⓘ」）、回大廳、這個廳的小按鈕（評語、說明）都在同一行，改成圖示加字的小按鈕。
  2. **主區**：這個廳要做的事（委託單、展台、做佩佩的選項……）佔大部分高度。
  3. **側欄**（電腦）或**上面一條可以收起來的帶子**（手機）：次要的（老主顧、壹鍵交件、怪癖的治法、上課和兌換所入口）。
  4. **收藏**放在最下面一條固定的抽屜：平常收成一行縮圖，要拖的時候拉開。
- **先量**：寫一個工具，每個廳用 `#畫面` 打開，量電腦和手機的 `scrollHeight`，排出哪幾個廳最需要改，寫進這一節。
- **一個 PR 改一個廳**，從最常用、最長的開始（委託櫃台、畫廊、手作坊、展廳、地下收藏庫的入口、館長室）。每個 PR 都要三種尺寸量過、截圖。

### 11-13 做了：委託櫃台（第一個套骨架的廳）

- 翊文生了整張介面 U-1～U-3 和零件 P-1～P-3（`assets/ui2/`），切好放在 `web/public/ui2/`。軟木板 Gemini 生不出來，照 U-2 的顏色用程式算了一張（`ui2-cork.webp`）。
- 共通骨架的 class（`web/src/css/ui2.css`），別的廳照這樣套：
  - `.screen.ui2`：整個廳剛好填滿導覽列和狀態列中間，整頁不捲；狀態列排成兩排也量得對（`syncStatusHeight`）。
  - `.room-head`：銅牌（廳名）＋羊皮紙條（一句說明）＋右邊的按鈕，一行。
  - `.u2-main`：主區＋側欄（`.u2-side`）；太多的時候在自己裡面捲。
  - `.u2-side` 裡的每一塊用側欄面板（`ui2-side`）；大按鈕 `.u2-big`（銅牌按鈕）。
  - `.u2-drawer`＋`.u2-pull`：最下面收藏的抽屜，平常一排縮圖，按拉環拉開才有頁籤和篩選；手機橫拿平常只留拉環。
- 委託櫃台：委託單貼在軟木板上（羊皮紙、紅蠟封、老主顧那張掛玫瑰結）；側欄放老主顧和壹鍵交件；上課、兌換所改成標題列右邊兩顆銅牌按鈕（翊文：「上課，兌換所就不構明顯」）。
- 量過：電腦 1366×768、手機直拿 375×740、手機橫拿 740×375 都不用捲。手機直拿的委託單左右滑。
