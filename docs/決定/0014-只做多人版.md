# 0014 第 4 版只做多人版，不做單一 HTML 檔

- 日期：2026-11-08
- 誰決定：翊文
- 狀態：有效

## 背景

- 第 3 版以前，整個遊戲打包成一個 HTML 檔（`build.js`），為了離線、雙擊就能玩。
- 多人版本來就要連伺服器。翊文 11-08：

  > 「新的版本這樣就不用整個遊戲只放在一個HTML檔案了吧，可以動態存取」

## 決定

- 第 4 版只做多人版，做成一般的網站：程式拆成 ES 模組，用 Vite 開發和打包（`npm run dev`、`npm run build`）。
- 不再做單一 HTML 檔，也不做離線版。
- 想離線玩，就玩第 3 版的 `../佩佩博物館3/PepeMuseum3.html`。第 3 版凍結，不再改。
- 「不做離線版」「第 3 版凍結」是照規劃.md 的建議（第五節「不再是一個 HTML 檔」、第十節第 5 題）。紀錄裡找不到翊文對這兩點另外說的原話。

## 影響

- 第 3 版的 14 個檔改成 ES 模組：規則和資料在 `shared/`，畫面在 `web/src/`（階段 9，已完成）。
- 第 3 版的 `build.js`、`serve.js`、預告片（`預告片.html`、`預告片.mp4`、`trailer/`）沒有搬過來。
- 不再共用同一個全域範圍：每個檔用 `import`／`export` 說清楚要什麼、給什麼（`docs/架構.md` 第 4.1 節）。
- 之後可以做：用到才載入房間的程式、檔名加雜湊、劇情由伺服器照時間給（規劃.md 第五節）。
- 要有打包這一步，不能再「打開 HTML 就好」。

## 什麼時候可以再討論

- 翊文想要第 4 版也能離線玩的時候。
