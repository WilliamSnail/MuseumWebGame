# 0085 限定帽子也有能力（簽到 2、兌換所 8、特展 13）

- 日期：2026-11-15 15:00:00
- 誰決定：翊文（「這些東西應該也要有特殊能力…甚至要有一些更特殊的」；「要地下以外的效果，第三級更強一點」）；數字由數值平衡訂
- 狀態：有效
- 提案：`docs/限定配件能力提案.md`（細節和每件的說明）

## 決定

1. **23 頂限定帽子都有能力**，全部寫在 `shared/config.js` 的 `LIMITED_FX`（名字 → 效果）。手作坊的說明、卡片短標、手作坊「隊伍規則」的字都讀這張表，不另外寫壹份。
2. **三種效果**：
   - **探索（走房間）**：全隊強度、技能檢定、少扣理智、擋理智損失、每層第壹次回理智、多壹次重擲、強度下限；單人和多人（`coop.js`）都有。
   - **打怪（壹場壹次的招式）**：借用原本招式的算法（cheer／wizard／cap／squat／beanie／crown／tentacle），數字和次數照表（金冠可用 2 次、淚滴耳環全隊回、火氣頭帶推 ×1.5 不扣理智…）。
   - **館內（地下以外）**：餐車吃的心情／理智、每週簽到靈感、換日回理智／心情、房間第壹次過關靈感。**都是玩家存檔裡的東西，沒有新的籌碼來源**。看「館友證頭像」那隻佩佩戴的帽子（`P.avatar`）。
3. **第三級（特展）比原本四件強壹點**：單頂全隊強度最多 +4（火氣頭帶，有代價）、+3（金冠、金瓜子項鍊）；原本的巫師帽 +2、觸手帽 +5。第壹、二級是小方便。
4. **守住地下的平衡**：限定帽子的全隊強度加起來最多 `NUM.limitedFx.teamCap`（+6，低於巫師帽＋觸手帽的 +7）；同壹頂帽子的非強度效果只算壹次；技能加成取最高，不疊；少扣理智最少扣 1。
5. **有代價的**：火氣頭帶（每層第壹次多扣 1 理智）、躺平眼罩（全隊強度 −1）。
6. **不做**：動籌碼的效果（礦工帽原提案的「撿籌碼 +10%」、黑絨領結的「拍賣手續費 −1%」）。原因：伺服器收到的籌碼請求不知道你戴什麼，會變成誰都能報；改成存檔裡的靈感（礦工帽房間第壹次過關 +1）和換日心情（黑絨領結 +3）。

## 檢查

- `econ:check` 新增兩項：單頂全隊強度 ≤ 觸手帽、`teamCap` ≤ 巫師帽＋觸手帽；館內效果每項 ≤ 3。
- `test/limited_fx.test.cjs`：每頂都有設定和說明、全隊強度與上限、強度下限、少扣／擋／回理智／多扣、館內效果（含頭像沒戴就沒有）、打怪壹回合的招式。

## 還沒決定、之後可以調

- 數字是草稿，看玩家反應調 `LIMITED_FX`。
- 「只有館友證頭像那隻戴的才算館內效果」：想改成「任何一隻收藏有就算」或另開裝備欄，另外決定。
