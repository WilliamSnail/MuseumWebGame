## 改了什麼

- 起因：11-22 我手寫主線揭露音樂那篇日誌，把「為什麼要改」寫成「為什麼改」、「怎麼確認的」寫成「測了什麼、沒測什麼」，又漏了「還沒做、要注意」。ship 跑了快 3 分鐘的 npm test 才擋下來。
- 新增 `npm run log:fix`（tools/check/log_fix.cjs）：只動這個分支新加、改過的日誌。很接近的標題改成範本的寫法；「還沒做、要注意」「給下一個人」可以沒內容，漏了就補「- 沒有」。
- 「為什麼要改」「改了什麼」「怎麼確認的」要真的有內容，不自動補，照樣報錯。
- ship：跑測試前先跑 log:fix，格式還是不對就馬上停，不用等 npm test。
- log_check：報「少了標題」時多一行提示，叫人用 log:fix、寫新日誌用 doc:new。
- 這篇日誌本身就是用 doc:new 寫的。
