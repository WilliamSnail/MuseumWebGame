# 0154 取消一人一天賣出上限

- 日期：2026-11-23 23:04:02
- 誰決定：翊文
- 狀態：有效（取代第 0093 篇的第 1 件）

## 背景

翊文問「股票有一天只能賣 2000 萬的限制嗎」，聽完說明後說：

> 「有的話把它取消」
>
> 「今天把它取消」

原本館外股、館內股一人一天最多賣 2,000 萬，信用 2 級 ×2.5、4 級 ×50（決定 0093）。

## 決定

1. `NUM.casino.stock.sellDay` 改成 0，代表一人一天賣出不限。館外股、館內股都一樣。
2. `casSellCap` 遇到 0 回傳 Infinity。畫面拿到的 `sellLeft`、`sellCap` 是 null，不再寫「今天還能賣多少」，也沒有「信用升到幾級可以賣到」的提示。
3. 規則和 `sellMultByCredit` 都留著。之後 `sellDay` 改回大於 0，就照信用等級算，不用改程式。

## 照舊、沒動的

- 館內股的全館一天淨賣出上限（`netSellPct`、`netSellFlat`）照舊，用來守住莊家。
- 館外股的錢由外面世界付，外面世界付不出來照樣會擋（`casWorldRoom`）。
- 槓桿一天淨賺上限（`profitCap`）、集團股一人一天成交量（`gstock.dayVolPct`）不受影響。

## 要注意

以前這個上限擋的是多頭時一口氣兌現大量獲利、館裡的錢變多。拿掉以後，靠的是手續費、證交稅、持有成本，和外面世界的上限。上線後看幾天財報裡股市讓館裡多了多少。
