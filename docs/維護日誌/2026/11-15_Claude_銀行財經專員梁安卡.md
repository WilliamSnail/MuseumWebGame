## 為什麼要改

> 「決定 0093 第 3 件：欠了不少錢，金融集團的財經專員梁安出來排還款計畫，每項都要館友同意才動。伺服器和資料早就有了，這次只做畫面。」

## 改了什麼

- 銀行「借款」頁多一張「財經專員」卡（advisorPanel）：頭像（先用圓形加「梁」字的剪影）、名牌、壹句開場白、現在欠多少。
- 卡內分兩項：借款延期（延到哪天、手續費、延完要還多少；不能延的寫原因）、賣股還債（照伺服器排的順序，館內股先；寫賣幾股、約還多少、夠不夠）。
- 每項都有「同意」鈕，先跳確認視窗才送：延期送 casino advisor／extend，賣股送 casino stock／sellDebt。
- 有專員資料（advisor.need）就用這張卡代替原本的「賣股還債」卡，沒有就照舊顯示原本那張，不重複。
- 示範資料 fakeBankHall 加了壹份假 advisor，開發畫面看得到。bank.css 新增 bank-adv- 開頭的樣式（前綴沿用 bank-）。

## 怎麼確認的

- npm run dev 開 #bank:report 點借款：電腦 1366x768、手機直拿 375x812 都照過，字有對比、按鈕看得出能按。
- npm test 全過。

## 還沒做、要注意

- 梁安的頭像還是剪影，要生圖（建議：胸像，穿深藍西裝、拿壹本還款計畫，綠背景，跟其他 NPC 頭像同尺寸）。
- 沒接過真實伺服器資料：同意延期、同意賣出只在示範資料看過畫面，還沒在模擬器登入實際按過。
- 確認視窗沒有另外照圖。
