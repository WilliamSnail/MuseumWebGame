# 0026 遊戲裡的「現在」照網路上的時間

- 日期：2026-11-09 00:42:03
- 誰決定：翊文
- 狀態：有效，11-09 做了（`維護日誌/2026/11-09_翊文_真實的一天.md`）

## 背景

- 決定 0019：一天＝台灣時間 05:00 換日，「伺服器說了算」，瀏覽器不自己用電腦的時鐘決定（避免改電腦時間）。
- 11-09 做真實的一天時，「今天」先照玩家電腦的時鐘算。電腦的時間不準、或玩家自己改時間，「今天」就跟別人不一樣。
- 翊文 11-09：

  > 「遊戲裡的內容也是跟著那網路抓取的真實時間時間」

## 決定

- 遊戲裡的「現在」一律照網路上的時間，不照玩家電腦的時鐘。大家同步，改電腦時間也沒用。
- 換日、換週、每天的次數、每週的活動、公佈欄、信箱、館友「幾分鐘前來過」都照這個時間。
- 網路的時間：Firebase Realtime Database 的 `.info/serverTimeOffset`（Firebase 給的「伺服器時間 − 這台電腦的時間」）。
- 還沒連上（還沒登入、離線）之前，照電腦的時間。
- 畫面上動畫的計時（`setTimeout`、多久沒動算「暫停」「離開」）不用改，那是量「過了多久」，不是「現在幾點」。

## 影響

- `shared/logic.js`：`NOW_CLOCK`、`setNowClock`、`nowMs()`。規則裡要「現在」一律用 `nowMs()`，不要直接 `Date.now()`。`todayStr()`、`secToNextDay()` 不給時間時用它。
  - 這三個跟 `claude/怪癖二十分鐘` 分支一模一樣，合併時保留一份。
- `web/src/net_firebase.js`：登入連上之後讀 `.info/serverTimeOffset`，`setNowClock(() => Date.now() + 差)`。差會自己更新。斷線、登出時留著最後一次的差（不改回電腦的時間，不然連線斷斷續續會讓「今天」跳來跳去）。
- `web/src/ui_login.js`：館友「幾分鐘前來過」跟網路的時間比（`lastSeen` 本來就是伺服器的時間）。
- Cloud Functions 本來就是伺服器的時間，`nowMs()` 在那裡就是 `Date.now()`。現在 `functions/` 沒有用到「今天」。
- 測試：`setNowClock` 換掉時，`todayStr`、`secToNextDay`、換日、每週活動都照換掉的時間走（`test/logic.test.cjs`）。

## 什麼時候可以再討論

- 不用 Firebase 了（換別的後端），要換一種拿網路時間的方法。
- 要「離線也照網路的時間」（例如把上次的差存起來）的時候。
