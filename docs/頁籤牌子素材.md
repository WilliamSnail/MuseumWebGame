# 頁籤牌子素材（六種材質）

> 翊文 11-14 生的（`docs/介面重塑素材清單.md` P-13，原圖 `assets/ui2/P-13_tab-plates.webp`）。「這些以後都可以保留，分類一下看哪些頁籤適合在哪個介面用。」
> 切好的零件在 `web/public/ui2/ui2-tabx-<材質>-1.webp`（平常）、`-2.webp`（選好）。每塊約 480×80，中間留空，字讓程式寫；用 `border-image` 切九宮格，邊 14px。
> 舊的黃銅牌是 `ui2-tab-1.webp`、`ui2-tab-2.webp`（現在畫廊、館長室、圖書館在用）；新的 `brass` 是同一種材質的新版，邊更平整。

## 一、六種材質：樣子、字色、適合的介面

| 材質（檔名） | 樣子 | 字色（平常／選好） | 適合哪個介面 | 為什麼 |
|---|---|---|---|---|
| 黃銅 `brass` | 舊銅平牌，選好是亮銅帶光 | 深棕 `#1A0F06`／同 | 畫廊、設定、大廳之外的「預設」 | 跟現在的牌子（標題銅牌）同一種，換上不突兀；金色跟畫框一致 |
| 胡桃木 `wood` | 深木紋＋銅角，選好是蜂蜜色木 | 淡金 `#F3E0B0`／深棕 `#2A1608` | 圖書館、手作坊 | 書架、工作台都是木頭；字亮在深色上看得清楚 |
| 酒紅皮革 `leather` | 酒紅皮、金色縫線，選好更紅更亮 | 米金 `#F7E3B0` | 館長室、抱枕工作台 | 辦公室的皮椅、軟的東西；跟酒紅牆紙一國 |
| 羊皮紙 `parchment` | 米白紙、細墨框、銅鉚釘，選好是紅蠟邊 | 深棕 `#3A2410` | 圖鑑室、公佈欄、兌換所 | 紙的東西；是唯一的淺色牌，字用深色 |
| 墨綠絲絨 `velvet` | 深綠絨、金色細繩邊，選好是亮翠綠帶金光 | 淡金 `#F3E3A8` | 賭場 | 牌桌的綠；金邊跟籌碼一國 |
| 石板 `slate` | 深灰石、鐵邊鉚釘，選好是淺石帶藍色符文光 | 淡藍白 `#E6EEF4` | 融合室、地下收藏庫、銀行 | 冷色、有魔法或金屬的感覺；銀行是深藍底，石板的冷灰最搭 |

## 二、每個介面用哪一種（11-14 已套用：圖書館、畫廊、館長室、圖鑑室、銀行）

| 介面 | 用哪一種 | 狀態 |
|---|---|---|
| 圖書館 | 胡桃木 `wood` | 已換 |
| 畫廊 | 黃銅 `brass`（新版） | 已換 |
| 館長室 | 酒紅皮革 `leather` | 已換 |
| 圖鑑室 | 羊皮紙 `parchment` | 已換 |
| 銀行 | 石板 `slate` | 已換 |
| 賭場 | 墨綠絲絨 `velvet` | 還沒換（賭場還沒套 onescreen 骨架） |

## 三、怎麼換（不要每個廳各寫一次）

- 實作在 `web/src/css/tabx.css`（最後載入）：每個廳的根 class 設四個變數（圖、字色、陰影），牌子的 `border-image` 讀變數。新的廳要用，就在那個檔加一行變數。
- 變數：在每個廳的根 class 設兩個 CSS 變數：`--tabx-1: url(/ui2/ui2-tabx-wood-1.webp)`、`--tabx-2: url(/ui2/ui2-tabx-wood-2.webp)`、`--tabx-ink`（平常的字色）、`--tabx-ink-on`（選好的字色）。
- 頁籤的 `border-image` 讀這兩個變數（目前各廳 css 各抄一份，之後合成一份）。
- 計數（「4・2 沒讀」）不要灰色小圓牌，直接寫在牌子上，用小一點的字（圖書館 11-14 已經這樣做）。
- 暗色牌（木、皮革、絲絨、石板）的字要加 `text-shadow: 0 1px 0 rgba(0,0,0,.6)`；亮色牌（黃銅、羊皮紙）加 `rgba(255,240,200,.7)`。

## 四、沒做的

- 只生了頁籤牌子，沒生「段落小標題」「計數牌」「選項牌（含鎖著的）」，要換整套再生。
- 手機直拿、橫拿的小尺寸（高度 30～38px）下，牌子邊 14px 太粗，要用 6～8px；圖書館已經這樣縮。
