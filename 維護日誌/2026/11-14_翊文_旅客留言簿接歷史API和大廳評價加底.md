## 為什麼要改

> 「主 session：旅客留言簿的資料 API 上線了（PR 421），請接上：按日期前後翻、選一位 NPC、每則星星＋誰＋時間＋內容、沒資料寫「還沒有旅客留言」」
>
> 「大廳那一塊可以給個底，不然有點難看的到字」

## 改了什麼

- 圖書館「旅客留言簿」改接 NET.call("casino", { act: "reviews", day, who, limit: 50 })：左邊「‹ 前一天／日期／後一天 ›」照 prevDay、nextDay 翻（沒有就按鈕變灰）；旅客用小圓鈕選一位（傳 who，換人就回到有資料的最新一天）；右邊列星星、內文、誰・幾分鐘前；標題寫「日期　共 N 則」；沒資料寫「還沒有旅客留言」；讀失敗寫「現在讀不到留言簿」。旅客名單是看過的名字累積起來（最近 20 則加翻到的）。
- 沒登入的開發環境用示範資料。
- 大廳右欄「展廳現在有 N 人」那塊加深色底、金色細框，字改亮色。
- 加館方公告 library-gb2。

## 怎麼確認的

- 電腦 1366×768：留言簿示範資料版面對、大廳右欄那塊有底、整頁不捲（右欄 577px 沒變）

## 還沒做、要注意

- 真的 reviews API 沒登入看過：prevDay、nextDay、who 篩選、total 都是照主 session 給的格式寫的
- 旅客名單只收看過的名字，沒看過的 NPC 要先翻到他留言的那天才會出現（API 沒有給名單）
- 手機直拿、橫拿的留言簿日期翻頁沒量
