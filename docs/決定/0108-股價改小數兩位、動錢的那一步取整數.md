# 0108 股價改小數兩位、動錢的那一步取整數

- 日期：2026-11-16 22:00:00
- 誰決定：翊文（「選③：小數兩位含槓桿」；Yuga 轉達）
- 狀態：有效（補充決定 0107；取代 0107 第 2 點裡「整數價會凍住」的取捨）

## 為什麼

七支非科技台股（決定 0107）真實價只有 30～141 元，翊文要照真實價 ×1、不乘倍數。遊戲價如果還是整數，一個籌碼的跳動是 0.7～3.3%，比真實 15 分鐘的 0.3～0.45% 大，價格會凍住再跳。所以價格改成小數兩位。

## 決定

1. **所有館外股（台股、美股）的價格用小數兩位**：`H.px`、`H.prev`、`H.hist`、盤中每分鐘的價、掛單價、槓桿進場價、強平價、停損停利價。新的取價函式 `stPx`（四捨五入到兩位）。舊存檔的整數價照常讀（整數也是合法的兩位小數）。
2. **錢包的籌碼、成本、手續費、稅、損益、保證金、部位全部維持整數**。每次真的動錢，在那一步取整數，方向寫死：

   | 步驟 | 怎麼取整 | 誰吃虧 |
   |---|---|---|
   | 買進成本（現股、限價買鎖錢、換股數的成本、舊持股補成本） | 無條件進位（`stBuyCost`） | 玩家多付不到 1 籌碼 |
   | 賣出收入、持股市值（`stSellGet`、`stValue`） | 無條件捨去 | 玩家少拿不到 1 籌碼 |
   | 手續費、借券費、利息 | 進位（跟以前一樣） | 玩家 |
   | 資本利得稅 | 捨去（跟以前一樣） | 玩家少繳 |
   | 成本照比例賣出 | 捨去（跟以前一樣） | 稅多一點點 |
   | 槓桿損益 | 價差用「分」算 × 股數，**四捨五入**（對稱，賺賠都一樣；不偏玩家也不偏外面世界） | 兩邊都不偏 |
   | 槓桿部位、保證金 | 部位進位、保證金＝部位÷倍數進位（跟以前一樣） | 玩家 |
   | 換股數的零頭 | 市值捨去後換股數、零頭用籌碼補（從外面世界來，跟以前一樣） | — |

   不做的事：不允許「碎股」，股數一樣是整數。
3. **強平價用「分」逐分往內找**（`casLevLiqPx`），保證「剛好碰到」的那一分價，再靠近一分就不碰到；強平、停損、停利的判斷全部用整數比較（損益是整數）。
4. **畫面**：價用 `casPx`（整數寫整數，有小數寫兩位）；掛單、停損停利輸入框 `step` 0.01；確認單的總價用同樣的進位、捨去算。
5. 館內五家店（`casino_stock_in.js`）不動，價格還是整數（它的價本來就是整數籌碼，跟外面無關）。
6. 七支新台股拿掉 `peg.byId`（×10／×20），全部 ×1。決定 0107 跟著改。

## 為什麼這樣取整

- 玩家買賣來回一次，只會少（進位＋捨去＋手續費），不會多：測試每種價和股數都驗過（`stock_decimal.test.cjs`）。
- 槓桿損益用四捨五入而不是一律對玩家不利，因為做多做空、賺錢賠錢要一樣公平，不然放空永遠比做多吃虧。玩家能靠挑股數佔到的最多是每筆 0.5 籌碼，比手續費小很多。
- 守恆：所有帳都是整數，`casBookGap` 在每一步（買、賣、掛單、開倉、平倉、強平）驗過是 0。

## 不做

- 不做碎股、不做小數籌碼。
- 不改手續費率、稅率、槓桿規則、曝險上限。
