# 0017 公佈欄是導覽列的頁籤，公佈欄和信箱蓋在整個畫面上，設定收進「選單」

- 日期：2026-11-08
- 誰決定：翊文
- 狀態：有效

## 背景

- 規劃.md 第四節原本寫：公佈欄的入口在大廳右上角，一塊黃銅框。
- 做的時候先放成導覽列右上角的小圖示。翊文 11-08 看了之後說了三件事：

  > 「館內公佈欄 應該也要是個TAB，放在下面玩家注意不到」

  > 「可以做 "漢堡菜單" 查一下， 把設定和公告相關的放進去」

  > 「信箱，公佈欄應該可以在整個畫面最上面覆蓋，像真的公告欄一樣」

- 查了漢堡選單的做法（NN/g 等）：
  - 三條線的圖示大部分人認得，但還是建議旁邊寫「選單」兩個字。
  - 選單適合放不常用的東西（設定、帳號）。重要的東西藏進去，玩家就不會發現。
  - 要能用 Esc 關、用鍵盤走。

## 決定

- **公佈欄是導覽列的頁籤**，放在大廳右邊。重要的沒讀：紅色火漆印；一般的沒讀：金色小圓點。頁籤上不寫數字。
- **右上角一個「選單」按鈕**，每個寬度都有，三條線旁邊寫「選單」：
  - 裡面：公佈欄、信箱、設定；手機上還有房間。
  - 按鈕上有數字＝沒讀的公告＋沒領的信。有重要的沒讀，數字是紅的。藏進去的東西才不會被忘記。
  - 原本右上角的齒輪（設定）收進選單；聲音的開關留在外面（常常要按）。
- **公佈欄和信箱不是房間**，按了不換畫面，是一層蓋在整個畫面上（導覽列、狀態列也蓋住）：
  - 公佈欄：木框＋軟木板，公告是用圖釘釘上去的紙，沒讀的蓋紅色火漆。
  - 信箱：木框＋綠絨布，一封一個信封。
  - 手機上鋪滿整個畫面。
- 公佈欄還是重要的東西，所以兩個地方都有：頁籤（看得到）＋選單（找得到）。進館時有新公告也會自己打開。

## 影響

- `web/src/ui_core.js`：`buildNav`（頁籤、選單）、`openPanel`、`toggleMenu`、`updateBoardBadges`。
- `web/src/ui_board.js`：`overlay`（蓋在畫面上的木框）、`openBoard`、`openUrgent`、`openMailbox`、`autoBoard`。
- `web/src/css/board.css`：頁籤的火漆印、選單、木框、軟木板、信封。
- `shared/notices.js`：公告裡寫入口在哪裡的句子。
- 規劃.md 第四節「館內公佈欄」的「入口」改成這樣。
