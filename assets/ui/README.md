# 介面素材（先存起來，還沒接進遊戲）

- `panel-wide.png`：橫向的鎏金面板框，1024x254，酒紅天鵝絨中間是空的，綠底已去掉。`_panel-wide-src.png` 是原圖。
- 用法：適合大廳的標題橫幅、活動預告條、大按鈕底板。
- 能不能拉伸：左右兩端是尖角和渦卷花紋，上下中間各有壹個裝飾。要拉長時，**兩端和中間的裝飾不能跟著拉**，要切成「左端、中間（可重複或拉長）、右端」三段（三切片），不是九宮格。
- 授權要翊文確認；不要放 Pepe the Frog 的樣子（決定 0005）。
- 不在 `web/` 底下，不會進 `dist/`。

- `card-done.png`：做完的卡，灰綠羊皮紙、右下角有勾勾章（勾勾位置固定，文字要避開右邊）。

## 大按鈕

- `button-big-pressed.png`：大按鈕「按下」的狀態，1024x254，圓角、只有四角有花紋、中間平，可以九宮格拉伸。酒紅絨面比較暗，像壓進去。原圖 `_button-big-pressed-src.png`。

- `button-big-hover.png`：大按鈕「懸停」的狀態，1024x254，銅框比較亮、絨面比較紅，外圈有薄薄的暖金光（原圖的綠色光暈已改成暖金色）。原圖 `_button-big-hover-src.png`。跟 pressed 同尺寸。還缺：正常（沒存）、不能按。
