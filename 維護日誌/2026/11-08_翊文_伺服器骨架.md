## 改了什麼

- **伺服器 `server/`**（Node，ES 模組，`npm run server`，port 8787，只聽 127.0.0.1）：
  - HTTP API：`GET /api/health`、`POST /api/login`、`POST /api/logout`、`GET/PUT /api/me`（暱稱、隱身）、`GET/PUT /api/save`。
  - WebSocket `/ws`：`hello`（帶 token）→ `welcome`；`beat`（心跳）；`where`（在哪個房間）；伺服器送 `roster`（館友名單）、`error`。
  - 正式環境（`NODE_ENV=production`）發 `dist/`；開發時網頁照舊走 Vite。
- **登入轉接層 `server/auth/`**：`dev.js`（帶名字就登入，email 是「名字@dev.local」；正式環境建立時就丟錯誤）、`firebase.js`、`access.js`（還沒做，回 501）。全部只回傳 `{ email, name }`。
  - 正式環境照 `ENTRY` 選：`ddns`→Firebase、`tunnel`→Access。設 `AUTH=dev` 會開不起來。
- **邀請名單**：資料表 `invites`；只有名單上的 email 能登入，開發時 `@dev.local` 例外（`DEV_OPEN`）。拿掉＝標停用，不刪；拿掉後 token 馬上失效。小工具 `node server/invite.js list|add|disable`。
- **資料庫 `server/db.js`**：`node:sqlite`、WAL。搬家檔在 `db/`（`0001_帳號和邀請.sql`、`0002_存檔和快照.sql`），照編號跑、記在 `schema_migrations`（含內容的 SHA-256）。跑過的檔被改了就不開；搬家檔裡不准 `DROP`、`RENAME`、`DELETE`。
- **存檔**：整份存，`PUT` 要帶 `baseRev`，對不上回 409（別的分頁先存了）。被蓋掉的那份隔 10 分鐘以上留一份快照，每人留最近 20 份。最大 1 MB。
- **在線名單**：連上算在線；5 分鐘沒動算「離開」；60 秒沒心跳算離線並斷線（4010）；斷線後等 5 秒才算離線（重新整理不會閃）。隱身：別人看到離線，「最後上線」停在變隱身的那一刻。名單裡沒有 email。
- **每則訊息檢查大小、次數**：一則最多 4 KB（超過 1009 斷線）；一口氣 20 則、之後每秒 2 則；送錯 10 次斷線（4008）；一個帳號最多 5 條。HTTP 也限次數（每 IP、登入、存檔各一個桶子）。
- **訊息格式 `server/protocol.md`**：每種訊息的欄位、錯誤代號、關閉碼、之後的邀請／招募／合作關卡怎麼加（預計的名字先列好）。程式那份在 `server/protocol.js`。
- **`server/README.md`**：怎麼開、環境變數、檔案、邀請名單、資料庫的規矩、上 homelab 前伺服器這邊要補的（對照規劃.md 第五節 A0–A8、B1–B6）。
- **`web/src/net.js`**：瀏覽器端的連線模組（`NET`）。登入、`restore`、讀存檔、`save`／`saveSoon`／`flush`、WebSocket 連線和斷線重連（1、2、4……秒，最多 30 秒）、`where`、事件 `roster`／`arrive`／`leave`／`status`／`logout`／`conflict`。**沒有任何畫面 import 它**，用法寫在檔頭。
- `vite.config.js`：只加 `proxy`（`/api`、`/ws` → 127.0.0.1:8787）。
- `package.json`：加 `"server"` 這一行 script、`ws`（放 dependencies，正式環境要用）；`package-lock.json` 跟著更新。
- `test/run_all.cjs`：加一行「遊戲伺服器」。

## 怎麼確認的

- `test/server.test.mjs` 29 項（暫存的資料庫、隨便一個 port，時間改短，整支約 6 秒）：
  - 健康檢查；沒登入、token 不對回 401。
  - dev 登入：header、網址、body 都可以；同一個名字同一個帳號；沒名字、名字有空白被擋。
  - 存檔存了讀得回來；舊的 rev 回 409 而且沒被蓋掉；格式不對、沒 rev、太大、不是 JSON 被擋；快照只留最近 3 份（測試設 3）；別人的存檔讀不到。
  - 暱稱：空的、太長、零寬空白被擋。
  - 兩個假玩家：A 收到 welcome；B 上線 A 收到名單；B 換房間 A 看得到；B 隱身 A 看到離線、B 自己看到在線；名單沒有 email；B 斷線 A 看到離線和最後上線；C 不送心跳被斷（4010）、A 看到離線。
  - 訊息：不是 JSON、不認得、欄位錯回 error（id 帶回 `re`）；超過 4 KB 斷線（1009）；送太快回 rate_limited、再送斷線（4008）；不送 hello（4002）、token 錯（4001）、先送別的（4001）、版本錯（4000）。
  - `net.js` 在 Node 裡：登入、讀存、存、saveSoon 合成一次、別人先存的 conflict；連線、where、別人上線下線的事件、被切斷自己重連而且補送房間。
  - 邀請名單：不在名單上 403；加進去可以；停用後 token 失效、停用不是刪掉。登入試太多次 429。
  - 正式環境：`AUTH=dev` 開不起來、沒 `DB_PATH` 開不起來、預設照入口選 Firebase／Access、登入回 501。
  - 搬家：照編號、跑過不再跑；改過的檔不開；DROP、跳號被擋；`db/` 每個檔都只加不刪。
  - 關伺服器：連著的收到 1001，最後上線有記下來。
- 測完暫存的資料夾都刪掉了（`os.tmpdir()` 裡沒有留下 `pepe4-server-test-*`）。
- `npm test` 全部通過；`npx vite build` 成功。
- 真的開 `npm run server`：`curl /api/health` 直接打和透過 Vite（`localhost:5173/api/health`）都通；兩個 ws 假玩家透過 `ws://localhost:5173/ws` 看到對方在畫廊、斷線 5 秒後離線。
- 正式模式（`NODE_ENV=production`、port 8788、暫存的資料庫）：首頁 `no-cache`、`/assets/` 長期快取；`/../package.json` 讀不到；`?user=`、`X-Dev-User` 的 dev 登入被擋（501）；`Origin` 是別的網站的 WebSocket 回 403。

## 給下一個人

- **規則不要寫在 server/**：擲骰、結算照舊寫在 `shared/`（純函式、`RNG()`），伺服器 import 同一份。`server/` 只管連線、登入、存、轉送。
- 加新的 WebSocket 訊息：`server/protocol.js` 的 `CLIENT_MESSAGES` 加欄位 → `server/app.js` 用 `gateway.on()` 接 → `server/protocol.md` 加一列 → 測試加一項（`protocol.md` 第四節）。`web/src/net.js` 沒有 import `protocol.js`，版本號和「不要重連的關閉碼」是抄過去的，改了兩邊都要改。
- `tools/check_imports.cjs` 也會掃 `web/src/net.js`：它 export 的 `NET`、`createNet`、`NetError` 不能跟別的檔重複。
- 開發用的資料庫在家目錄 `~/.pepe-museum4/dev.db`，不在專案裡（不會進 repo，也不會被 OneDrive 同步到一半）。正式環境一定要設 `DB_PATH`，放在 releases 外面。
- Windows 上用背景跑 `npm run server`，停掉 npm 之後 `node server/main.js` 可能還活著（port 還被占著）。用命令列找 `server/main.js` 那個 node 再關，不要把 Vite 一起關掉。
- 開發登入的 header `X-Dev-User` 只能放英文字，中文要 `encodeURIComponent`；`net.js` 用 body 的 `name`，沒有這個問題。
- 網址 `#畫面` 會清掉瀏覽器存檔（`pepeMuseum3`），但不會清 `net.js` 的登入（`pepe4.session`）。
- 測試的時間都改短（心跳逾時 1.5 秒、斷線寬限 0）。等名單時要先看「現在的名單」再等下一份，同一份名單可能已經先到了（測試裡的 `rosterIs`）。
- Vite 的 proxy 寫死 8787；改了伺服器的 `PORT`，`vite.config.js` 也要改。
