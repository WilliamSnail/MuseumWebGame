## 為什麼要改

翊文想要一張「聲音和畫面特效的總表」，好追蹤和改進，而且要自動產生、自動檢查；另外加 Pixabay 音效這幾天都是手動做的，要變成一個指令。

## 改了什麼

- `tools/fx_report.cjs`（`npm run fx:report`，`-- --check` 只比對）：從程式掃出 `docs/音效與特效總表.md`。
  - 聲音：音效檔（`shared/sfx_files.js`）、合成音（`fx.js` 的 `R`）、各房間環境音（`AMB`）、地下 `FLOOR`／`MODE`、`AMB_OF`、`AMB_MIX`、理智的聲音規則、銀行的音效 slot、全部觸發點（`snd`／`sndFile`／`fileOnce`／`fileLoop`，含檔:行、函式、音量）、沒人用的、沒登記的。
  - 畫面特效：房間效果、理智效果、FX 工具、地下戰鬥特效、門檻速查。這幾項是 `fx_report.cjs` 裡一張清單，每項帶一個標記去程式裡找行號；標記找不到會報錯（程式改名時會被抓到）。
  - 翊文聽過／要調：讀 `content/fx_notes.json`（新項目跑 `fx:report` 會自動補 null）。
- `tools/sfx_add.cjs`（`npm run sfx:add`）：Pixabay 檔名拆作者／編號、抓網頁 title 拿原名和作者（抓不到要手動給 `--url --name --by`）、ffmpeg 壓縮（一般或 `--loop` 頭尾交叉淡化）、登記 `shared/sfx_files.js` 和 `來源.md`、備份原檔到 `.claude/交接/音效/原檔/`、印出接下來要做的。
- 測試：`test/fx_report.test.cjs`（解析正規式＋總表是最新的）、`test/sfx_add.test.cjs`（檔名、title、登記）。

## 怎麼確認的

- `npm run fx:report -- --check` 過；改一行 `fx.js` 後 `--check` 會失敗並提示跑 `npm run fx:report`。
- `sfx:add` 用現有的 wind.mp3 實跑一次（`--loop --trim 2:20`），輸出 15 秒單聲道，登記兩個檔都有加；之後還原。
- 總表裡的行號會隨程式移動，所以改了 `web/src/*.js` 之後要重跑一次 `npm run fx:report`（CI 會提醒）。

## 還沒做、要注意

- 「沒人用的」目前是 0，因為判斷很保守：合成音只要名字以字串出現在有 snd／sound／play 的行就算用到，音效檔只要引號字串出現在 web/src 就算用到。
- 畫面特效那張清單（`tools/fx_report.cjs` 的 VFX）是手寫的，新增畫面特效時要自己補一列（總表不會自己發現新的 CSS 效果）。
- 聲音沒有人聽過，翊文聽過、要調的寫在 `content/fx_notes.json`。

## 給下一個人

改了 `web/src/*.js`、`fx.js`、`shared/room_mood.js`、`shared/sfx_files.js` 後，`npm test` 會因為總表行號不一樣而失敗：跑 `npm run fx:report` 再 commit 就好。多個 PR 同時改總表衝突時，合併後重跑一次 `npm run fx:report`。
