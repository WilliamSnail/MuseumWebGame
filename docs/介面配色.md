# 介面配色和字級

> 11-13 建（美術統籌的 session）。翊文：「各種顏色、字體等等的有沒有平衡也要看看喔」。
> 給之後改每個廳的人看。變數寫在 `web/src/css/onescreen.css` 最上面（`.onescreen-room` 上），套了骨架的廳都拿得到。

## 為什麼要有

11-13 量地下收藏庫入口：一個畫面裡有 16 種字的大小、22 種字色。很多是各個檔案各寫各的（`#3A2A20`、`#2E2014`、`#3A1E10` 其實都是「深咖啡字」）。
看起來亂，也容易在淺底上放淺字（11-13 展廳側欄就是這樣）。

## 字色：看底是深的還是淺的

| 底 | 變數 | 色 | 用在 |
|---|---|---|---|
| 淺（羊皮紙、銅牌、名牌） | `--ink` | `#2E2014` | 內文 |
| 淺 | `--ink-soft` | `#5A4030` | 說明、次要的字（不要再淡，`#7A5A2A` 在羊皮紙上太淡） |
| 淺 | `--ink-accent` | `#8E2A24` | 標題、大數字（酒紅） |
| 淺 | `--ink-good` | `#1F5A2C` | 好處、加成（綠） |
| 深（木頭、石牆、深色板子） | `--paper` | `#F3E6C4` | 內文 |
| 深 | `--paper-soft` | `#D8C59A` | 說明 |
| 深 | `--paper-gold` | `#F3DFA6` | 標題、名字 |

- **淺底只用 `--ink` 那組，深底只用 `--paper` 那組。** 換底的時候字色要跟著換。
- 不好的（扣理智、受傷）用 `--ink-accent`，再加粗。不要另外發明紅色。
- 銅牌按鈕（`/cellar2/ui-sbtn.webp`、`/ui2/ui2-tab-*.webp`）是淺底，字用 `--ink`。
- `.sc-kicker`（story.css）是 `!important` 的金色，放到淺底上會看不到，要用 `!important` 蓋掉（地下入口踩過）。

## 字級：只用四級

| 變數 | 大小 | 用在 |
|---|---|---|
| `--type-tiny` | .6875rem（11px） | 標籤、小牌、最不重要的說明。**電腦上最小就這麼小** |
| `--type-small` | .75rem（12px） | 說明、名牌上的資料 |
| `--type-body` | .875rem（14px） | 內文、列表的標題 |
| `--type-head` | 1.05rem | 側欄每一塊的標題 |

- 廳名（銅牌）、大數字（隊伍強度）、大按鈕（下到 B1）是例外，各自一個大小。
- 手機最小 .625rem（10px）；再小就看不到了。

## 字體

- 中文跟著遊戲原本的設定（微軟正黑體這類）；數字、B1 這類英文字是 Georgia（襯線）。這兩種就好，不要再加。

## 還沒做

- 委託櫃台、展廳還是寫死的色碼（跟這組是同一家的顏色），下次動到那兩個廳順便換成變數。
- 地下室其他畫面（打怪、地圖選路）有自己的一套，還沒對過。
