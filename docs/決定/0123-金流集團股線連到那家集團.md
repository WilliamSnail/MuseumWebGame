- 日期：2026-11-17 22:30:00
- 誰決定：翊文（11-17：「補好」）
- 狀態：已決定

## 決定
1. 集團增資（gRaise）、庫藏股（gBuy）、股利（gDiv）原本線只到整個「外面世界」。現在照集團分開記一份累計（`house.led.units`，key 是 `種類|從|到`，跟集團之間的交易同一套，只記累計不記明細）：增資＝莊家 → 那家集團、庫藏股＝那家集團 → 莊家、股利＝那家集團 → 館友。金流頁籤的線兩端是那家集團。
2. 這三種來源有照集團分的線時，不再重複掛在「外面世界」那條（`casFlowEdges` 的 `grp` 標記）。
3. 海外（真實市場）節點可以是負數，照實顯示，節點說明寫「負數＝館友在真實市場賺回來的，比投出去的多」。其他節點照舊不低於 0。
4. `wtCard`（集團之間的交易週報）只看 `trade` 開頭的種類，不被新種類混進去。
5. 沒動任何錢的搬動，只多記一份累計。
