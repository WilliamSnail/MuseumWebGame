# 本機用 Firebase 模擬器登入、看賭場和其他要登入的畫面

> 給所有 AI（和人）：賭場、銀行、展廳的訪客、拍賣這些畫面都要「登入伺服器」才開得起來（沒登入會直接擋），所以光用 `npm run dev` 的 `#畫面` 看不到。
> 這份寫「在自己的電腦上開模擬器、登入一個假帳號、給它籌碼和資料、用無頭瀏覽器照下來」。全部只連 `127.0.0.1`，碰不到正式的 Firebase，帳號和資料都是假的。
> 測試 session 11-14 寫，每一步都跑過。

## 1. 開環境（一個指令）

```bash
npm install && npm --prefix functions install     # 第一次，新的 worktree 也要
npm run local -- --set 3 --port 5393              # 放背景跑；開模擬器、放規則、開網頁
```

- `--set N` 會把模擬器的連接埠都加 `1000×N`，**每個 session 用不同的 `--set` 和 `--port`**，不然會測到別人的分支。開之前先看有沒有人在用（`npm run local -- --set 3 --stop` 只關這一套）。
  - 建議：美術統籌 `--set 4 --port 5394`，測試 `--set 3 --port 5393`，數值平衡 `--set 5 --port 5395`，Yuga 自己用 `--set 0`／5173。
- 等到印出「好了：http://localhost:5393/?user=小明」就是起來了（約 60～90 秒）。
- 改了 `shared/` 或 `functions/` 要**重開**（規則是開的時候才複製進 `functions/shared/`）；只改 `web/` 不用，網頁會自己更新。
- 用完關掉：`npm run local -- --set 3 --stop`。

## 2. 登入一個測試帳號

網址加 `?user=名字` 就是登入那一位，不用密碼、不用 email：

```
http://localhost:5393/?user=賭場甲
```

- 第一次進標題畫面，按「**自由模式**」就能進大廳（賭場、銀行、大廳都看得到；不用做佩佩、不用選職業）。要看需要挑戰存檔的畫面（展廳有展品、委託、館長室升級）按「新參觀者」，並用 §4 的 `qa_seed_save` 先放存檔。
- 瀏覽器可能先跳「這台電腦有之前的存檔…要搬上去嗎？」：按「從頭開始」。
- 大廳會自動跳公佈欄，右上角 × 關掉。
- 開第二個分頁用 `?user=別的名字` 就是第二個人。**網址的連接埠不同，登入也是各自的。**

**很重要的順序：** 一個名字如果先被網頁登入過，之後 `emu:call` 就登不進（`EMAIL_EXISTS`）；反過來先 `emu:call` 建好，再用網頁登入沒問題。所以：**先用腳本建帳號、放籌碼和資料，最後才開網頁（或無頭瀏覽器）。**

## 3. 建帳號、給籌碼

```bash
# 建帳號和錢包（任何一個會寫入的動作都可以；存 1 萬進活存）
npm run emu:call -- --set 3 --user 賭場甲 casino '{"act":"bank","op":"put","amt":10000}'

# 給籌碼（改錢包的 chips 欄位；賭場、銀行、大禮包、餐車都用得到）
npm run emu:doc -- --set 3 data casinoWallets/@賭場甲 chips=50000000

# 銀行館債要帳號滿 3 天、拍賣也是：把開戶日往前改
npm run emu:doc -- --set 3 data casinoWallets/@賭場甲 'bond.born="2026-01-01"'
```

- `@暱稱` 會換成那個人的 uid。看欄位：`npm run emu:doc -- --set 3 get casinoWallets/@賭場甲`。
- 莊家的錢（`casinoHouse/main` 的 `bankroll`）預設 11 億，不用管。
- 賭場面板打開要「進館」過；自由模式進大廳就算進館。
- 其他腳本說明在 `tools/README.md`（`emu:call`、`emu:doc`、`qa_seed_save`）。

## 4. 賭場每一頁要有資料

賭場面板的頁籤：牌桌、本週收藏、大禮包、拚經濟、實況、餐車、換小獎、成就、財產。剛建的帳號有的頁是空的（成就全部鎖著、本週收藏沒有進度），要看「有資料」的樣子：

```bash
U=賭場甲
# 打幾手 21 點（成就、牌桌紀錄、本週收藏的進度會動）：發牌 → 停牌（seq 從 0 開始，每手重新發）
for i in 1 2 3 4 5 6; do
  npm run emu:call -- --set 3 --user $U casino '{"act":"deal","text":"10000"}' > /dev/null
  npm run emu:call -- --set 3 --user $U casino '{"act":"stand","seq":0}' > /dev/null
done
# 開大禮包、吃餐車、拚經濟（各壹次）
npm run emu:call -- --set 3 --user $U casino '{"act":"pack","n":1}'
npm run emu:call -- --set 3 --user $U casino '{"act":"buy","item":"tea"}'
npm run emu:call -- --set 3 --user $U casino '{"act":"econ"}'
```

- `deal` 要帶 `text`（下注的字，例如 `"10000"`、`"全下"`）；打到一半（還沒 `stand`）的手，網頁畫面會看到進行中的牌桌。
- 動作的名字和參數看 `functions/casino.js` 的 `switch (act)`（`pack`、`buy`、`econ`、`stock`、`bank`、`borrow`…）。
- 要看展廳有人、有展台：`node tools/qa_seed_save.cjs --set 3 --nick 名字 --pepes 6 --hall 3`（要先用 `emu:call` 建過帳號；然後網頁按「新參觀者」→「繼續參觀」）。
- 要看銀行股票有行情、台股盤中：模擬器沒有真實行情，要自己寫假的（看維護日誌 `11-13_測試_真實價過期的暫停訊息.md`）。

## 5. 照畫面存成 PNG（不用開瀏覽器分頁）

登入後的畫面也能用無頭 Edge／Chrome 照，**一個指令**（`tools/shot_login.cjs`，背後用 `tools/shot_phone.cjs`）：

```bash
node tools/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --tab 成就 --size 1366x768 --out 成就.png
node tools/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --size 375x740  --out 直拿.png
node tools/shot_login.cjs --url http://localhost:5393 --user 賭場甲 --room 賭場 --size 740x375  --out 橫拿.png
```

- `--room` 是大廳地圖上的房間名（賭場、銀行、我的展廳、圖書館…）；`--tab` 是進去之後要點的頁籤字（牌桌、本週收藏、大禮包、拚經濟、實況、餐車、換小獎、成就、財產；不給就停在第壹頁）。
- `--size`：電腦 `1366x768`、手機直拿 `375x740`、橫拿 `740x375`。直拿會自動略過「請轉橫」。
- 照完用 Read 打開 PNG 看。要照每一頁就把 `--tab` 換九次。
- 沒給 `--mode` 是「自由模式」；要用「新參觀者」加 `--mode 新參觀者`（要先 `qa_seed_save` 放過存檔，而且網頁第一次會跳選職業，無頭瀏覽器走不過，這種畫面請用瀏覽器分頁看）。
- 只准 `localhost`；需要的字（頁籤、房間）要跟畫面上一模一樣。

### 踩過的坑

- **賭場面板的關閉鈕、公佈欄的關閉鈕都是 `.nb-x`。** 自己寫腳本時，進房間之後不要再 `document.querySelector('.nb-x').click()`，會把剛打開的賭場關掉。
- `?user=` 帶中文沒問題；`#畫面` 的 debug 網址（`#bank`、`#hall`…）**不登入**，只有示範資料，看不到真的錢包。
- 頁籤超出螢幕時（手機直拿）只有前幾個看得到；點得到的用 `--tab` 指名，它會直接點（程式點擊，不用捲）。
- 手機直拿的大廳是壹張地圖，房間在 `.l2-room`（`aria-label` 是房間名），程式點擊就行，不用真的點到字。
- 沒聲音：網址有 `?user=` 在開發時自動靜音。
- 瀏覽器分頁測試時：先 `resize_window` 到要的尺寸再載入頁面；用完改回 `desktop`。

## 6. 收工

```bash
npm run local -- --set 3 --stop
```

模擬器裡的資料每次重開都清空，不用清。
