## 改了什麼

- 第 3 版的預告片在 OneDrive 的 yu program\佩佩博物館3（不在 E 槽旁邊）：30.5 秒、canvas 逐格畫、Web Audio 合成配樂、ffmpeg 合成。新版照這套做法。
- 新預告片 61 秒、1920×1080、30fps，兩支：docs/素材/預告片/預告片_原創配樂.mp4、預告片_素材配樂.mp4。畫面壹樣，只有配樂不同。
- 分鏡先給翊文看過（照這份做 60 秒）：開場、大廳、做佩佩、融合抱枕、畫廊展廳、任務板、賭場四種、銀行股票、地下合作、圖書館、館友證簽到兌換所、標題、開館、彩蛋。表在 docs/素材/預告片/分鏡.md。
- 畫面是遊戲真的截圖：tools/assets/trailer/shots.cjs 用無頭瀏覽器開 #畫面（賭場、銀行走假伺服器），清單在 shot_list.cjs。
- trailer.js 在 canvas 上加慢推、字卡、閃光、暗角；原創配樂 score() 是 Claude 寫的，樂器沿用第 3 版自己寫的合成器。
- 素材配樂 audio_mix.cjs：照 CUES 把 web/public/sfx 的音樂接起來，自動跳過前奏的空白、音量對齊、最後壓峰值到 -1.5 dB。
- render.cjs 開小伺服器和無頭瀏覽器逐格輸出，再叫 ffmpeg 合成兩支 mp4；--stills 只畫幾格看。
- 結尾彩蛋：理智低的畫廊閃兩下，接壹行「剛剛那幅畫……是不是動了？」。

## 怎麼確認的

- 每段都用 --stills 畫了預覽格看過：字卡位置、慢推、截圖裡沒有開發用的字。
- 守門打怪那張把「開發用：打怪預覽」和怪物的名字藏起來再照（不破梗）。
- 成品用 ffprobe 看過長度、解析度、有聲音；素材配樂量過峰值和平均音量。
- npm test 全過。
