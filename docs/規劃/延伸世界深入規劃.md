## 零、給翊文的摘要（白話版）

**現在的問題**

- 目前的線索幾乎都是「看得到、數得到」的痕跡：正字多一畫、簽名補齊、腳印、水聲的節奏。玩家的動作只有「發現」。
- 這樣一季可以撐得住，但再往下，玩家會覺得「只是在對帳」，不知道這些帳**為什麼重要、誰付了代價**。
- 館裡的人（六位交代人、旅客、阿鑿、小鈴、文化部的承辦欄）現在多半只是「這個謎的證人」，沒有自己的事要煩惱。

**接下來往哪裡走：三個方向**（第貳節，各有優缺點）

| 方向 | 一句話 | 建議 |
|---|---|---|
| 一、人的故事 | 每個人為什麼在這裡、為什麼不走。謎從「物」移到「人」。 | **主軸** |
| 二、規矩的來歷 | 館、名牌、補帳這套規矩是誰訂的、怎麼變成這樣。 | **底**（季末揭曉用） |
| 三、你的選擇 | 玩家的行動會改變帳、改變誰被記下來。 | **只在最後一季，先小規模** |

**怎麼排揭露**（第參節）：每一季問的東西換一種——物 → 人 → 規矩 → 你。每次**答一個小問題，同時冒出一個更大、而且不同種類的問題**，不是「再多一畫」。

**要翊文決定的**（第伍節）：主旨要不要動、挑哪個方向、最終怎麼收尾、2027-W43 之後怎麼辦。每題都有建議。

## 貳、三個方向

### 方向一：人的故事（建議當主軸）

**做什麼**：每位常駐的人（六位交代人、旅客、阿鑿、小鈴、退休的郵差、賣傘的老闆…）各扛一個**自己的兩難**，剛好對上一條子主旨。玩家跟他熟了，聽到的不再是「今天的證物」，而是「他今天為什麼這樣選」。

**扛哪條問題**（只列問題，不列答案；對應 `st-*`）：

| 人 | 他扛的問題 | 子主旨 |
|---|---|---|
| 荷官（yuga） | 欠的東西，算不算還清了？ | `st-owe` |
| 堂主（hall） | 推薦到什麼程度，算替人決定？ | `st-name` |
| 退休的郵差（postman） | 信送到了，算誰的？ | `st-trace` |
| 便利商店店員（clerk） | 只記數量不記名字，是保護還是失職？ | `st-count` |
| 阿秤（scale） | 秤得出的才算數，那秤不出的呢？ | `st-price` |
| 號碼機（number） | 叫到的號，和沒被叫到的人。 | `st-outside` |

- 這六個都在 `content/givers/` 已經有第 2、3 段小故事的位子（Lv3、W51 起），可以直接接，**不用另開新系統**。
- 旅客（找 NPC 下地下的人）、城鎮的人，用同一個做法：一個人一個小兩難，在他的好感度裡慢慢露。

**優點**
- 玩家有理由回來聊天（熟識度）；跟剛做完的交代人互動最順。
- 每個人獨立，可以一人一批慢慢寫，不怕排程中斷。
- 跟「差一畫」是不同種類的好奇：不是「答案是什麼」，是「他會怎麼選」。

**缺點 / 風險**
- 人多容易散，變成日常小品，離主線太遠。→ 每個人只扛**一條**問題，並且只准碰子主旨的問題，不碰謎底。
- 寫得好壞很吃文字；Yuga 要看。
- 號碼機、文化部那條線有「不碰」的規矩（撥款信、池子、水位、名牌），人物線要避開。

### 方向二：規矩的來歷

**做什麼**：把「名牌、交接、補帳、排隊」當成**一套制度**來講：它什麼時候出現、前一套是什麼、有誰試過改、為什麼大家還是照做。用館史、舊版規章、歷任館長簽到簿、館際通知這類**文件**說話。

**優點**
- 跟現有八個謎直接接，季末揭曉可以拿來收線，不用另寫證據鏈。
- 讀起來像在拼館史，喜歡考據的人會很愛。

**缺點 / 風險**
- 容易變成說明文：玩家讀完是「懂了設定」而不是「被打動」。
- 文件類線索在 App 裡只能放書和特展，量一多會很重。
- 寫多了容易自己跟自己矛盾（要靠帳本管）。

### 方向三：你的選擇

**做什麼**：玩家的行動影響誰被記下來：替空白的名牌取名、替別人補一筆、投票、把某個東西留下或交出去。結果在玩家自己的館裡不同，也可以統計全館。

**優點**
- 多人遊戲獨有的東西，別的線做不到。
- 跟 `m-you`（最後一季）直接對上，是主旨的最後一句。

**缺點 / 風險**
- 要程式、要存檔、要平衡，工程量最大。
- 結局會分歧，要維護多個版本；跟「最終收尾要翊文決定」的規矩衝突。
- 太早放，會讓還沒看懂的人被「選」壓著。

### 我的建議

**一為主、二為底、三留到最後一季。**
- 平常（每兩週）：人的故事（交代人、旅客、城鎮的人）往前走。
- 每季末：用「規矩的來歷」收線，把一季的小事連成一個看得見的制度。
- 最後一季（第 4 季，m-you）：才開「你的選擇」，而且**先做小的**（例如寫不寫一個名字），別一次做完。

## 參、揭露的節奏：從「差一畫」走到更大的層次

### 3.1 五階梯

每個謎、每個人都照這五步走，**一次只上一階**：

| 階 | 玩家的動作 | 長什麼樣 |
|---|---|---|
| 1 看見 | 發現一個痕跡 | 現在的「正字多一畫」。小、可驗證、單看說得過去。 |
| 2 連起來 | 自己把兩個痕跡接上 | 兩條線的細節撞在一起，玩家自己「咦」。不說破。 |
| 3 規矩 | 知道這件事為什麼這樣運作 | 一份文件、一個人的話，講出「有這套做法」。 |
| 4 代價 | 知道誰為這套做法付了什麼 | 某個人（不是證物）的處境。**這是現在最缺的一階。** |
| 5 選擇 | 知道自己能怎麼辦 | 玩家有得選，而且選擇有重量。留到最後。 |

- 現在多半在 1～2 階，少數到 3。接下來要把 4 階補起來，**第 4 階一定是「人」，不是「物」**。
- 對應 `main.depths` 的七層問題與 `units.depth` 數字：這份不重排，只是提醒「後面的段，一半以上要落在 3、4 階」。

### 3.2 答小的、換大的

每次揭露，**回答一個玩家已經在問的小問題，同時露出一個不同種類、更大的問題**：

- 第 1 季（物）：問「帳為什麼差」，答完一個小問題，冒出一個跟「人」有關的問題。
- 第 2 季（人與人）：問「誰在寫名牌」，答完之後，冒出一個關於「他為什麼肯」的問題（代價）。
- 第 3 季（館與館、制度）：問「怎麼補帳」，答完之後，冒出一個關於「被牽進來的人願不願意」的問題（選擇）。
- 第 4 季（你）：問題回到玩家身上。
- 每一步答到什麼，照舊只寫在帳本，這份不寫。

**不是越來越多的線索，是每一季問的東西換一種。** 玩家不會覺得在重複數同一件事。

### 3.3 一段兩週怎麼排

沿用兩週一段，只加一條規矩：

- **揭露週**：照舊放一件小東西（階 1～2）。
- **回聲週**：除了換地方再出現，**加一位人物的一句話**（階 3～4）：用他自己的話提到，不解釋、不對答案。這句放在他的閒聊或小故事裡。
- **每一段只讓一位人物往前一階**，同時最多兩條人物線在走。
- 玩家可以只追物證（照舊），也可以只追人，**兩種玩法都能看懂主線**。

### 3.4 人物線的入口

- 六位交代人：Lv3 的小故事（W51 起第 2、3 段）就是第 3、4 階的位子。
- 旅客：好感度夠高的旅客，在他的段落裡用同樣方式露。
- 城鎮的人（郵差、傘店、夜市）：用季節線明信片和日報各一句。
- 館外的人（小鈴、阿鑿、承辦欄）：維持「只有痕跡」，不露臉，不扛人物線。

### 3.5 看得出自己在往深走

玩家要感覺得到「這不是同一種謎了」：
- 書：新增一類「他說的」（人物自述），跟「紀錄」（證物）分開放。
- 交談紀錄（圖書館那一格）：小故事讀過的段落整頁記下來，自然成為「人的那一邊」。
- 不另做進度條、不顯示總數（跟交談紀錄同一條規矩）。

## 柒、風險

- **變成日常小品**：人物線太遠，玩家以為是支線。→ 每條只碰一條子主旨的問題。
- **提早講完**：把「規矩」那一階講太白，後面沒東西。→ 階 3 只講「有這套做法」，階 4 才講代價，階 5 留到最後。
- **兩種玩家**：只追物證的人覺得人物太慢，只追人的覺得物證太硬。→ 兩條線都能獨立看懂主線。
- **寫太多**：人物線的句子量比物證多很多。→ 先六位交代人，再旅客，再城鎮；每批過了再開下一批。
- **洩漏**：這份和之後的人物線都不得出現謎底。→ 照舊用 `tools/check/givers_check.cjs` 和 `week_check.cjs` 的字表擋。
