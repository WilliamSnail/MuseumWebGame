# 0035 主題展辦完：同一個主題掛滿 3 天，銅給心情、銀給靈感、金給限定配件，手記銅就讀得到

- 日期：2026-11-09 09:50:43
- 誰決定：翊文（原話在下面）；細節是 Claude 照 `docs/每週劇情.md` 第十節的預設做的，翊文還沒定，數字、名字、文字都可以改
- 狀態：有效，11-09 做了（`維護日誌/2026/11-09_翊文_主題展.md`）

## 背景

翊文 11-09：

> 「展廳的 評分 +10～+20 這些，目前好像還沒什麼用處，有沒有能讓他更有遊戲性，比如主題展辦完了會獲得新的限定帽子或首飾等等的，再加相對應的劇情?」

以前展廳湊成主題只是加分；分數只影響參觀者留下多少靈感。每週特展只記最高分。

## 決定

- **「辦完」**：牆上的主題（`hallScore` 的 `theme`，加分最高的那個）連續掛滿 3 天，分數到銅以上。
  - 真的天，`todayStr()`，05:00 換日。掛上那天算第 1 天，到第 3 天第一次打開就結算（所以實際至少過 2 次 05:00）。
  - **不用每天上線**：不在的時候展覽照樣開著，回來才結算。
  - **中間換掉就重算**。牆上變成別的主題、或主題不成立，都算換掉（多擺兩隻傳說級，牆上會變成「傳說殿堂」，也算）。
  - 只有一個例外（Claude 加的）：**同一天之內換回來，接著算**。不然把一隻拿下來再放回去，兩天就白等了。
  - 分數看結算那一刻。第 3 天分數不到銅：不算辦完，等分數到了馬上結算。
- **三級**（`NUM.show`）：銅 60、銀 80、金 95。
  - 銅：心情 +10（給現在這位）。銀：靈感 +15（給博物館）。金：這個主題的限定配件。**策展手記銅就讀得到**。
  - **每一級每個主題只給一次**。第一次就到金，三樣一起給。掛著不動就是下一場（又是 3 天），可以往上拿；沒比以前高就什麼都沒有。到金之後不再結算。
  - **失敗作另外算**：40／55／75（`NUM.show.tiersBy`）。失敗作一件只有 3 分，照 60／80／95 辦不到金。
  - 實際量過到得了多少：維護日誌有表。6 座展台到得了銀，金要買到第 8 座（傳說殿堂除外）。
- **限定配件**：10 個主題各一件，放在 `LIMITED_ITEMS`（`from: "show"`）、`PEPE_PARTS` 的帽子（`limited: "show"`）。
  - **首飾也放在「帽子」這一類**，一次戴一樣。不多開一類：`pepeKey` 是照類別接起來的，多一類每個舊存檔的 key 都要改。
  - 不算進基本組合、圖鑑、「全部解鎖」，算進「限定收藏 N／M」。每週全簽到、大成功的免費解鎖都不會給。沒拿到不會出現在手作坊（下面一行字說怎麼拿），拿到才列。
  - 領的時候有「馬上使用」，到手作坊、已經選好。
- **策展手記**：每個主題一篇，放在起源室書架的「策展」頁籤。來看展的怪客是展廳留言裡那些人；接得上值班紀錄、「帳對不上」，不破梗。還沒見過 8+9 的人不列那一本。
- **展覽海報**：一個主題一張（到過的最高級），掛在展廳牆下面；`hallView` 也帶上 `posters`。
- **每週特展**：換週時（週一 05:00，第一次 `weeklyState` 的時候）照上週的最高分，到金就給那週的配件。
  - 金的分數每種不一樣（`NUM.show.weekGold`）：失敗作週、回到起點週、不准傳說的週本來就到不了 90。
  - 先做 3 件（`from: "week"`）：黑色週「黑絨領結」、抱枕週「小枕頭髮夾」、8+9 週「金瓜子項鍊」。其他 5 週到金只記分數。
  - 已經有了（8 週輪一次）：照簽到的規矩換成靈感 +10（`NUM.signin.dupInsp`）。
- **提示**：第 2 天用現有的 `note()` 提示一次「再 1 天就辦完了」，不亮小紅點。不能蓋卡片的時候（別的房間、今天自動跳的視窗夠多了）提示「走進展廳看看」。
- **只在挑戰模式**。自由模式什麼都打開了，沒有展期。

## 為什麼這樣做

- 「不用每天上線」：這是朋友之間的遊戲，有事沒來不該把展覽算斷。要求每天上線，等於把連續簽到又做一次。
- 「每一級只給一次」：靈感不能變成可以一直刷的來源（靈感不能讓全部解鎖更快）。全部辦到銀也只有 150 靈感，至少要 30 天。
