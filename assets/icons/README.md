# 圖標素材（先存起來，還沒接進遊戲）

- 來源：翊文用 Gemini 生成的 4x4 圖標總表（`_sheet-16.webp`，1024x1024）。
- `*.png`：切成 16 張 256x256，圓形外面是透明（綠底已去掉）。
- 名字：lightbulb 燈泡、firstaid 急救箱、book 書、thread 金線、canvas 畫布、brush 畫筆、key 鑰匙、lantern 提燈、magnifier 放大鏡、watch 懷錶、scroll 捲軸、bell 鈴、star 星章、rosette 緞帶徽章、nameplate 名牌、quill 羽毛筆。
- 注意：
  - `firstaid` 有紅十字（紅十字會的標誌），接進遊戲前建議重生，改成綠色或金色的加號。
  - 授權和用途要翊文確認過才能上線。
  - 不要放 Pepe the Frog 的樣子（決定 0005）。
- 這個資料夾不在 `web/` 底下，所以不會被打包進 `dist/`。
