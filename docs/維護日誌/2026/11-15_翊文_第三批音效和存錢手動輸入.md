# 存錢、領錢、開定存可以手動輸入金額；地下 B5、平安回來、銀行、拿到籌碼的音效

## 為什麼要改
- 翊文：「存錢應該也要能手動輸入數字」。
- 又給了 Pixabay 檔：Echo of the Void（我放 B5）、鋼琴弦樂（「用在走完壹趟平安回來的時候」）、Number pad、ATM 吐鈔（「可以改銀行已經用的聲音…看哪個適合」）、Coin and Money Bag（「玩家其他地方獲得籌碼的音效」）。

## 改了什麼
- ui_bank.js pickAmt 多第五個參數 type { min, max, verb }：快捷按鈕下面多壹格輸入，範圍外不能按、Enter 送出。用在存入（s.min～手上籌碼）、提出（1～活存）、開定存（termMin～min(termCap, 手上)）。
- numField 打數字、Backspace 響 keypad（40 毫秒內不重複）；銀行所有數字欄都有。
- 銀行提出、借錢改 atm-dispense（原本 coin-payout）；賣股票照舊 coin-payout。
- ui_core.js setChips：籌碼變多、不在銀行和賭場時響 money-bag；從 null 來不響。
- fx.js AMB.cellar：B5 多壹條 void-echo 底音（0.3），風降到 0.05；bed 少的 key 當 0。
- 平安回來：單人 advanceFlow 走完壹層 fanfare 後 1.5 秒播 safe-return；合作 overCard 不是 lost 時，壹趟（v.id）只播壹次。
- 來源加進 shared/sfx_files.js、來源.md；safe-return 是 Pixabay「音樂」分類，測試的網址檢查改成 sound-effects 或 music。

## 怎麼確認的
- npm test、test/sfx_files.test.cjs、vite build。耳朵沒聽，音量要翊文聽；手動輸入沒在正式站按過。

## 還沒做、要注意
- money-bag 只要籌碼變多就響（包括伺服器同步回來的分紅），太常響再加條件。
- safe-return 跟地下的環境音疊在壹起；如果太亂可以播的時候把環境音壓低。

## 給下一個人
- 銀行的音效對照在 ui_bank.js 的 BANK_SFX_*；拿到籌碼的聲音在 ui_core.js 的 setChips。
