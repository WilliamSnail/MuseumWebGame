# 0047 地下探險撿籌碼：走完地下的房間，有機會撿到一點點籌碼

- 日期：2026-11-09 15:54:08
- 誰決定：翊文（要加）；時機、機率、數量是做的時候先定的，標「先照這樣」的等翊文看
- 狀態：有效

## 背景

翊文 11-09：

> 「讓地下探險劇情也有機會可以拿到一點點籌碼」

籌碼是 Hamachi 賭場的代幣（決定 0040），存在伺服器，玩家不能自己改；不是錢，不能買，不能換現實的東西。

## 決定

先照這樣（等翊文看）：

### 什麼時候撿

- **走完壹個房間，結果出來的那壹刻**（單人：`resolveFlow` 把結果寫上去之後；合作地下：`playResult` 演完那壹間之後，撤退不算）。
- 為什麼選這裡：房間是地下探險最小的壹步，每間都有劇情和結果；撿東西接在「結果」後面最自然，像是走完壹間，在角落多看到壹點東西。不選整層走完：壹層 4 間左右，太少機會。不選「進房間」：還沒做事就拿東西，不像探險。不分成功失敗：失敗也走過了，撿到壹點不奇怪，也不會變成逼玩家選容易的房間。
- 每間都擲，所以不是「第壹次走」才有。要防刷靠下面的上限，不靠限制第壹次（伺服器看不到存檔裡的「走過」，畫面說的不能信）。
- 自由模式不撿（跟靈感壹樣，自由模式沒有收穫）。每週劇情多出來的房間、試煉房間不撿（它們的 id 不在 `CELLAR` 裡，伺服器會拒絕）。

### 誰說了算

- 畫面只說「我走完了這間」（`casino` 的 `act: "cellarFind"`，只帶房間 id）。有沒有、多少、第幾句話，都是 `shared/casino_find.js` 的 `casCellarFind` 用伺服器的亂數決定。
- 防刷：
  - 每個帳號每個遊戲日（台灣 05:00 換日）最多撿 `perDay` 次。
  - 同壹個房間壹天只擲壹次（沒撿到也算，不能重擲）。
  - 房間 id 要是 `CELLAR` 裡真的有的。
  - 重複、撿夠了：什麼都不寫，畫面安靜地不跳通知。
- 記帳跟大禮包壹樣：錢包的籌碼加、莊家（大家共用的那份）減，加起來守恆；錢包 `st.finds`（撿到幾次）、`st.findChips`（共幾枚）、`st.chipsMax` 對得上。錢包多壹欄 `cf`（`{ day, n, rooms }`），舊錢包沒有，讀回來補。
- 沒進過賭場、錢包還沒建立的人：伺服器照平常的做法建壹份新的（開場 1,000,000，跟狀態列 `peek` 看到的壹樣）再加上撿到的；之後第壹次進賭場讀到的是這份錢包，不會再給開戶禮。

### 數字（`NUM.casino.cellarFind`，先照這樣，等翊文）

`chance: 0.25`、`min: 500`、`max: 2000`、`step: 100`、`perDay: 3`。

怎麼算的（對照玩家平常拿到的量）：

| 對照 | 籌碼 |
| --- | --- |
| 開場的錢包 | 1,000,000 |
| 最小的注 | 100 |
| 救濟補到 | 20,000 |
| 最便宜的餐車（麥茶 1,750、壽司 2,000、烤雞 3,000） | 1,750～3,000 |
| 免費大禮包（每天 2 包），最小的壹星 | 10,000（平均整包約 1,720,000） |
| 換壹點靈感 | 200,000 |
| **撿到壹次（平均 1,250）** | 500～2,000 |
| **壹天最多（3 次都撿到最大）** | 6,000 |

- 壹次最多 2,000，大約是壹杯麥茶到壹份烤雞肉；是最小的注的 5～20 倍，所以真的能下壹兩手，但不會改變牌桌的節奏。
- 壹天最多 6,000，比最小的壹星大禮包（10,000）還少，是每天 2 包免費大禮包平均的 0.2% 左右。要攢到換壹點靈感（200,000），最多的情況也要 34 天；測試擋住「10 天也換不到壹點靈感」。
- 機率 25%、壹天最多 3 次：壹天走 10 間房，平均撿約 2 次（上限 3 次擋著），感覺是「偶爾有」。
- 壹天上限不分單人和合作地下，同壹個帳號壹起算。

### 文字（`CAS_FIND_TEXT`，`shared/casino_text.js`）

6 句，伺服器給第幾句，畫面照那句念，後面加「（+N 籌碼）」。接主線「帳總是差壹點」的感覺，但不碰「差壹隻」（週日才揭曉）；不寫賭博、不寫錢、不鼓勵下注。例：

> 抽屜沒關好，掉出幾枚籌碼。帳上總是差壹點，這大概是其中壹點。（+1,200 籌碼）

### 失敗要安靜

- 不等伺服器：畫面照常往下走（`ADDONS.cellarFind` 沒有 `await`，整個包在 `try` 裡），房間不會卡。
- 離線、沒登入、本機沒有 Functions、模擬器沒開、伺服器回不 ok：都算了，不跳錯誤、不重試。

### 合作地下

接了。很小的改動：`ui_coop.js` 的 `playResult` 結尾叫同壹個 `ADDONS.cellarFind(房間 id)`（合作地下用的房間 id 就是 `CELLAR` 的）；留守的人看不到骰子的那條路不叫。伺服器那邊沒有改合作的程式，因為撿籌碼是畫面額外問壹次 `casino`，不是合作交易的壹部分。
