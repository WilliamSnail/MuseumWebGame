## 改了什麼

- 看了現在的排程：一個 Claude 排程每天 08:00 跑（content/排程說明.md），週一排這週、其他天寫當天的 dN.json，跑 npm test（裡面有 tools/week_check.cjs），開 PR 自己合併，部署後發 Discord。故事的連續性靠帳本 weeks.<週>.hooks 和 motifs（一之七）。新工具照這個流程接，不另外發明一套。
- 新工具 npm run level:new（tools/new_level.cjs）：排程寫名字、出場那句、打法、心情顏色、每種招的預告、登記卡、接哪條線；工具照樓層填數字、自動調壓力到目標難度、模擬 1～4 人、印出玩家在地圖上會看到什麼和該帶哪種心情的佩佩，--write 寫進當天的檔。
- 五種打法（STYLES）：嚇人、撲人、越來越多、混合、守門。每一種附一句給排程看的說明（什麼時候用、玩家要怎麼打）。
- 調難度：會弄倒佩佩的看一個人的勝率（hard 1／2／3 ＝ 85～97%／68～88%／50～72%）；不會弄倒佩佩的一個人幾乎不會輸，改看打幾回合（3～4.5／4.5～6.5／6.5～8.5）。調不進去會說要換打法或換樓層。
- shared/cellar_fight.js：fightDailyCheck 檢查 dN.json 的 cellar 那一塊。shared/cellar_map.js：cmapAddDaily 把今天的怪物放進地圖中間那一排；cmapPeek 認得今天的點。
- tools/week_check.cjs：dN.json 可以寫 cellar；檢查數字、字數、「壹」、英文字母、禁用字、劇情線、id 不重複、不能放在備用週。
- test/sim_fight.cjs 改成可以被別的工具用（simFoe），吃每天內容寫的怪物。
- content/排程說明.md 新的「一之八」：步驟、五種打法什麼時候用、一週的節奏表；content/README.md 加格式；tools/README.md 加兩行。
