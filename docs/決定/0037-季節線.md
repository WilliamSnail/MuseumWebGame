# 0037 加季節線；主線的主旨是所有劇情線的主軸；新聞可以用選舉、政治、兩岸

- 日期：2026-11-09 09:22:27
- 誰決定：翊文
- 狀態：有效（做法見 `docs/每週劇情.md` 第二、三、十二節，內容格式見 `content/README.md` 第八節）

## 背景

- 決定 0031 之後，劇情線有主線、這週的線、樓層的線，每週從新聞找事件。
- 翊文問：「劇情線有沒有分主線跟季節線?」然後說：「加季節線」。
- 接著補了三句，把主線、季節線、每日、新聞的關係定下來：
  - 「主線劇情的主旨還是要繼續下去，季節線跟每日也要像副劇情一樣，圍繞這主軸，即便有使用新聞來參考喔」
  - 「新聞可以找最近台灣相關的，連選舉那種都可以，把找到的用我們劇情敘述的方法來呈現」
  - 「兩岸 的可以，這是我們喜歡的議題」

## 決定

**季節線**

- 一年四季各一條線（`LINE_KINDS.season`），跨好幾週，大約每兩週一章，接得上當季的節日。
- 季節照節氣切：立冬約 11/7 起是冬、立春約 2/4 起是春、立夏約 5/5 起是夏、立秋約 8/7 起是秋（`yearSeason(日期)`）。這週的週一屬於哪一季就算哪一季（`weekSeason(週)`）。主線四週一段的「季」（`seasonOf`）名字不變，是兩回事。
- 節日跨在換季那週，可以放在新的那一季：2027-W05 的週一 2/1 還沒立春，除夕 2/5 已經過了，放春天。檢查程式准跨在換季那週的章。
- **沒玩也不會卡住主線**：季節線的書不算進「讀幾本打開結局」。書放起源室的「季節」頁籤，過了那週還是可以補讀。

**主旨是主軸**

- 帳本 `main.theme` 寫主線的主旨，是所有劇情線共同的主軸。沒有就擋。
- 新聞只決定這週的事件和氣氛，不能帶走主軸。
- 每週的線、每天的書、季節線都是圍繞主軸的副劇情：碰到主線的東西（同一個帳、同一批人物或地方、同一個謎的另一面），但不揭曉主線的謎底、不搶主線的進度。
- 帳本要記 `ties`：每週（`weeks.<週>.ties`）、季節線每章都寫碰到主線的哪一點。沒寫只警告，不擋（擋了會來不及上線）。

**新聞的界線改了**（取代 `docs/每週劇情.md` 第三節原本「不碰政治、選舉、兩岸」那幾個字）

- 選舉、政治話題、兩岸議題都可以用，要轉成我們劇情的講法（例如館內的展品投票選館長）。
- 還是不准：真人、政黨、候選人、公司、品牌、別人作品的名字；選邊站、嘲笑任何一邊（要看不出在挺誰）；有人傷亡的事故和災難、犯罪；抄新聞的文字（連結只寫在靈感來源表和 PR）。
- `tools/week_check.cjs` 的禁用字拿掉選舉、投票、政治、政黨、罷免、公投、兩岸、統獨、台獨這類一般的字，加上真實的政黨、人名。

## 影響

- `shared/story.js`：`LINE_KINDS.season`、`yearSeason`、`weekSeason`、`seasonLines`；跨週的線 id 不加週的名字；結局不算季節線的書。
- 起源室書架多一個「季節」頁籤；劇情線面板看得到季節線。
- 帳本多 `main.theme`、`seasonal`、`weeks.<週>.ties`；排程每週看這週有沒有季節線的章。
- 文件裡戰爭、宗教不特別列為禁止，也不特別鼓勵。檢查程式的禁用字清單裡這兩類的字這次沒有動。
