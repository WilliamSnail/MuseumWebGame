# 0075 藝術市場：畫是避險資產，跟館方買賣、稀有的拍賣

- 日期：2026-11-13 19:38:13
- 誰決定：翊文
- 狀態：有效

## 背景

翊文：

> 「對了，讓每日特展的畫也能被玩家購買，想想交易怎麼做」
>
> 「藝術市場也是一個市場機制」
>
> 「畫可以當像富人買用來避險的感覺」

## 決定

1. 每日特展的畫可以用**籌碼**買。
2. 跟誰買賣：**兩種都要**。館方隨時買賣、有底價；稀有的畫另外開拍賣。
3. **畫是避險資產，不是賭博**：價格跟景氣反向或低相關、每天變動很小、長期慢慢增值、買賣有價差讓短線一定虧、入手門檻高。畫面安靜，不做漲跌跳動的刺激感。
4. 第一步只做跟館方買賣（規劃 `docs/經濟體系規劃.md` 2.10 節）。拍賣是下一步，還沒做。

## 為什麼

- 畫廊本來只能看。多一個「放著」的出口，讓有錢的玩家有地方存錢，也讓特展的畫有用處。
- 錢只搬不生：買進莊家、賣回由莊家付 80%，價差留在莊家。
- 「畫越久沒人買越便宜」原本的想法被取代：避險資產要放久了增值，不降價。
