# 0027 怪癖：做完一件事就好，不然 20 分鐘後自己消失

- 日期：2026-11-09 00:40:46
- 誰決定：翊文（要改、怎麼改）；治療的事有哪幾種、狂熱算不算負面，是 Claude（subagent）判斷的，等翊文看
- 狀態：有效（先照這篇做了，等翊文看）

## 背景

- 一天掉的理智超過當天理智的 1/5，會得到一個怪癖：恐懼症（不敢碰某個選項）或狂熱（做某個選項少花 1 靈感、其他多花 1）。
- 原本的治法有兩種：
  - 委託櫃台交「治療委託」：得到怪癖時，把當天一張委託標成治療委託。
  - 連續 3 天抱抱枕（`NUM.quirkCureDays`）。
- 翊文 11-08：

  > 「或連續 3 天去抱抱枕 這個太久了，現在改成20分鐘內只要完成某樣事情就可以了」

  問了怎麼做，翊文選：

  > 「做完一件事情就好，20分鐘後負面怪癖會自己消失」

- 多人版的一天要改成真的一天（第 0019 篇）。照舊的話，「連續 3 天」就要真的等 3 天。
- 沒有哪一篇決定紀錄定過「連續 3 天抱抱枕」（第 3 版就有的規則）。第 0003、0019 篇有提到它，寫的是當時的狀況，狀態不改，只在那兩篇加一行註記。

## 決定

- **得到怪癖時，同時抽一件治療的事**（`q.task`），做完就治好：
  - `hug`：抱一次抱枕（抱枕工作台；今天還沒抱過的抱枕都可以）。
  - `deliver`：交一張委託（委託櫃台；哪一張都可以，一鍵交件也算）。
  - `calm`：看一幅不可怕的畫（畫廊；不用理智檢定的畫，現在是「普通的佩佩肖像」「稀有佩佩圖畫」）。
- **只抽現在做得到的**（20 分鐘內做得完）：
  - 抱抱枕：有今天還沒抱過的抱枕。
  - 交委託：收藏裡已經有交得出去的；或是有一張「做一隻就交得出去」的委託（不挑稀有度、不要完美作品、不要失敗作、要的選項沒被擋住），而且靈感夠做一隻（`NUM.costPepe + 1`，狂熱時最多多花 1）。
  - 看畫：有開放的、不用理智檢定的畫。挑戰模式一定有。
  - 跟別的還沒好的怪癖不一樣的優先，免得做一件事一次好兩個。
  - 都做不到（目前不會發生）：沒有治法，只能等時間到。
- **沒做的話，得到之後 20 分鐘自己消失**（`NUM.quirkMinutes`），跳一則提示。
  - 存檔記到期的那一刻（`q.until`，毫秒）。
  - 照真的時鐘（`nowMs()`），關掉遊戲也在走。
    - 理由一：翊文說的是「20分鐘後」。
    - 理由二：翊文 11-09：「遊戲裡的內容也是跟著那網路抓取的真實時間時間」。`claude/真實的一天` 分支會把 `nowMs()` 接到網路的時間。
  - 測試、伺服器用 `setNowClock` 換時鐘（跟 `setDayClock` 一樣的做法）。
- **「治療委託」併成「交一張委託」**：原本就是「交一張委託就治好」，只是限定標起來的那一張。現在哪一張都算，委託板上不再標。不留兩套治法。
- **「連續 3 天抱抱枕」拿掉**：`NUM.quirkCureDays`、`hugStreak` 拿掉；`P.hugDays` 不再記（欄位先留著，舊存檔有）。
- **恐懼症、狂熱都算「負面怪癖」，都照這篇做**。理由：
  1. 怎麼來的：都是理智掉太多得到的（CoC 的「不定性瘋狂」），是壞事的結果。
  2. 文字把它寫成病：狂熱是「你滿腦子都是「x」。其他的看起來都不太對。」，治好是「你發現「x」以外的東西也很好。」
  3. 效果整體不利：只有那一個選項少花 1 靈感，其他選項全部多花 1。圖鑑、委託要的是各種組合，大部分都會多花。少花 1 是附帶的。
  4. 原本的治法也不分種類：治療委託、抱抱枕都會治好任何一個怪癖。只改恐懼症的話，狂熱就要留舊的治法，變成兩套。
  - 要注意：狂熱有時會落在預設的選項（例如背景「沒有」→「沒有狂」），這種幾乎都是好處。現在 20 分鐘就沒了，影響小。要不要讓狂熱不落在預設選項，問翊文。
- **舊存檔**：
  - 怪癖沒有 `until`：從載入那一刻起算 20 分鐘。
  - 沒有 `task`：補「交一張委託」（原本的治法是交治療委託，最接近）。
  - `until` 比「現在＋20 分鐘」還晚（電腦時鐘被往回調過）：拉回「現在＋20 分鐘」。
  - 不在場的參觀者（`P.visitors`）也一樣補。

## 影響

- `shared/config.js`：`NUM.quirkMinutes: 20`（拿掉 `quirkCureDays`）。
- `shared/logic.js`：
  - `NOW_CLOCK`、`setNowClock`、`nowMs`：拿「現在幾毫秒」。規則裡算時間一律用 `nowMs()`。
  - 怪癖多兩個欄位：`until`（毫秒）、`task`（`"hug"`、`"deliver"`、`"calm"` 或 `null`）。
  - `QUIRK_TASKS`、`quirkTaskOk`、`pickQuirkTask`、`cureByTask`、`expireQuirks`、`activeQuirks`、`quirkLive`、`quirkMinsLeft`、`calmExhibits`、`fixQuirks`。
  - `hug`、`deliver`、`viewExhibit` 回傳的 `cured` 改成陣列（`[{ quirk, from, to }]`）。
  - `blockedSet`、`blockedWhy`、`maniaQuirk` 不算過期的：時間到就不擋了，就算還沒拿掉。
  - `dailyCommissions` 不再標 `cure`。
- `shared/visitors.js`：不在場的參觀者也補 `until`、`task`。`shared/legacy.js`：歷任參觀者牆只記沒過期的怪癖。
- `shared/content3.js`：`QUIRK_TASK_TEXT`（每種的「要做的事」、狀態列的短版、在哪個房間、說明）。
- 畫面：
  - 狀態列的怪癖小牌子多一行小字：要做的事・剩幾分。
  - 怪癖卡片（得到時蓋的、點小牌子看的、館長室名片上的）：「怎麼治好」「沒做的話：還剩 N 分鐘」。
  - 手作坊不敢碰的說明（`afraidText`、`afraidBar`）、狂熱的那一行。
  - 抱枕工作台、委託櫃台、畫廊上面一塊綠框說明「在這裡○○，就能治好「○○」」；畫廊的不可怕的畫掛「看了治好怪癖」。
  - 說明頁「理智檢定」那一條補一句。
  - 剩幾分鐘：每秒看一下，數字變了才換字，不重畫畫面。時間到：跳提示，有用到怪癖的房間等沒有視窗蓋著時重畫一次。
- 存檔格式：`quirks` 多 `until`、`task`。舊存檔載入時補（`test/logic.test.cjs` 有測）。
- 節奏：怪癖最多留 20 分鐘（原本要交到治療委託，或等 3 天）。模擬（`sim.cjs`、`sim_san.cjs`）改成照模擬的秒數算「現在」，結果寫在這次的維護日誌。

## 什麼時候可以再討論

- 覺得 20 分鐘太長或太短（改 `NUM.quirkMinutes`）。
- 想加別的治療的事（例如做一個抱枕、讀一次《起源》）。加法寫在 `shared/logic.js` 的 `QUIRK_TASKS` 上面。
- 翊文覺得狂熱不算負面，或想讓狂熱不要落在預設選項。
- 想改成只算「在玩的時間」（關掉遊戲時不倒數）。
