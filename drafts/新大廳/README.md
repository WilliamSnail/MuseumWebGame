# 新的大廳介面（草稿，只給翊文看）

翊文 11-11 要的：用瀏覽器排壹個新的大廳給翊文看，**先不要改正式的大廳、不要合併**。Issue #154。

- `index.html`：草稿頁。資料是假的（裡面的 `DEMO`），素材都從 `../../assets/` 讀，字全部由程式放。
- `截圖/`：電腦 1366×768、平板 800×1100、手機橫拿 812×375、手機直拿 375×812。
- 這個資料夾不在 `web/` 底下，不會進 `dist/`、不會上線。

## 怎麼看

在專案資料夾：

```
python -m http.server 5291 --bind 127.0.0.1
```

打開 `http://localhost:5291/drafts/新大廳/`。網址加 `?rm=1` 看「減少動畫」的樣子。

## 版面

- 導覽圖（`assets/floorplan/land.webp`）放最大。11 個房間是疊在圖上的透明按鈕，滑過去會亮；房間名字、進度、館友名牌（綠點）、「新」小牌子都是程式畫的；「新」貼在名字標籤的左上角（翊文 11-11）。中間的八角形是大廳本身，寫「大廳・你在這裡」。
- 右邊壹欄：館友證（羊皮紙面板）、今天要做的事（第壹張發光、做完的變淡打勾）、4 個小圓章（週章、委託、靈感、收藏）。
- 活動預告、館友在線縮成兩條細橫幅，放在導覽圖上面，不壓到房間。
- 頂欄是圓形圖標按鈕：今天、館友證、兌換所、公佈欄、信箱、簽到、選單；有數字的掛紅點。
- 籌碼放在底下的狀態列（翊文 11-11：「籌碼感覺可以放在底下的ui」）。
- 手機橫拿：頂欄 40px＋狀態列 36px，約 20%；右欄縮窄，待辦只放 3 張。
- 第壹張待辦的發光有動畫，`body.reduce-motion`、系統的「減少動態效果」都會停掉。
