## 改了什麼

- 大廳「下壹步」下面多壹條「今天」：壹件事壹顆小牌子排成壹行（簽到、領獎勵、每日 做完／全部、每週、信箱、大禮包、拚經濟）。還沒做的亮著排前面，做完的打勾變淡，按了直接過去；按左邊的「今天」開整張清單。
- 每日任務好幾條在大廳合成壹顆（清單裡還是壹條壹條）。
- 簽到了、今天不是節日時，大廳原本的簽到條收起來（css），小牌子「簽到」打勾，按它開簽到日曆。
- 手機橫拿：這壹條排在館內地圖上面。
- 新腳本 `npm run shot`：不開瀏覽器分頁，把 localhost 的畫面照成 PNG，壹次照電腦和手機橫拿。
- `npm run ship` 上線完自己回到 main、拉最新；OneDrive 鎖住 index 會重試。

## 怎麼確認的

- 模擬器加瀏覽器：電腦寬度、手機橫拿（812×375）都排成壹行；按「每週」小牌子會開每週劇情。
- `npm run shot` 實際照了大廳兩個寬度，PNG 打開看過。

## 還沒做、要注意

- 「還有 6 件」是照清單算的，大廳的小牌子把每日合成壹顆，所以數起來比較少顆。
- 簽到了以後簽到條收起來，只在 css 寫了，沒有等到簽完的狀態親眼看。靠 `:has()`，很舊的瀏覽器會照舊顯示簽到條。
- 大廳現在還是有「下壹步、今天、簽到、本週地下收藏庫」四條，地圖被擠到下面。要不要把簽到條、劇情卡再收進「今天」這壹條，等翊文決定。
- `ship` 的回到 main 這次上線才第壹次真的跑。
- 登入後賭場的兩顆小牌子沒在畫面上看到（開發畫面沒登入）。
