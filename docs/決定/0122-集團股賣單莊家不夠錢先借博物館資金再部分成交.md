# 0122 集團股賣單：莊家不夠錢，先借博物館資金，再部分成交

- 日期：2026-11-17 21:00:00
- 誰決定：翊文（11-17：「莊家付不出錢時」兩個辦法都要）
- 狀態：已決定

## 決定
1. 賣集團股時，莊家的錢不夠付，不再整筆擋掉。順序：先用莊家的錢；不夠的差額跟博物館資金借；兩邊加起來還不夠，賣得掉幾股算幾股（部分成交），剩下的股票還在你手上，訊息會說「另外 N 股沒賣掉」；一股都付不起才擋。
2. 借的方式用現成的：博物館資金借給莊家，記成莊家欠博物館資金（`house.debt.budget`），來源 `budgetLoan`（跟莊家破產重開同一條金流線），莊家之後賺了錢，照舊先還這筆。守恆，對帳不用新線。
3. 底線：博物館資金只借「超過起始資金 × `houseLoan.budgetKeepPct`（50%）」的部分的 `gstock.cover.pct`（50%），一筆最多 `gstock.cover.max`（2 億）。博物館資金不會被一筆賣單掏空。
4. 共用函式 `casHouseCover(house, pct, max)`（`shared/casino_book.js`）。館內股、槓桿目前不是「付不起就擋」，而是用莊家餘額算出每天可賣上限（`inNetCap`、`lqHouseCap`），設計不同，這次不動；以後要補，就呼叫同一個函式。

5. 拿掉每人 5% 持股上限（`holdCapPct` 刪除）；一天成交上限 `dayVolPct` 1→80；莊家庫存上限 `makerCapPct` 10→100（翊文 11-17）。漲跌停 ±10% 沒動，所以實際一天淨買賣約股本 2%，80% 做不到；莊家賣空變多時股價漲會虧，風險看模擬。

## 沒做
- 莊家餘額是負的（破產中）時，賣單照舊擋，等換日重開。
