# 0152　延伸世界年底揭露：一二三都要、旁證逐條審

日期：2026-11-22　　決定的人：翊文　　寫的人：Claude（內容主管）

## 決定

翊文 11-22 對《延伸世界深入規劃》選了三題：

1. **第 1 題（主旨）**：不動。`main.theme` 照舊。
2. **第 2 題（方向）**：「一二三都要，並且在今年底揭露完成」。方向一（人的故事）、二（規矩的來歷）、三（你的選擇）都在 2026-W48～W53 揭露。
3. **第 5 題（人物線碰主線多近）**：B，可以給謎底的旁證；**每一條都要逐條審，寫在帳本裡標好**。

## 怎麼做

- 六週表：W48～W49 物、W50～W51 人、W52 規矩、W53 你。每週都有揭露（含加開），三個去處，最多兩條人物線。表在 `docs/規劃/延伸世界深入規劃.md` 零之二；資料在帳本 `extend`。
- 新的揭露：b29（m-queue）、b30（m-ledger）在 W52；b31（m-you）在 W53。
- 旁證每條有 `audit`（誰審、哪天、檢查哪幾項）；`npm test` 會擋沒有審過的資料格式，排程只准用「審過」的，也不准自己新增旁證。檢查程式是 `tools/content/extend_check.cjs`。

## 還沒決定的

- 「揭露完成」我照最小的意思讀：方向揭露，**謎底的收線日期不動**（m-queue W04、m-guard W17、m-ledger W30、m-you W43）。要不要連謎底也提前，請翊文在 12-06 前確認（規劃 零之一 第 2b 題）。
- 第三方向的「選擇」要程式，W53 不放；第 7 題最晚 12-01、第 3 題最晚 12-06（規劃 柒之二）。

## 為什麼

主旨已經夠深，缺的是玩家在乎；年底揭露讓玩家在這個月就看到「人」「規矩」「你」，不用等到 2027 年。把謎底留在原本的日期，才不會一個月就把一整年的線收完。
