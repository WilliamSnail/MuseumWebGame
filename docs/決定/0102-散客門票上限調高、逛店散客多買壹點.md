# 0102 散客門票上限調高、逛店散客多買壹點

- 日期：2026-11-16 16:00:00
- 誰決定：翊文（看財報：散客 1,760 位但門票停在 500,000 上限；店裡消費只有 39,500，散客逛店幾乎 0）；數字由數值平衡定
- 狀態：有效（補充決定 0079、0084 的散客設定）

## 決定

| 設定 | 舊 | 新 |
|---|---|---|
| `crowd.dayCap`（散客門票全館壹天上限） | 500,000 | **1,200,000** |
| `crowd.shop.perStore`（每店每天逛店的散客平均幾位） | 1.5 | **6** |
| `crowd.shop.spend`（每位進店花） | 3,000 | **4,000** |
| `crowd.shop.dayCap`（全館逛店消費壹天上限） | 300,000 | **600,000** |

- 都是外面世界付（搬，不是憑空）；門票 ticketBudgetPct% 進預算池、其餘館方帳；餐車、牌桌的消費進莊家，其餘進預算池（跟原本壹樣）。
- 外面世界每天成長 5,000,000：散客門票上限 24%、門票加店裡上限 36%；實際平均遠小於上限。`econ:check` 的比例改：散客門票 ≤ 成長的 25%（原 10%）、門票加店裡 ≤ 40%（原 20%）、每店每天逛店位數 ≤ 保底人數的壹半（原 ≤ 有名字 NPC 的 λ）。

## 模擬（42 天，每天 1,339 位散客）

- 舊：門票平均 497,333，**36/42 天撞到上限**；逛店消費平均 24,518。
- 新：門票平均 669,464（最高 1,021,000，沒撞上限）；逛店消費平均 約 110,000。
- 平均每天多：門票約 +170,000、逛店消費約 +85,000，合計約 +260,000 籌碼（外面世界搬給預算池、館方帳、莊家）。
- 館內股：逛店的散客算進店的人數，所以人更多；卡位模擬（`test/sim_peek_stock.cjs`，館友 3、10 位）看人數每家店每天約 0.03%、0.004%（成本 1.04%），加上「到現在的 NPC 營收」預測欄約 0。沒有變得比較好賺。

## 沒有做

- 順路逛別間的散客（決定 0095）到餐車、牌桌、手作消費：不做。他們是「人數」，不到店、不算人數、不動錢；要讓他們消費就要算進館內股人數，需要另外評估。
